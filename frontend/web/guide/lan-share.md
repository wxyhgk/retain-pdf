# 局域网共享

桌面版才有。让同一个 Wi‑Fi 里的手机、平板用浏览器打开这台电脑上的 RetainPDF。

1. ![设置](icons/settings.svg) → ![局域网共享](icons/lan-share.svg) **局域网共享**，勾选「允许局域网里的设备访问」
2. 手机扫 ![二维码](icons/qr.svg) 二维码，或点 ![复制](icons/copy.svg) **复制完整链接** 发过去

**拿到链接的人能用你的 Key 翻译，只发给信任的设备。** 发错了点 **重置访问码**，旧链接立刻失效。

<summary>详细说明</summary>

只有桌面版有。打开后，同一个 Wi‑Fi 或局域网里的手机、平板、别的电脑，用浏览器就能打开这台电脑上的 RetainPDF：看书库、阅读、上传新书、发起翻译。

翻译和 OCR 用的是这台电脑上设置好的 Key，费用也记在这些 Key 上。Key 本身不会发给别的设备。

## 打开

1. 到 **设置 → 局域网共享**，勾选「允许局域网里的设备访问」。
2. 下面会列出这台电脑的局域网地址，每个地址配一个二维码。
3. 手机连同一个 Wi‑Fi，扫二维码；或者点「复制完整链接」发给别的设备，用浏览器打开。

链接里带着访问码，第一次打开后设备会记住，以后直接打开地址就行。

列不出地址时，说明这台电脑现在没连 Wi‑Fi 或网线。

## 安全

**拿到链接的人能用你的 Key 发起翻译，只发给信任的设备。**

发错了人，点 **重置访问码**：旧链接马上失效，之前连上的设备会立刻断开，再把新链接发给需要的设备。不用时取消勾选，局域网共享就关了。

## 别的设备上不能做的事

为了安全，这些只能在这台电脑上做：

- 改接口设置、检测 Key、拉取模型列表。
- 同步、备份。
- 上传字体、下载运行资源。

在别的设备上打开接口设置，会看到提示「…这里也改不了、检测不了」。

## 用不了

- 设置里写着「当前连接的是外部后端，局域网共享不可用」：桌面版连的是别处的服务，不是自己带的那个，这时不能共享。
- 手机打不开：确认手机和电脑在同一个网络里；公司、学校的网络可能禁止设备互相访问，换家里的 Wi‑Fi 试试。电脑的防火墙如果问要不要允许 RetainPDF 接收连接，选允许。
