# 阅读和修改译文

书的详情里点 ![对照阅读](icons/read-compare.svg) **对照阅读** 打开。

| 想要 | 怎么做 |
| --- | --- |
| 只看原文 / 对照 / 只看译文 | 顶部三个切换，或按 `1` `2` `3` |
| 看目录、找字、翻书签 | 顶栏左边的目录按钮打开左栏；找字也可以直接按 `⌘F` / `Ctrl+F` |
| 记住这一页 | 底栏左边 ![书签](icons/bookmark.svg)，书签都列在左栏「书签」里 |
| 让左栏一直开着 | 左栏右上角的图钉：钉在左边，书页往右让 |
| 复制一段 | 鼠标停在那段上，点 ![复制](icons/copy.svg) |
| 改一段译文 | 鼠标停在译文那段上，点 ![改](icons/edit.svg)（或按 `E`），改完点「保存」，再点右下「重新排版」 |
| 问 AI | 顶栏右边的「提问」；问某一段：书页上右键「在这里提问」 |
| 看文字版（Markdown） | 顶栏右边的 Markdown |
| 画线做标记 | 底栏右边的画笔（或按 `P`），旁边的 ▾ 选笔和颜色 |
| 截一块书页来问 | 底栏右边的截图，或书页上右键「截一块问」 |
| 下载 PDF | 顶栏右边 ![下载](icons/download.svg) |
| 看所有快捷键 | 按 `H` |

## 打开阅读页

在图书馆点一本书，打开 [书的详情](book-detail.md)，左边有两个按钮：

- **对照阅读**：原文和译文并排看。只做了 OCR、没有译文的书，这个按钮叫「查看 OCR」；还没处理过的书叫「读原文」。
- **查看原版**：只看原始 PDF。

书还在翻译时，详情「进度」页有「实时译文」按钮，不用等全部完成，就能在原文上逐页看到已经翻好的部分，见本章最后一节。

## 原文、对照、译文

阅读页顶部中间有三个切换：

| 模式 | 显示什么 | 快捷键 |
| --- | --- | --- |
| 原文 | 只看原始 PDF | `1` |
| 对照 | 左边原文，右边译文，两边同步翻页 | `2` |
| 译文 | 只看译文 PDF | `3` |

没有译文的书，「对照」和「译文」是灰的。手机等窄屏上默认打开「译文」。

每本书会记住你读到哪一页、缩放多大、用哪种模式，下次打开接着读。

## 页面的三行

阅读页从上到下是三行：顶栏、中间看书的地方、底栏。顶栏和底栏一直在，不会盖住书页。

**顶栏**

- 左边：返回图书馆（‹）、左栏开关（目录、搜索、书签、待处理）、书名。
- 中间：原文 / 对照 / 译文。
- 右边：提问、Markdown、对比版本（翻译过两次以上才有），再右边是下载（原文 PDF、对照 PDF、译文 PDF，还不能下载的是灰的、写着原因）。窗口窄时只剩图标，鼠标停上去看名字。

**底栏**

- 左边：「书签」给当前页加书签或取消（书签都列在左栏的「书签」里）；旁边的「收藏」还在做，点开只有一句说明。改过译文还没排进 PDF 时，这里有一行小字和「重新排版」。
- 中间：页码（点一下输入页码跳过去）、深色文档（半黑的圆，`D`，书页换成黑底白字）、缩放（减号、加号，点百分比恢复默认大小）。
- 右边：画笔（`P`）、截图、快捷键（键盘图标，`H` 或 `?`）。

## 左栏：目录、搜索、书签、待处理

顶栏左边的目录按钮打开左栏，再点一下收起。左栏有四个页签：

- **目录**：列出书里的各级标题（PDF 自带目录的书可以在「按 PDF 目录」和「按标题」之间切），点一条就跳过去，也会标出你当前读到哪一节。
- **搜索**（`⌘F` / `Ctrl+F` 直接打开）：同时搜原文和译文，命中的字在书页上会标出来，回车跳到下一处，`Shift+回车` 回上一处。
- **书签**：你加过的书签，点一条跳到那一页，鼠标移上去点 × 删掉。
- **待处理**：这次翻译里需要你看一眼的段落，按「没翻成 / 内容问题 / 版面放不下」分组列出，点一条就跳过去。按 `N` 到下一处，`Shift+N` 回上一处（左栏收着也能按）。有待处理时，目录按钮的角上会有一个灰底的小数字；没有问题的书没有这个页签。

打开阅读页时左栏总是收着，书页占满宽度；点顶栏的目录按钮或按 `⌘F` / `Ctrl+F` 才展开。左栏默认浮在书页左上角：点书页别处、按 `Esc`，或在目录、书签里点一条跳过去，它就收起。点左栏右上角的 **图钉** 可以把它钉在左边：书页往右让出一栏，左栏一直开着，直到你再点开关收起；钉没钉住会记住，下次展开时照样。窗口太窄（手机、窄窗口）时钉不住，照旧浮着。

## Markdown 文字版

点顶栏右边的 Markdown，右边让出一栏打开这本书的文字版，公式和图片都保留。

- 可以在「译文 / 原文 / 双语」之间切换。
- 点面板里的一段，左边 PDF 会跳到同一段；鼠标停在 PDF 某段上，面板里也会高亮对应的段。
- 面板底部有搜索和目录。
- 拖两栏中间的分隔线调宽窄；再点一次「Markdown」或按 `Esc` 收起。

## 提问窗贴在右边

提问窗标题栏右边的「贴到右边」把它放进右边那一栏（和 Markdown 用的是同一栏，同时只放一个）：书页往左让出位置，提问窗是页面的一部分，不再浮在书页上。拖它左边缘调宽窄，宽度会记住。这时打开 Markdown，提问窗会变回浮动的窗口。

## 画笔和截图

- **画笔**（底栏右边，`P`）：在书页上画线、做标记。旁边的 ▾ 选画笔、荧光笔、橡皮和颜色，也能撤销；平时不展开。
  - 在书页上点右键也能选笔和颜色，还能清掉这一页的笔迹。
  - `⌘Z` / `Ctrl+Z` 撤销，`Esc` 退出画笔。
  - 笔迹只保存在这台电脑上，画在原文栏的只出现在原文栏，画在译文栏的只出现在译文栏。
- **截图**（底栏右边）：在书页上拖出一块，截图带进提问窗问（和右键「截一块问」一样），`Esc` 取消。

## 对比两份译文

同一本书用不同模型或设置翻译过两次以上，就能对比：

1. 点顶栏右边的「对比版本」。
2. 选一份放在左边。右边是你正在读的这份。
3. 两边逐段对着看。
4. 觉得左边那份更好，点「用左边这份」，以后这本书默认就读它。
5. 点「退出对比」，左边换回原文。

## 问 AI

先在设置里配好翻译模型（或在电脑上装好 Claude Code 等本机 agent），阅读页就能问 AI。

- **问某一段**：在书页上点右键，选「在这里提问」（问鼠标下面那段）；选着一段字时是「问这段」，也可以选字后直接按 `?`。
- **问整本书**：点顶栏右边的「提问」。每本书有自己的一条对话，关掉再打开都接着聊。
- 问过的段落，书页左边白边上会有一个「?」，点它回到那次对话。
- 回答里的页码能点，点了跳到那一页；问题上方的小标签点了回到问的那一处。
- 窗口开着时在书页上选字，输入框上方会出现「第 N 页 · 选中 N 字」，下一问就问这段；点 × 不带。
- **谁来答**：输入框下面那颗按钮（写着模型名）。点开最上面一排选 agent（自带模型、Claude Code、Codex……没装的写「要先装」，点了给安装命令），下面选模型和要不要深度思考。
- **开个新对话、看以前的**：点标题栏左边的「主对话 ▾」。「开个新对话」会把现在这段收进「以前的对话」（问一句再开）；以前的对话点了只读地看，「回主对话」回来。
- **记忆**：标题栏右边「···」里，是 AI 记住的关于你和这本书的事，可以改、删、关掉。
- 标题栏右边还能把窗口贴到右边（书页往左让，不挡字）或放大；窗口的摆法、大小和选的 agent 都会记住，下次打开照旧。

## 翻译中看实时译文

书还在翻译时打开阅读页，原文上直接叠着已经翻好的译文：

- 页签右边显示「已译 N / 总页数 页」，点它在译文和原文之间切换。
- 「跳到最新」跳到刚译好的那一页。页不一定按顺序出来，所以它不一定是最后一页。
- 翻到还没译好的页，页顶会提示「这一页还没翻到」，译好后会自动出现。一页都还没好时，会显示「正在完成 OCR，译文将在这里逐页出现」。
- 翻译完成后，叠加会自动关掉，顶部出现「翻译完成 · 看对照」，点它左右对照看最终译文。

## 快捷键

| 做什么 | 按键 |
| --- | --- |
| 下一页 / 上一页 | `J` `↓` `PgDn` / `K` `↑` `PgUp` |
| 第一页 / 最后一页 | `Home` / `End` |
| 放大 / 缩小 / 恢复 | `+` / `−` / `0` |
| 原文 / 对照 / 译文 | `1` / `2` / `3` |
| 在书里搜索 | `⌘F` / `Ctrl+F` |
| 下一处 / 上一处搜索结果 | `Enter` / `Shift+Enter` |
| 下一处 / 上一处待处理段落 | `N` / `Shift+N` |
| 改鼠标停着的那段译文 | `E` |
| 改上一段 / 下一段 | `Alt+↑` / `Alt+↓` |
| 保存修改 | `⌘Enter` / `Ctrl+Enter` |
| 画笔 | `P`，`Esc` 退出 |
| 问选中的这段 | 选字后按 `?` |
| 快捷键说明 | `H` 或 `?` |

光标在输入框里时，这些快捷键不会触发。
