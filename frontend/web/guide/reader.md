# 阅读和修改译文

书的详情里点 ![对照阅读](icons/read-compare.svg) **对照阅读** 打开。

| 想要 | 怎么做 |
| --- | --- |
| 只看原文 / 对照 / 只看译文 | 顶部三个切换，或按 `1` `2` `3` |
| 在书里找字 | 底部 ![搜索](icons/search.svg)，或 `⌘F` / `Ctrl+F` |
| 记住这一页 | 底部 ![书签](icons/bookmark.svg) |
| 复制一段 | 鼠标停在那段上，点 ![复制](icons/copy.svg) |
| 改一段译文 | 鼠标停在译文那段上，点 ![改](icons/edit.svg)（或按 `E`），改完点「保存」，再点右下「重新排版」 |
| 看文字版（Markdown） | 右下角 ![工具](icons/grid.svg) → Markdown |
| 画线做标记 | 右下角 ![工具](icons/grid.svg) → 画笔（或按 `P`） |
| 下载 PDF | 右上角 ![下载](icons/download.svg) |
| 看所有快捷键 | 按 `H` |

## 打开阅读页

在图书馆点一本书，打开 [书的详情](book-detail.md)，左边有两个按钮：

- **对照阅读**：原文和译文并排看。只做了 OCR、没有译文的书，这个按钮叫「查看 OCR」；还没处理过的书叫「读原文」。
- **查看原版**：只看原始 PDF。

书还在翻译时，详情「进度」页有「实时译文」按钮，不用等全部完成，就能在原文上逐页看到已经翻好的部分，见本章最后一节。

## 原文、对照、译文

阅读页顶部中间有三个切换：

| 模式 | 显示什么 | 快捷键 |
| --- | --- | --- |
| 原文 | 只看原始 PDF | `1` |
| 对照 | 左边原文，右边译文，两边同步翻页 | `2` |
| 译文 | 只看译文 PDF | `3` |

没有译文的书，「对照」和「译文」是灰的。手机等窄屏上默认打开「译文」。

每本书会记住你读到哪一页、缩放多大、用哪种模式，下次打开接着读。

## 底部工具栏

从左到右：

- **页码**：显示「当前页 / 总页数」，点一下可以输入页码跳过去。
- **搜索**（放大镜，`⌘F` / `Ctrl+F`）：同时搜原文和译文，命中的字在书页上会标出来，回车跳到下一处。
- **书签**：给当前页加书签或取消。加过书签后旁边会出现书签列表，点一条跳到那一页。
- **待处理**（三角警告图标加数字）：这次翻译里需要你看一眼的段落，按「没翻成 / 内容问题 / 版面放不下」分组列出，点一条就跳过去。按 `N` 到下一处，`Shift+N` 回上一处。没有问题的书不显示这个按钮。
- **缩放**：「−」「+」缩小放大，点中间的百分比恢复默认大小。
- **快捷键**（键盘图标，`H` 或 `?`）：列出所有快捷键。

往下读时工具栏会自动收起，往回翻或把鼠标移到窗口底部就会出来。

## 顶部按钮

- **目录**（左上角）：列出书里认出的各级标题，点一条就跳过去，也会标出你当前读到哪一节。
- **下载**（右上角）：下载「原文 PDF」「对照 PDF」「译文 PDF」。还不能下载的项是灰的，下面写着原因。
- **关闭**（右上角）：回到图书馆。

## 右下角的工具球

点右下角的方格按钮，会展开几个工具：

- **Markdown**：在右边打开这本书的文字版，公式和图片都保留。
  - 可以在「译文 / 原文 / 双语」之间切换。
  - 点面板里的一段，左边 PDF 会跳到同一段；鼠标停在 PDF 某段上，面板里也会高亮对应的段。
  - 面板顶部有搜索和目录。
  - 再点一次「Markdown」或按 `Esc` 收起。
- **画笔**（`P`）：在书页上画线、做标记。
  - 可以选画笔、荧光笔、橡皮，颜色有红、墨、绿、黄。
  - 在书页上点右键也能选笔和颜色，还能清掉这一页的笔迹。
  - `⌘Z` / `Ctrl+Z` 撤销，`Esc` 退出画笔。
  - 笔迹只保存在这台电脑上，画在原文栏的只出现在原文栏，画在译文栏的只出现在译文栏。
- **对比版本**：这本书翻译过两次以上才有，见下面「对比两份译文」。

## 复制和修改译文

鼠标停在某一段上，原文和译文两栏会同时框出这一段。框上有：

- **复制**：复制这段原文或译文；公式会复制成 LaTeX。
- **改这段译文**（笔形图标，只在译文栏出现，快捷键 `E`）：把这一段变成编辑框，直接改。

在编辑框里：

- 有公式时，下面会显示预览。
- 「上一段」「下一段」（`Alt+↑` / `Alt+↓`）可以接着改相邻的段落。
- 「原因」可以不填，填了会记进修订历史。
- 点「保存」（`⌘Enter` / `Ctrl+Enter`）保存，`Esc` 取消。

正文和公式可以改，表格不能改。书还在翻译或排版时也不能改，要等处理完。

### 改完要重新排版

保存后，改过的段落会标上「待排版」，右下角出现「改了 N 处，还没排进 PDF」。点旁边的 **重新排版**，排完后译文 PDF 会自动换成新的。大书要几分钟。

### 改错了怎么办

编辑框里有修订历史按钮（时钟图标加次数）。点开能看到这一段每一版的时间、来源（初译 / 手改 / 精修）和原因，在想要的那版旁边点「用这版」就恢复了。

## 对比两份译文

同一本书用不同模型或设置翻译过两次以上，就能对比：

1. 点右下角工具球里的「对比版本」。
2. 选一份放在左边。右边是你正在读的这份。
3. 两边逐段对着看。
4. 觉得左边那份更好，点「用左边这份」，以后这本书默认就读它。
5. 点「退出对比」，左边换回原文。

## 翻译中看实时译文

书还在翻译时打开阅读页：

- 原文栏会一页一页叠上已经翻好的译文。还没有译文时，会显示「正在完成 OCR，译文将在这里逐页出现」。
- 顶部左边显示「实时译文 · N 页」，点它可以打开或关掉叠加。
- 翻译完成后，叠加会自动关掉，右栏就是最终的译文 PDF。

## 快捷键

| 做什么 | 按键 |
| --- | --- |
| 下一页 / 上一页 | `J` `↓` `PgDn` / `K` `↑` `PgUp` |
| 第一页 / 最后一页 | `Home` / `End` |
| 放大 / 缩小 / 恢复 | `+` / `−` / `0` |
| 原文 / 对照 / 译文 | `1` / `2` / `3` |
| 在书里搜索 | `⌘F` / `Ctrl+F` |
| 下一处 / 上一处搜索结果 | `Enter` / `Shift+Enter` |
| 下一处 / 上一处待处理段落 | `N` / `Shift+N` |
| 改鼠标停着的那段译文 | `E` |
| 改上一段 / 下一段 | `Alt+↑` / `Alt+↓` |
| 保存修改 | `⌘Enter` / `Ctrl+Enter` |
| 画笔 | `P`，`Esc` 退出 |
| 快捷键说明 | `H` 或 `?` |

光标在输入框里时，这些快捷键不会触发。
