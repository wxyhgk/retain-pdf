# 更新

只有桌面版有。

- **macOS、Windows**：软件会自己检查新版本并在后台下载，下好后提示「新版本已下载，重启即可更新」，重启一下就是新版本。
- **Linux**：不会自动更新。到 [GitHub Releases](https://github.com/wxyhgk/retain-pdf/releases) 下载新的 `.deb`，照 [安装](install.md#linux) 那一步再装一遍，书库和设置都会保留。

## 设置 → 更新

- 显示当前版本和最新版本。
- **检查更新**：马上去 GitHub Releases 查一次。
- 有新版本时会列出这次更新了什么。

连不上 GitHub 时会提示「暂时无法连接 GitHub Releases」，等网络好了再点一次。

这一栏下面还有「命令行工具」，见 [外观和命令行](settings.md#命令行工具)。
