# 通知

任务跑完时，软件会提醒你：

- 你正看着软件时，在页面里弹一条提示。成功的带「去阅读」按钮，失败的带「查看」按钮。
- 软件在后台时，弹系统通知，标题是「翻译完成」「识别完成」「排版完成」或对应的「…失败」。网页版的标签页标题前还会加上 ✓ 或 ✗。
- 自己取消的任务不提醒。

第一次提交任务时，会问你要不要开系统通知，点「开启」就行。

## 设置 → 通知

- **任务跑完时弹系统通知**：总开关，默认开。
- **允许通知**：系统还没允许软件发通知时，点它去允许。
- **发一条试试**：发一条测试通知，看看系统那边有没有拦住。

收不到系统通知时，先点「发一条试试」。还是收不到，到系统设置的「通知」里找 RetainPDF（网页版找浏览器），看是不是被关了。
