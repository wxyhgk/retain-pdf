# 「朱砂手绘」装饰包 —— 素材说明

这套主题照用户给的设计图做：米黄纸底、粗深色描边、向右下偏移的实色硬阴影、朱红强调、
书卡带折角和「在读」书签丝带，右下角一个人物，四角红色云纹。

**分工**：

| 部分 | 谁做 | 放哪 |
|---|---|---|
| 颜色、描边、硬阴影、按钮和书卡形状 | 代码（主题变量） | `frontend/packages/ui/styles/themes/zhusha.css` |
| 书签丝带、书卡折角 | 代码（纯 CSS，不用图） | 同上 |
| 背景（纸纹 + 四角云纹）、人物 | **素材，放在本文件夹** | `frontend/web/decor/zhusha/` |

素材到齐之前主题照样能用，只是没有背景图和人物。

方案：[主题完全可自定义](../../../../docs/ops/planning/theme-customization/20261124-主题完全可自定义.md)。
装饰包怎么挂、有哪些位置：[装饰包契约](../../../../docs/core/frontend/theme-system/DECOR_PACKS.md)。
现成的例子：[墨家](../mojia/ASSETS.md)。

## 1. 要做的图

### 1.1 `bg.webp` —— 全屏背景（必需）

- **内容**：米黄纸底，带一点纸纹；红色祥云纹只放在**四个角**（设计图里左上、右上、左下三处）。
- **尺寸**：1920×1080（16:9），会按屏幕铺满裁切，四角往里留 5% 不放关键图案。
- **中间留白**：中间约 70% × 70% 是书库面板，会盖住，不要放东西。
- **云纹的大小**：背景按屏幕铺满，1280×800 的窗口下整张图会缩放到 0.74 倍左右再裁掉两边。云纹横向控制在左右各
  **15%** 以内（1920 宽的图里离边 ≤ 290px）、纵向控制在上下各 **18%** 以内，1280 宽才不会碰到「全部书库」标题和视图切换。
- **四条边**：不要留拉伸出来的条纹，铺满时边上会露出来。
- 2026-11-24 用户给的第一版云纹偏大、四边有拉伸条纹，按上面两条处理过一遍：纸纹取中间干净的一块镜像拼满，
  四朵云抠出来缩到 70%、离边 40px 贴角放（左上 40–283 × 30–140，右上 1624–1880 × 30–154，下面两朵同理）。
  以后换图照这个尺寸画，就不用再处理。
- **明度**：背景整体要浅，书库面板是半透明纸色盖在上面的，背景太深会透出来影响文字。
  底色建议接近 `#f3e9d6`，云纹用朱红 `#c8372d` 上下、可以带深墨描边。
- 不用透明。

> 云纹做进背景图里，不单独做成四张图：右下角要放人物，单独的角图会和人物抢同一个位置，
> 而且窄屏（宽度小于 1100px）时只保留背景，角图会被隐藏，做进背景里窄屏也看得到。

### 1.2 `character.webp` —— 右下角人物（必需）

- **内容**：设计图右下角那种手绘风人物（抱书的人），压在书库面板右下边缘之上。
- **尺寸**：600×840，**透明背景**；人物占画布高度约 95%，**贴右下角**（脚或身体底边贴画布底边，
  右侧贴画布右边），朝向屏幕中间。
- 风格：粗墨线描边 + 平涂，和界面的粗描边硬阴影一致；颜色以朱红、米黄、墨色为主。
- 点击人物可以轮播一两句话（可选）。要的话把文案写在下面「4. 交付清单」里，我写进配置。

### 1.3 可选

- `prop-left-top.webp`：左上角飞着的小物件（风筝、纸鹤、飘带之类），560×720 透明，只占画布上半部。
  **只有会飞的东西**能放上面，站着的东西放上面会像悬空贴纸。
- 底栏按钮的贴面图（像墨家把「+」换成齿轮那样）：先不做，等主题定稿再说。

## 2. 技术要求（不满足会被测试挡下）

- 格式：`webp`（首选）、`png`、`avif`、`svg`；人物和道具**必须透明背景**。
- 单个文件 **≤ 512 KB**。webp 压缩参考：`magick 原图.png -quality 85 -define webp:alpha-quality=95 输出.webp`。
- 色彩空间 sRGB。
- 文件名按上面写的来；以后替换素材，用同名文件覆盖就行。
- 只用自己画的、或者有授权可以商用的图（项目是 MIT 开源，素材会随安装包发布）。
  来源写进下面的交付清单。
