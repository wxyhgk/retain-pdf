# @blog/ui

博客和 Studio 共用的页面部件。

| 文件 | 内容 |
|---|---|
| `block-sheet.ts` | `openBlockSheet`：块的详情窗口。页面上的块只留精简卡片，所有细节都放在这个窗口里：Studio 里双击块或选中后按 Enter 打开，博客上点一下打开。窗口顶部是块的类型、名字和操作按钮，详情按页签分开（结果、设置、输出……）。Esc 关闭，⌘/Ctrl+Enter 执行主操作。 |
| `block-sheet.css` | 窗口的样式，用网站的颜色变量；手机上铺满全屏 |

已经用上的：计算块（`@blog/compute`）。以后分子、cube、交互模块、代码文件、Office 卡片也会改成「卡片 + 双击打开窗口」。
