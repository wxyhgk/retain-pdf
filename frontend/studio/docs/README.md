## 文章放在哪里

每篇文章是 `blog/` 下的一个文件夹：

```text
blog/
└── hf-project/          ← 文件夹名，也是网址：/blog/hf-project/
    ├── index.md         ← 正文和开头的属性（YAML）
    ├── img/             ← 图片，随文章发布
    ├── assets/          ← 计算的输入输出、数据，随文章发布
    └── ai/              ← 给 AI 的私有材料，不发布
```

页面可以挂在别的页面下面，组成一棵树：在属性里写 `parent: <上级的文件夹名>`。文件夹始终并排放在 `blog/` 下面，网址不会因为挪动而改变。
