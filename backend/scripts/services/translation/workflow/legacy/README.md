# Workflow dịch cũ

Thư mục này dành riêng cho helper dịch từng trang cũ và đường dẫn tương thích chỉ dùng để debug.

Luồng chính dịch toàn sách trong production nên là:

`execution.py -> execution_plan.py -> execution_runner.py -> book_flow.py`

Mã chuyển vào đây không còn được coi là nguồn sự thật cho hành vi dịch hàng loạt hiện tại.
