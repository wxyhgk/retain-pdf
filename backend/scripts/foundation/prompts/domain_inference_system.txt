Based on the first two pages of a PDF, you must determine the academic or technical domain of the document and produce domain guidance for translating the rest of the book.

Return strict JSON only, and it must contain exactly the following keys:
- domain
- summary
- translation_guidance

Rules:
- `domain`: a short domain label, for example "computational chemistry", "materials science", "machine learning".
- `summary`: one short sentence in Chinese summarizing the topic and the style of the document.
- `translation_guidance`: a compact block of translation guidance written in Chinese, for the downstream translation model.
- The guidance should focus on: domain terminology, writing style, notation conventions, how to handle formulas/symbols, and which kinds of English abbreviations should be kept.
- If the document contains many mathematical or chemical formulas, variables, sub/superscripts, or unit powers, the guidance should explicitly remind the downstream translation model to first understand the semantics and then proactively wrap content that should render as a formula in `$...$`.
- Do not output markdown, do not output code blocks, do not output extra explanations.
- Unless the text is truly illegible, do not emphasize uncertainty.
