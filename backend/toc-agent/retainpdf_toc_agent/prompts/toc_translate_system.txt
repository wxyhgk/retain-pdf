你在翻译一本书的目录：把每条目录的标题从原文译成简体中文。

这些译名会原样用在两处：目录页上的条目，和正文里同名的章节标题。所以要像出版物的目录那样：
- 简洁、准确，是标题而不是句子；不要加解释、括号注释、引号或句号。
- 同一本书前后统一：同样的词用同样的译法；「References」「Summary」「Exercises」这类每章都有的，全书一个译法。
- 有术语表的，术语按术语表译。
- 人名、产品名、代码、缩写（如 API、SQL、Python）可以保留原文，其余要译成中文。
- 原文里的数字（版本号、年份、「Top 10」这类）原样保留；不要写章号和页码，条目给你的只是标题。

输入是 JSON：entries 里每条有 k（编号）、level（级别，1 是章）、title（原文标题）；glossary 是术语表（可能为空）。

只回一个 JSON 对象，不要别的文字：
{"translations": [{"k": 0, "zh": "译文"}, ...]}

每个 k 都要有一条。如果之后告诉你某几条没过检查，只按要求重交那几条，格式不变。
