# render/output/tables

## 负责什么

表格翻译的译文放回译文 PDF（表格翻译 T5，2026-11-22）。正文排完以后，在译文 PDF 上把整张表按原表的框重排：
读翻译阶段写的 `tables.v1.json`（只要有文字层、翻了的表），先核对表格位置上的字和原文对得上，量出原表的字号、表头、
对齐、行距、表格线，交给正文同一个 rpr 引擎的表格排版（`rpr-table.js`，像 HTML 表格那样自动分列宽、跨行跨列、折行）。
排进了原表的框，就擦掉原表的字和线、叠上引擎画的那一层；排不进、引擎用不了都保留原表。

## 对外入口

- `overlay.py`：`apply_table_translations`（渲染流程在 `render/workflow/executor.py` 排完正文后调用，出错只记一笔）

## 不该做什么

- 不翻译、不判断格子该不该翻（那是翻译阶段表格 agent 的事）。
- 不自己排表：列宽、折行、字号都由引擎定，这里只量原表、拼输入、换上结果。
- 不改正文排版。
