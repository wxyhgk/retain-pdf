## Cách đọc

Trước tiên đọc hướng dẫn đóng góp ở thư mục gốc, sau đó vào tài liệu con tương ứng theo module bạn muốn sửa. Thay đổi xuyên module cần đọc đồng thời tài liệu các module liên quan.
