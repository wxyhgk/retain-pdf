Bạn có thể gặp các lỗi sau khi gọi DeepSeek API. Dưới đây là nguyên nhân và cách khắc phục.

Mã lỗi	Mô tả
400 - Lỗi định dạng	Nguyên nhân: Định dạng body yêu cầu sai
Cách khắc phục: Sửa body yêu cầu theo thông báo lỗi
401 - Xác thực thất bại	Nguyên nhân: Sai API key, xác thực thất bại
Cách khắc phục: Kiểm tra API key; nếu chưa có, hãy tạo API key
402 - Số dư không đủ	Nguyên nhân: Tài khoản không đủ số dư
Cách khắc phục: Xác nhận số dư và nạp tiền tại trang Nạp tiền
422 - Sai tham số	Nguyên nhân: Tham số body yêu cầu sai
Cách khắc phục: Sửa tham số theo thông báo lỗi
429 - Vượt giới hạn tốc độ	Nguyên nhân: Tốc độ yêu cầu (TPM hoặc RPM) đạt giới hạn
Cách khắc phục: Lên kế hoạch tốc độ yêu cầu hợp lý.
500 - Lỗi máy chủ	Nguyên nhân: Lỗi nội bộ máy chủ
Cách khắc phục: Thử lại sau. Nếu vẫn gặp vấn đề, hãy liên hệ với chúng tôi
503 - Máy chủ bận	Nguyên nhân: Máy chủ quá tải
Cách khắc phục: Thử lại yêu cầu sau
