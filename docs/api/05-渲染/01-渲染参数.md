# 渲染参数

渲染参数位于创建任务请求的 `render` 对象中。

## 常用字段

```json
{
  "render": {
    "render_mode": "auto",
    "compile_workers": 0,
    "typst_font_family": "Source Han Serif SC",
    "pdf_compress_dpi": 0,
    "translated_pdf_name": "book-translated.pdf",
    "body_font_size_factor": 0.95,
    "body_leading_factor": 1.08,
    "font_unify_mode": "role_min",
    "source_cleanup_strategy": "pikepdf_text_strip",
    "engine": "typst"
  }
}
```

字段说明：

- `render_mode`: 渲染模式。
- `compile_workers`: Typst 编译并发，`0` 表示使用默认策略，最多 64。
- `typst_font_family`: Typst 使用字体。
- `pdf_compress_dpi`: PDF 图片压缩 DPI，默认 `0` 表示不额外压缩，最多 1200。
- `translated_pdf_name`: 输出 PDF 文件名。
- `body_font_size_factor`: 正文字号全局倍率，默认 `0.95`。
- `body_leading_factor`: 正文行距全局倍率，默认 `1.08`。
- `font_unify_mode`: 字体统一策略，`role_min`（默认）或 `off`。`role_min` 按块的角色统一字号，整本书的正文字号更一致；
  `off` 只关掉字号统一，版面适配、行高求解、碰撞处理、底色清理照旧。
- `source_cleanup_strategy`: 原文处理策略，默认 `pikepdf_text_strip`，取值见 [source_cleanup 策略](02-source-cleanup策略.md)。
- `inner_bbox_shrink_x`、`inner_bbox_shrink_y`、`inner_bbox_dense_shrink_x`、`inner_bbox_dense_shrink_y`: 译文框向内收缩量，默认 `0.0`。
- `engine`: 排版引擎，`rpr_fit`（默认）或 `typst`。`rpr_fit` 是自研排版引擎：引擎精确断行、按测量定字号、排版并直接写出叠加层 PDF（不经过 Typst），公式走 MathJax；`typst` 是原 Typst 路线。旧取值 `rpr`（同一引擎、沿用 retain-pdf 算好的字号）2026-11-02 起不再单独走一条路线，照旧接受、按 `rpr_fit` 渲染。`dual` 模式、非思源宋体字体、Node 不可用（需 ≥ 22.8）、引擎依赖缺失或引擎失败时自动回退 `typst`，回退原因记在 `pipeline_summary` 的 warning 里，任务不失败。非法值返回 400。

`render_mode`、`font_unify_mode`、`source_cleanup_strategy`、`engine` 不认识的值都是 400（重试的 `overrides.render.engine` 也一样）。

完整规范见 `backend/api/RENDER_OPTIONS_CONTRACT.md`。
