# 渲染参数

渲染参数位于创建任务请求的 `render` 对象中。

## 常用字段

```json
{
  "render": {
    "render_mode": "auto",
    "compile_workers": 0,
    "typst_font_family": "Source Han Serif SC",
    "pdf_compress_dpi": 0,
    "translated_pdf_name": "book-translated.pdf",
    "body_font_size_factor": 0.95,
    "body_leading_factor": 1.08,
    "font_unify_mode": "role_min",
    "source_cleanup_strategy": "pikepdf_text_strip"
  }
}
```

字段说明：

- `render_mode`: 渲染模式。
- `compile_workers`: Typst 编译并发，`0` 表示使用默认策略。
- `typst_font_family`: Typst 使用字体。
- `pdf_compress_dpi`: PDF 图片压缩 DPI，`0` 表示不额外压缩。
- `translated_pdf_name`: 输出 PDF 文件名。
- `body_font_size_factor`: 正文字号全局倍率。
- `body_leading_factor`: 正文行距全局倍率。
- `font_unify_mode`: 字体统一策略，常用 `role_min` 或 `off`。
- `source_cleanup_strategy`: 原文处理策略。

完整规范见 `backend/api/RENDER_OPTIONS_CONTRACT.md`。
