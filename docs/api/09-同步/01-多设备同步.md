# 多设备同步

几台电脑通过一个「同步文件夹」（iCloud、坚果云、Dropbox 等网盘客户端同步的目录）交换书库，
不需要任何一端跑服务。格式与合并规则见 `backend/packages/retain-data/src/sync.rs`。

设置存在后端的数据库里（跟着数据目录走），桌面版、网页版、Docker 都一样。开启后后端每隔
`RUST_API_SYNC_INTERVAL_SECS`（默认 60）秒同步一轮；改设置或调用「立即同步」时马上跑。

## 同步什么

- 同步：上传的原文、书（标题、阅读状态等）、合集与合集成员、收藏、结束了的任务
  （成功、失败、取消；含 OCR 结果、译文与手改记录、成品 PDF、事件与进度）。
- 不同步：还在排队或运行的任务（结束后再同步）、渲染中间文件与 Word 下载（各设备需要时
  重新生成）、凭据与 API Key、界面偏好。

## `GET /api/v1/sync`

返回同步状态：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "enabled": true,
    "folder": "/Users/me/Library/Mobile Documents/com~apple~CloudDocs",
    "sync_root": "/Users/me/Library/Mobile Documents/com~apple~CloudDocs/RetainPDF-Sync",
    "device_id": "6ce4ea829f53da8e",
    "device_name": "书房的 Mac",
    "running": false,
    "interval_seconds": 60,
    "last_run": {
      "started_at": "2026-10-09T08:00:00Z",
      "finished_at": "2026-10-09T08:00:03Z",
      "ok": true,
      "error": null,
      "exported": 2,
      "applied": 5,
      "deleted": 0,
      "files_uploaded": 1,
      "files_downloaded": 9,
      "rejected": 0,
      "folder_changed": false,
      "device_renewed": false
    },
    "pending_total": 0,
    "pending": [],
    "peers": [{ "device_id": "fedcba9876543210", "name": "办公室的 Mac", "segments_read": 12 }]
  }
}
```

- `folder`：用户选的文件夹；`sync_root`：实际读写的目录。所选文件夹里已经有同步数据
  （`format.json`）就直接用，否则在里面建 `RetainPDF-Sync`。
- `pending`：还在等文件从网盘下载、或等相关的书和任务同步过来的改动（最多列 20 条），到了自动补上。
- `last_run.folder_changed`：换了同步文件夹，本机书库已全部重新放进去。
- `last_run.device_renewed`：数据目录是从别的电脑复制来的，这台电脑已换成新设备号加入。

## `PUT /api/v1/sync`

改设置，没给的字段不变，返回新的状态：

```json
{ "enabled": true, "folder": "/absolute/path", "device_name": "书房的 Mac" }
```

`400` 的情况：开启时还没有文件夹；路径不是绝对路径、不存在、不是文件夹、写不进去；
文件夹在 RetainPDF 数据目录里面或包含数据目录；设备名超过 64 个字。`folder` 传空串表示清除。

## `POST /api/v1/sync/run`

立即同步一轮，等它跑完后返回状态（已经有一轮在跑就等它跑完再跑）。同步没开启时返回 `409`。
