# 字体与运行资源

接口清单见 [接口目录 · 字体](../00-接口目录/18-字体.md)、[运行资源](../00-接口目录/19-运行资源.md)。

## 字体

```http
GET  /api/v1/fonts
```

- 返回能用的字体数组，每项 `{family, files, available}`。结果在服务器上缓存（字体目录没变时最多 10 分钟）。
- 上传字体 `POST /api/v1/fonts/upload` 2026-11-25 删了（没有调用方，10-18 起 0 次）。要加字体，直接把文件放进 `<数据目录>/fonts/`。

## 运行资源（字体、Typst 按需下载）

2026-11-22 起。安装包不带思源宋体和 Typst 时，后端首次启动在后台从 npm 源（东八区先 npmmirror）下到 `<数据目录>/runtime-assets/`，
逐个文件核对 sha256。方案见 [字体和 Typst 按需下载](../../ops/planning/desktop-size/20261122-字体和Typst按需下载.md)。

```http
GET  /api/v1/runtime-assets
POST /api/v1/runtime-assets/download
```

返回 `{downloads_enabled, assets: [{id, title, version, state, bytes_done, bytes_total, source, error}]}`：

- `id`：`fonts`、`typst`。
- `state`：`bundled`（包里带着）/ `ready`（下好了）/ `missing` / `downloading` / `failed`。
- `source`：正在从哪个源下（`npmmirror`、`npmjs`）；`error`：失败原因。
- `downloads_enabled`：要桌面端设 `RETAIN_PDF_RUNTIME_ASSETS=download` 才会下；Docker、开发环境不下，资源多半是 `bundled`。

`POST …/download`（多用户下只给管理员）在后台把缺的、失败的再下一遍，马上返回当前状态，进度再用 `GET` 看。
渲染前最多等 5 分钟，还没好就用包里的 DroidSansFallback 排（黑体风格、标题没有粗体）。
