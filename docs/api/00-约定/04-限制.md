# 限制

2026-11-24 整理：rust_api 对外接口上的大小、条数、时间限制，每行写出配置项（环境变量，没有的写「常量」）和代码位置。
数值以代码为准；改了代码请同时改这张表。超出大小限制的回应是 `413`（`error.code = "PAYLOAD_TOO_LARGE"`），`limit` 越界是 `400`，
信封见 [响应格式](01-响应格式.md#错误响应)。

## 请求体大小

| 范围 | 上限 | 配置项 | 代码位置 | 说明 |
|---|---|---|---|---|
| 普通 JSON 请求体（没标记的接口） | 2 MB（2,097,152 字节） | 常量（axum `DefaultBodyLimit` 默认值） | `backend/api/src/app/endpoints.rs` 的 `endpoints!` 宏：没写 `[large_body]` / `[unlimited_body]` 就不改默认 | 超了 `413` `request body is too large`（`backend/api/src/routes/common/extractors.rs` 的 `safe_json_rejection`）。模型执行器的内部接口也是这个上限 |
| 带图的 JSON：`POST /providers/translation/ask` | 24 MiB | 常量 `LARGE_BODY_LIMIT_BYTES` | `backend/api/src/app/endpoints.rs`（`large_body`） | 接口登记表里标 `[large_body]` 的接口。请求里最多 4 张图、每张 base64 解码后 4 MiB、提示 10 万字（`backend/packages/retainpdf-providers/src/provider_probe/ask.rs` 的 `ASK_MAX_*`） |
| 访问控制读 JSON 请求体 | 16 MiB | 常量 `ACCESS_JSON_BODY_LIMIT` | `backend/api/src/auth.rs` 的 `enforce_access` | **只在多用户模式下的网站账号**生效：先把 JSON 请求体读进来核对里面的编号是不是自己的，超了 `413`。单机模式、API Key 调用不经过这一步 |
| 上传 PDF：`POST /uploads` | 512 MiB | `RUST_API_UPLOAD_MAX_BYTES`（字节，只写数字；不设或 `0` 用默认） | 默认值 `DEFAULT_UPLOAD_MAX_BYTES` 在 `backend/packages/retainpdf-core/src/config/upload.rs`；接口标 `[unlimited_body]`（`backend/api/src/app/router/ingestion.rs`），由上传自己按这个上限边收边查 | 页数上限 `RUST_API_UPLOAD_MAX_PAGES`，`0` 不限（默认）。磁盘剩余低于 `RUST_API_MIN_FREE_DISK_MB`（默认 1024，`0` 不查）时 `503` `insufficient_storage` |
| 选了 OCR 服务商时的文件上限 | MinerU：600 页、小于 200 MiB；PaddleOCR：999 页、不超过 100 MiB（分片上传不受字节限制） | `RUST_API_MINERU_MAX_PAGES`、`RUST_API_MINERU_MAX_BYTES`、`RUST_API_PADDLE_MAX_PAGES`、`RUST_API_PADDLE_MAX_BYTES` | 服务商清单 `backend/config/ocr_providers.json` 的 `limits`，读取在 `backend/packages/retainpdf-core/src/config/provider_config.rs` 的 `upload_limits_from_definition` | 建任务时查，清单里没写 `limits` 的服务商不限 |
| 上传字体：`POST /fonts/upload` | 64 MiB | 常量 `FONT_UPLOAD_MAX_BYTES` | `backend/api/src/routes/common/fonts.rs` | 接口标 `[unlimited_body]`，上限由处理函数自己查 |

## 条数

各列表 `limit` 越界（`0` 或大于上限）一律 `400`，不静默夹，规矩见 [分页](03-分页.md)；表里注明了例外。

| 接口 | 默认 | 上限 | 配置项 | 代码位置 |
|---|---|---|---|---|
| `GET /jobs` | 20 | 500 | 常量 `MAX_JOB_LIMIT` | `backend/packages/retainpdf-core/src/config/limits.rs`；校验在 `backend/packages/retainpdf-jobs/src/presentation/listing.rs` |
| `GET /documents/{document_id}/jobs` | 20 | 500 | 常量 `MAX_JOB_LIMIT` | 同上；`backend/packages/retainpdf-jobs/src/query.rs` |
| `GET /documents`（书库列表） | 50 | 500 | 常量 `MAX_DOCUMENT_LIMIT` | 默认值 `backend/packages/retainpdf-library/src/views.rs`；校验 `backend/packages/retainpdf-library/src/documents.rs` |
| `GET /search`（全文搜索） | 20 | 100 | 常量 `MAX_SEARCH_LIMIT` | `backend/packages/retainpdf-library/src/search.rs` |
| `GET /documents/{document_id}/metadata-suggestions` | 20 | 100 | 常量 `MAX_SUGGESTIONS` | `backend/packages/retainpdf-library/src/metadata_suggestions.rs` |
| `GET /jobs/{job_id}/translations`（译文条目） | 20 | 500 | 常量 `MAX_LIST_LIMIT` | `backend/packages/retainpdf-jobs/src/translations/index.rs` |
| `GET /jobs/{job_id}/data/{dataset}` | 200 | 1000 | 常量 `MAX_LIMIT` | `backend/packages/retainpdf-jobs/src/data/mod.rs` |
| `GET /jobs/{job_id}/progress/events` | 500 | 500 | 常量 `MAX_JOB_EVENT_LIMIT` | `backend/packages/retainpdf-jobs/src/progress/event_feed/mod.rs` |
| `GET /jobs/{job_id}/progress/editorial`（编辑部事件） | 500 | 2000 | 常量 `MAX_LIMIT` | `backend/packages/retainpdf-jobs/src/progress/editorial.rs`。**例外**：越界不报 400，夹到 1..=2000 |
| `POST /usage/prices`（批量查单价） | — | 一次 100 条 | 常量 `MAX_PRICE_LOOKUP_ITEMS` | `backend/packages/retainpdf-jobs/src/reports/usage/estimate.rs`；超了 `400` |
| 排队的任务（建任务、原地重跑） | — | 1000 个排队中的任务 | `RUST_API_MAX_QUEUED_JOBS`（`0` 不限） | `backend/packages/retainpdf-core/src/config/job_runner.rs`；满了 `429` `queue_full`，见 [认证与错误](02-认证与错误.md) |

不分页、一次全给的列表（合集、术语表、OCR 服务商、备份、同步）见 [分页](03-分页.md) 的说明。

## 时间

**JSON 接口没有统一的请求超时**：rust_api 没挂超时中间件，一个请求跑多久取决于处理函数自己（下表）。进度流（SSE）这类长连接
一直开着，只在停机时按 `RUST_API_SHUTDOWN_GRACE_SECS`（默认 3 秒，`0` 不等）断开。客户端自己要设超时（网页端等 30 秒）。

| 什么 | 时限 | 配置项 | 代码位置 | 超时后 |
|---|---|---|---|---|
| 服务商密钥校验（MinerU、Paddle、翻译接口、DeepSeek 余额、拉模型列表） | 20 秒 | `RUST_API_PROVIDER_PROBE_TIMEOUT_SECS`（没设时认旧名 `RUST_API_DEEPSEEK_PROBE_TIMEOUT_SECS`） | `backend/packages/retainpdf-core/src/config/provider.rs` | 校验结果里报超时；比网页端的 30 秒短，免得前端先放弃 |
| 问模型 `POST /providers/translation/ask` | 180 秒 | 常量 `ASK_TIMEOUT_SECS` | `backend/packages/retainpdf-providers/src/provider_probe/ask.rs` | 报「等了 180 秒模型还没回答」 |
| 页预览、封面、缩略图（渲染一页） | 60 秒 | 常量 `RENDER_TIMEOUT` | `backend/packages/retainpdf-files/src/derived_artifacts/preview.rs` | 杀掉渲染进程、报错；不留半截文件 |
| 派生产物：对照 PDF | 120 秒 | 常量 `BUILD_TIMEOUT` | `backend/packages/retainpdf-files/src/derived_artifacts/side_by_side.rs` | 同上 |
| 派生产物：线性化 PDF（qpdf） | 120 秒 | 常量 | `backend/packages/retainpdf-files/src/derived_artifacts/pdf.rs` | 失败就照旧发原来的 PDF |
| 派生产物：Word | 600 秒 | 常量 `BUILD_TIMEOUT` | `backend/packages/retainpdf-files/src/derived_artifacts/word.rs` | 杀掉生成进程、报错 |
| 模型执行器（翻译工作进程经内部接口调模型）：排队 / 连接 / 两次收到数据的间隔 / 整次 | 30 / 10 / 60 / 180 秒 | 常量，任务请求里不能设（`Deadlines::default`） | `backend/packages/retainpdf-core/src/model_connection.rs`；用在 `backend/packages/retainpdf-providers/src/model_executor/` | 结果里标 `queue_timeout`、`read_idle_timeout` 等，由工作进程决定重试 |
| 任务失败后的诊断子进程（`retainpdf-pipeline diagnose-failure`） | 60 秒 | `RUST_API_FAILURE_AI_DIAGNOSIS_TIMEOUT_SECS` | `backend/packages/retainpdf-core/src/config/job_runner.rs`；用在 `backend/packages/retainpdf-runner/src/job_runner/process_runner/failure_ai_diagnosis.rs` | 不影响任务已经记下的失败结构 |
| 一个阶段的 worker 进程最长跑多久 | 24 小时（`0` 不限）；任务请求的 `runtime.timeout_seconds` 更大时以它为准 | `RUST_API_WORKER_MAX_RUNTIME_SECS` | `backend/packages/retainpdf-core/src/config/job_runner.rs`；用在 `backend/packages/retainpdf-runner/src/job_runner/worker_process.rs` 的 `max_runtime_secs` | 杀掉 worker，阶段失败 |
| MinerU、PaddleOCR 的请求 / 上传 / 下载 | 120 / 300 / 300 秒 | `RUST_API_MINERU_REQUEST_TIMEOUT_SECS`、`RUST_API_MINERU_UPLOAD_TIMEOUT_SECS`、`RUST_API_MINERU_DOWNLOAD_TIMEOUT_SECS`，Paddle 同名 `RUST_API_PADDLE_*` | `backend/packages/retainpdf-core/src/config/provider.rs` | OCR 阶段按服务商错误处理 |
| 数据库忙时等锁 | 5000 毫秒 | `RUST_API_DB_BUSY_TIMEOUT_MS` | `backend/packages/retainpdf-core/src/config/db.rs` | `500`（库被锁） |

其它环境变量（端口、数据目录、清理周期等）见 [本地开发](../../core/api/local-dev.md)。
