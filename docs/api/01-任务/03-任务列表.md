# 任务列表

## 接口

```http
GET /api/v1/jobs
```

用于展示最近任务、书库入口和任务卡片列表。

## 查询参数

当前实现支持的过滤和分页能力以接口返回为准。前端应避免依赖本地缓存作为最终状态。

## 响应重点

列表项应包含：

- `job_id`
- `status`
- `display_stage`
- `stage`
- `substage`
- `lane`
- `progress`
- `display_name`
- `page_count`
- `source_file_name`
- `cover_url`
- `thumbnail_url`
- `output_pdf_ready`
- `markdown_ready`
- `bundle_ready`

## 前端规则

- 列表卡片使用列表接口返回的快照即可，不需要立即拉每个 job detail。
- 图片使用 `cover_url` / `thumbnail_url`，为空时由前端使用占位图。
- 不要扫描本地文件系统或拼接 job 目录。
