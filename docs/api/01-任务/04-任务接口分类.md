# 任务接口分类

`/jobs/{job_id}` 下的接口按"回答什么问题"分成 8 类，每类一个固定前缀（2026-11-03 以前还有第 9 类 AI，已删，见下面「AI（已删）」）。下面表里的“旧地址”列只是对照：
这些旧地址都已于 2026-10-18 删除，请求返回 `404`，只能用新地址。

整理的来由见 [任务与文件接口整理](../../ops/planning/api-reorg/20261015-任务与文件接口整理.md)。
全部接口的清单钉在 `backend/api/docs/routes.txt`。

| 类 | 前缀 | 回答什么问题 |
|---|---|---|
| 任务 | `/jobs`、`/jobs/{job_id}` | 有哪些任务、建一个、看一个、删一个 |
| 操作 | `/jobs/{job_id}/actions/…` | 能对它做什么、去做 |
| 进度 | `/jobs/{job_id}/progress/…` | 跑到哪了（运行中） |
| 文件 | `/jobs/{job_id}/files/…` | 产出了哪些文件、取一个，见 [下载总览](../07-产物下载/01-下载总览.md) |
| 报告 | `/jobs/{job_id}/reports/…` | 跑完结果怎么样 |
| 阅读 | `/jobs/{job_id}/reader/…` | 阅读页要的东西 |
| 译文 | `/jobs/{job_id}/translations/…` | 逐条看、人工改、重翻一条 |
| 数据 | `/jobs/{job_id}/data/…` | 通用查询，按名字取一张表 |

还没产出时（2026-10-19 定，见 [错误约定](../00-约定/02-认证与错误.md#还没产出404)）：

- 原始报告 `translation-qa`、`translation`、`layout-fit`、`refine`：`404` + `error.details.reason = "not_ready"`，
  提示分别是 `translation-qa report not ready`、`translation report not ready`、`layout-fit report not ready`、`refine report not ready`。
- 摘要 `quality`、`failure`：`200`，没有的段给 `null`；`usage` 没有用量时 `200` 空汇总。
- 任务不存在一律是普通 `404`，不带 `reason`。

2026-11-14 删了两个没人调用的：质量问题逐条清单 `reports/quality/items`（同样的数据用 `data/{dataset}` 取，比如 `qa_violations`）、单个任务的模型用量 `reports/usage`（2026-11-20 加回，见 [加回单个任务的用量](../../ops/planning/api-reorg/20261120-加回单个任务的用量.md)）。删前路由计数 10-18 以来都是 0 次，见 [第二批删接口](../../ops/planning/api-reorg/20261114-第二批删接口.md)。

## 阅读

| 方法 | 新地址 | 已删除的旧地址 | 说明 |
|---|---|---|---|
| GET | `/jobs/{job_id}/reader/regions` | 不变 | 阅读页区块位置 |
| GET | `/jobs/{job_id}/reader/metadata` | 不变 | 阅读页元信息 |
| GET | `/jobs/{job_id}/reader/markdown` | `/markdown/document` | 原文 Markdown 的 JSON 视图（图片链接已换成绝对地址） |

`reader/markdown` 在 Markdown 还没产出时返回 `404` + `reason: "not_ready"`（`markdown not ready`）；
`reader/regions`、`reader/metadata` 是摘要类，还没有时照旧 `200`（空 `items`、`source`/`translated` 为 `null`）。
只取一个区块的 `reader/regions/{item_id}`（2026-11-01 给 Studio 引用一段加的）2026-11-14 删了：Studio 不再接 RetainPDF，没有调用方了。
`reader/regions` 带 ETag（2026-11-03 起）：带着上次的 `If-None-Match` 来、内容没变回 `304`，见 [阅读接口](../12-阅读/01-阅读接口.md)。

## 数据

| 方法 | 地址 | 说明 |
|---|---|---|
| GET | `/jobs/{job_id}/data` | 有哪些数据表 |
| GET | `/jobs/{job_id}/data/{dataset}` | 按名字查一张表（字段、筛选、分组、分页） |

`data`、`reports/quality` 读任务的方式和其余读接口一致：认合并阅读的虚拟任务 id
（`merged-<文档>-<指纹>`，合并目录里没有的数据集 `available: false`，没有的报告给 null），
旧目录格式的任务返回 `409`。
任务还没有输出目录（排队中、还没开始跑）时，`data` 每个数据集 `available: false`、`data/{dataset}` 是空结果，
`reports/quality` 各段 `null`，都是 `200`（2026-10-19 以前是 `404 job has no output directory`）。
