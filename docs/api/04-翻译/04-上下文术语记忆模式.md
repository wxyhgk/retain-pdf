# 上下文、术语和记忆模式

这三个字段控制 prompt 注入范围，不应关闭最终质量兜底。

## context_mode

可选值：

- `needed`: 默认。只给不完整片段、续接段、图注等需要上下文的 item 注入前后文。
- `all`: 退回更重的全量邻居上下文行为。
- `off`: 不注入前后文。

## glossary_mode

可选值：

- `matched`: 默认。只注入当前 item 或 batch 命中的术语。
- `all`: 注入整张术语表。
- `off`: 不注入术语表。

## memory_mode

可选值：

- `matched`: 默认。只注入当前 item 或 batch 命中的文档记忆。
- `broad`: 注入更宽的文档级摘要。
- `off`: 关闭记忆注入。

## 质量兜底

这些选项只影响 prompt 预算。`should_translate=true` 的 item 不能因为这些选项变成空译文。空译、严重英文残留、占位符错误仍应进入修复链路。
