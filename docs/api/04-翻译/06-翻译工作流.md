# 翻译工作流

## book workflow

`workflow=book` 的主链：

```text
OCR child -> normalize -> translate -> render
```

Rust 会先准备 OCR 结果，再启动翻译阶段。翻译成功后继续渲染。

## translate workflow

`workflow=translate` 的主链：

```text
OCR child -> normalize -> translate
```

翻译完成后任务结束，不生成最终 PDF。

## 复用已有 OCR artifact

如果请求带 `source.artifact_job_id`，后端可以复用已有 OCR artifacts，直接准备翻译输入，不必重新 OCR。

## 翻译阶段输入

- `source_json`: normalized `document.v1.json`
- `source_pdf`: 源 PDF
- `layout_json`: provider layout/result JSON，可用于诊断或补充信息

## 翻译阶段输出

- translation manifest
- page translation payloads
- diagnostics
- debug index
- review artifact

渲染阶段只应消费翻译产物和 source PDF，不应回头读取 OCR provider 私有字段。
