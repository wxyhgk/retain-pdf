# 翻译事件

翻译事件通过统一 job events 暴露：

```http
GET /api/v1/jobs/{job_id}/events
```

## 常见 substage

- `translation_prepare`
- `domain_inference`
- `page_policies`
- `continuation_review`
- `translation_batches`
- `garbled_repair`
- `translation_review`

## 事件示例

```json
{
  "seq": 120,
  "display_stage": "translation",
  "stage": "translating",
  "substage": "translation_batches",
  "lane": "main",
  "event_type": "progress",
  "progress": {
    "unit": "batch",
    "current": 789,
    "total": 5216,
    "percent": 15.1
  },
  "stage_detail": "正在翻译第 789 / 5216 批"
}
```

## 前端规则

- 主翻译进度读 `display_stage=translation` 且 `lane=main`。
- `progress.unit` 可能是 `batch`、`page`、`item` 或 `step`，按返回值展示。
- `stage_detail` 只做人类文案。
- 后台渲染预热事件会是 `display_stage=render`、`lane=background`，不要覆盖翻译主状态。
