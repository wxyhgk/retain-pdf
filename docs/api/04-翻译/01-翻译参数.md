# 翻译参数

翻译参数位于创建任务请求的 `translation` 对象中。

## 常用字段

```json
{
  "translation": {
    "api_key": "secret",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-v4-flash",
    "workers": 100,
    "batch_size": 1,
    "mode": "sci",
    "math_mode": "direct_typst",
    "context_mode": "needed",
    "glossary_mode": "matched",
    "memory_mode": "matched"
  }
}
```

字段说明：

- `api_key`: 下游大模型 API key，响应不会回显。
- `base_url`: 下游模型 OpenAI-compatible base URL。
- `model`: 模型名。
- `workers`: 翻译并发。
- `batch_size`: 每个请求包含的翻译 item 数。
- `mode`: 翻译模式。
- `math_mode`: 公式处理模式，当前默认 `direct_typst`。
- `context_mode`: 上下文注入策略。
- `glossary_mode`: 术语注入策略。
- `memory_mode`: 翻译记忆注入策略。

## 前端规则

- 普通用户界面只展示模型、并发、术语表等核心选项。
- `context_mode`、`glossary_mode`、`memory_mode` 更适合作为高级选项。
- 不要把 `api_key` 存进可见日志或事件。
