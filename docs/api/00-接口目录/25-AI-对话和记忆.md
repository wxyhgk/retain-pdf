# AI：阅读页提问的主对话、副对话和记忆

16 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/ai/ask-settings` | closed | library | agent | 阅读页提问的设置（「让 AI 使用记忆」总开关）；自带 agent 每次调记忆工具前看一眼 |  | `ask_conversations::get_settings_route` |
| PATCH | `/ai/ask-settings` | closed | library | none | 改阅读页提问的设置 |  | `ask_conversations::patch_settings_route` |
| POST | `/ai/ask-conversations/main` | closed | library | none | 取或建当前的全局主对话（同一时间只有一个开着的） |  | `ask_conversations::ensure_main_conversation_route` |
| GET | `/ai/ask-conversations` | closed | library | none | 列对话（主对话、副对话，可按种类、状态、主对话筛） |  | `ask_conversations::list_conversations_route` |
| POST | `/ai/ask-conversations` | closed | library | none | 从主对话的某条消息开一个副对话 |  | `ask_conversations::create_side_conversation_route` |
| GET | `/ai/ask-conversations/:conversation_id` | closed | library | none | 一个对话 |  | `ask_conversations::get_conversation_route` |
| PATCH | `/ai/ask-conversations/:conversation_id` | closed | library | none | 改对话：标题、归档主对话、再开副对话 |  | `ask_conversations::patch_conversation_route` |
| DELETE | `/ai/ask-conversations/:conversation_id` | closed | library | none | 删对话（连同消息和它的副对话；记忆留着）；开着的主对话不能删，先归档 |  | `ask_conversations::delete_conversation_route` |
| POST | `/ai/ask-conversations/:conversation_id/close` | closed | library | none | 结束副对话：给了结论就回填到主对话（一张摘要卡片） |  | `ask_conversations::close_conversation_route` |
| GET | `/ai/ask-conversations/:conversation_id/messages` | closed | library | none | 对话的消息（按 seq 往前翻页） |  | `ask_conversations::list_messages_route` |
| POST | `/ai/ask-conversations/:conversation_id/messages` | closed | library | none | 追加一轮（问和答一起，每条带结构化出处；只追加不覆盖） |  | `ask_conversations::append_messages_route` |
| GET | `/ai/ask-conversations/:conversation_id/context` | closed | library | agent | 开新会话用的上下文：用户层和当前书的记忆、最近几轮、拼好的文字 |  | `ask_conversations::context_route` |
| GET | `/ai/memories` | closed | library | agent | 记忆：列、全文检索（按层、书、状态筛） |  | `ask_conversations::list_memories_route` |
| POST | `/ai/memories` | closed | library | agent | 记一条记忆（用户自己加，或 agent 的 remember；可以替代旧的一条） |  | `ask_conversations::create_memory_route` |
| PATCH | `/ai/memories/:memory_id` | closed | library | none | 改一条记忆 |  | `ask_conversations::patch_memory_route` |
| DELETE | `/ai/memories/:memory_id` | closed | library | none | 删（撤销）一条记忆：标 deleted，被它替代的旧条恢复 |  | `ask_conversations::delete_memory_route` |
