9 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/usage` | signed | jobs | web | 全部模型用量 |  | `token_usage::all_usage_route` |
| GET | `/documents/:document_id/usage` | signed | jobs | web | 一本书的模型用量 |  | `token_usage::document_usage_route` |
| POST | `/usage/prices` | signed | jobs | none | 按接口地址和模型批量查单价 |  | `token_usage::price_lookup_route` |
| GET | `/usage/estimate` | signed | jobs | none | 按书库每页平均估一本还没翻译的书 |  | `token_usage::library_usage_estimate_route` |
| GET | `/documents/:document_id/usage/estimate` | signed | jobs | web | 这本书换个模型重新翻译大概多少钱 |  | `token_usage::document_usage_estimate_route` |
| GET | `/backups` | admin | platform | web、cli | 备份列表 |  | `backups::list_backups_route` |
| POST | `/backups` | admin | platform | web、cli | 马上备份一次 |  | `backups::create_backup_route` |
| DELETE | `/backups/:backup_id` | admin | platform | web、cli | 删除一个备份 |  | `backups::delete_backup_route` |
| POST | `/backups/:backup_id/restore` | admin | platform | web、cli | 从备份恢复 |  | `backups::restore_backup_route` |
