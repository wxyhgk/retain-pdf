7 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/jobs/:job_id/actions` | signed | jobs | web | 现在能做哪些操作（每个阶段能不能重试、重试的请求怎么写） |  | `actions::get_stage_actions` |
| GET | `/jobs/:job_id/actions/resume` | signed | jobs | web | 续跑会从哪里开始 |  | `actions::get_resume_plan` |
| POST | `/jobs/:job_id/actions/resume` | signed | jobs | web | 从断点续跑 | `/jobs/:job_id/actions/rerun`（旧名，和续跑是同一个处理函数） | `actions::resume_job` |
| POST | `/jobs/:job_id/actions/cancel` | signed | jobs | web | 取消任务 |  | `actions::cancel_job` |
| POST | `/jobs/:job_id/actions/retry-stage` | signed | jobs | web | 重试某一个阶段（OCR、翻译、渲染、精修） |  | `actions::retry_stage` |
| POST | `/jobs/:job_id/actions/resolve-ocr-ambiguity` | signed | jobs | web | OCR 拿不准时由用户选 |  | `actions::resolve_ocr_ambiguity` |
