4 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/sync` | admin | platform | web、cli | 同步设置和上次同步的结果 |  | `sync::get_sync_route` |
| PUT | `/sync` | admin | platform | web、cli | 保存同步设置 |  | `sync::update_sync_route` |
| POST | `/sync/run` | admin | platform | web、cli | 马上同步一次 |  | `sync::run_sync_route` |
| POST | `/sync/test` | admin | platform | web、cli | 测试同步文件夹能不能用 |  | `sync::test_sync_route` |
