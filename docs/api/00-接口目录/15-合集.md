6 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| POST | `/collections` | signed | library | web | 新建合集 |  | `collections::create_collection_route` |
| GET | `/collections` | signed | library | web | 合集列表 |  | `collections::list_collections_route` |
| PATCH | `/collections/:collection_id` | signed | library | web | 改合集（名字、排序） |  | `collections::patch_collection_route` |
| DELETE | `/collections/:collection_id` | signed | library | web | 删除合集 |  | `collections::delete_collection_route` |
| POST | `/collections/:collection_id/documents` | signed | library | web | 往合集里加书 |  | `collections::add_collection_documents_route` |
| DELETE | `/collections/:collection_id/documents/:document_id` | signed | library | web | 从合集里拿掉一本书 |  | `collections::remove_collection_document_route` |
