8 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/jobs/:job_id/reader/regions` | signed | jobs | web、agent | 阅读页的区块位置（原文块和译文的对应）；阅读页提问的自带 agent 也从这里读书 |  | `reader::get_reader_regions` |
| GET | `/jobs/:job_id/reader/metadata` | signed | jobs | web | 阅读页的元信息（原文、译文 PDF 的页数和页面尺寸） |  | `reader::get_reader_metadata` |
| GET | `/jobs/:job_id/reader/layout` | signed | jobs | web | rpr_fit 排的版面清单（HTML 页照它画；没有时 available: false 和补排的请求） |  | `reader::get_reader_layout` |
| GET | `/jobs/:job_id/reader/layout/pages/:page_idx` | signed | jobs | web | 一页版面（rpr_layout_v1 的一页：covers、blocks），带 ETag |  | `reader::get_reader_layout_page` |
| GET | `/jobs/:job_id/reader/layout/background` | signed | jobs | web | 版面的底图 PDF（去掉原字的原文页，只含有版面的页；扫描件没有） |  | `reader::get_reader_layout_background` |
| GET | `/jobs/:job_id/reader/layout/fonts/:name` | signed | jobs | web | 版面用的字体子集（woff2，按书切），清单 fonts[].url 指着它 |  | `reader::get_reader_layout_font` |
| GET | `/jobs/:job_id/reader/layout/math/:name` | signed | jobs | web | 版面里公式的 MathJax SVG，版面公式项的 svg 指着它 |  | `reader::get_reader_layout_math` |
| GET | `/jobs/:job_id/reader/markdown` | signed | jobs | web | 原文 Markdown 的 JSON 视图（图片链接已换成绝对地址） |  | `reader::get_markdown_document` |
