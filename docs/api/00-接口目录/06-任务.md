4 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| POST | `/jobs` | signed | jobs | web | 新建任务（翻译、只做 OCR、重新渲染……，按请求里的 workflow 分） |  | `lifecycle::create_job` |
| GET | `/jobs` | signed | jobs | web | 任务列表 |  | `lifecycle::list_jobs` |
| GET | `/jobs/:job_id` | signed | jobs | web | 任务详情：状态、进度、产物链接、能做的操作 |  | `lifecycle::get_job` |
| DELETE | `/jobs/:job_id` | signed | jobs | web | 删一个任务和它的 OCR 子任务，书留着（OCR 任务也能删；运行中要 force，被别的任务用着 409） |  | `lifecycle::delete_job` |
