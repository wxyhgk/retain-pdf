8 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/providers/ocr` | signed | providers | none | 能用的 OCR 服务商 |  | `providers::list_ocr_providers` |
| GET | `/providers/error-codes` | signed | providers | web | 各家 OCR、翻译模型服务商的错误码目录（含义、给用户的提示、我们怎么处理），可按种类、厂商、码、HTTP 状态筛 |  | `providers::list_provider_error_codes` |
| POST | `/providers/mineru/validate-token` | admin | providers | web、cli | 校验 MinerU 的 token |  | `providers::validate_mineru_token` |
| POST | `/providers/paddle/validate-token` | admin | providers | web、cli | 校验 Paddle 的 token |  | `providers::validate_paddle_token` |
| POST | `/providers/deepseek/validate-token` | admin | providers | web、cli | 校验 DeepSeek 的 API 密钥 |  | `providers::validate_deepseek_token` |
| POST | `/providers/deepseek/balance` | admin | providers | web、cli | 查 DeepSeek 余额 |  | `providers::query_deepseek_balance` |
| POST | `/providers/translation/models` | admin | providers | web | 从翻译接口拉取模型列表 |  | `providers::list_translation_models` |
| POST | `/providers/translation/ask` | admin | providers | none | 用翻译接口的配置问一次模型，可以带图片 |  | `providers::ask_translation_model` |
