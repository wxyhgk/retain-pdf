# 登录和健康检查（不需要登录）

5 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/health` | public | platform | desktop、cli、ops | 进程活着（不要密钥） |  | `health::health` |
| GET | `/ready` | public | platform | cli、ops | 能接请求了（库能用；受监督的 AI 服务、jobsd 也就绪）。不就绪 503，看 HTTP 状态码（不要密钥） |  | `health::ready` |
| GET | `/auth/session` | public | accounts | web | 现在是什么模式、登没登录（前端据此决定显示不显示登录页） |  | `accounts::session_route` |
| POST | `/auth/login` | public | accounts | multiuser | 登录 |  | `accounts::login_route` |
| POST | `/auth/register` | public | accounts | multiuser | 注册 |  | `accounts::register_route` |
