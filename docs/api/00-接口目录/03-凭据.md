|---|---|---|---|---|---|---|---|
| GET | `/credentials` | admin | providers | web | 凭据列表（不含明文） |  | `credentials::list_credentials_route` |
| POST | `/credentials` | admin | providers | web | 新建凭据 |  | `credentials::create_credential_route` |

| DELETE | `/credentials/:credential_ref` | admin | providers | web | 删除凭据 |  | `credentials::delete_credential_route` |
