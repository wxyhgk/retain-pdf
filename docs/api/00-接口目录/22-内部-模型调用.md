| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| POST | `/internal/model/jobs/:job_id/requests` | closed | providers | worker | 工作进程提交一次模型调用（凭能力令牌，返回不带信封） |  | `model_requests::submit` |
| GET | `/internal/model/jobs/:job_id/requests/:operation_id` | closed | providers | worker | 一次模型调用的状态和结果（返回不带信封） |  | `model_requests::status` |
| POST | `/internal/model/jobs/:job_id/requests/:operation_id/cancel` | closed | providers | worker | 取消一次模型调用（返回不带信封） |  | `model_requests::cancel` |
