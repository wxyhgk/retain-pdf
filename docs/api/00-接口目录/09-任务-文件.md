4 个接口。属于[接口目录](../00-接口目录.md)；「谁能用」「负责」「谁在用」的取值见那里。地址前缀省略了 `/api/v1`。

| 方法 | 地址 | 谁能用 | 负责 | 谁在用 | 说明 | 旧地址 | 处理函数 |
|---|---|---|---|---|---|---|---|
| GET | `/jobs/:job_id/files` | signed | jobs | web | 文件清单：按 output、pages、internal 三组列出这个任务的文件 |  | `files::list_job_files` |
| GET | `/jobs/:job_id/files/output/*name` | signed | jobs | web | 取一个成品：translated.pdf、side-by-side.pdf、translated.docx、ocr.md、ocr.zip、ocr/images/…、all.zip |  | `files::job_output_file` |
| GET | `/jobs/:job_id/files/pages/:page` | signed | jobs | agent | 译文某一页的预览图（pages/3.jpg） |  | `files::job_page_file` |
| GET | `/jobs/:job_id/files/internal/*name` | admin | jobs | ops | 取一个中间产物（规范化文档、翻译清单、请求日志……），多用户下只给管理员 |  | `files::job_internal_file` |
