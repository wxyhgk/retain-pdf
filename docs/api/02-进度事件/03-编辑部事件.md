# 编辑部事件（翻译 agent）

翻译引擎选翻译 agent（`translation.engine=agent`）的任务，调度一边翻一边写"编辑部"事件：通读、每页翻译、质检、重翻、
退回原文、审校、术语表变动、歧义单、停下、完成。前端书详情「进度」面板的编辑部画面只从这些事件来。
现有流程（legacy）的任务没有编辑部事件。2026-10-30 加。

契约：`contracts/job-events.v2.schema.json`（`listEditorialEvents`，类型 `EditorialEventsQuery`、`EditorialEventListView`、`EditorialEvent`）。

## 接口

```http
GET /api/v1/jobs/{job_id}/progress/editorial?after=0&limit=500
```

| 参数 | 说明 |
|---|---|
| `after` | 跳过前面这么多条，就是上次返回的 `next_after`；不带是从头取 |
| `limit` | 一次最多几条，默认 500，夹到 1..2000 |

别的参数 400。任务不存在 404。多用户模式下和任务的其它读接口一样（`signed`）。

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "events": [
      { "v": "editorial.v1", "ts": 1761800000.123, "type": "run_started", "pages": 34, "model": "claude-haiku-5-5", "doc_title": "Molecular Orbital Theory", "resumed": 0 },
      { "v": "editorial.v1", "ts": 1761800001.456, "type": "reading_started" }
    ],
    "next_after": 2,
    "has_more": false
  }
}
```

- `events`：事件原样，按写入顺序。
- `next_after`：下次带 `after=` 这个数接着取，就是到这一段为止读过的条数。比请求的 `after` 还小，说明事件文件重开了
  （换了文档或引擎版本，状态清掉重跑），从 `after=0` 重新取。
- `has_more`：这次只给到 `limit` 条，后面还有，马上再取一次。

没有事件（legacy 任务、agent 任务还没开翻）时 `events` 是空数组、`next_after` 是 0。

**怎么用：** 任务进行中每隔几秒带上次的 `next_after` 轮询；翻完以后从 0 取一遍全量回放。正在写的最后一行要是还没写完，
这次不给，下次再给。

**哪些任务有：** 翻译覆盖 `GET /api/v1/documents/{document_id}/translation-coverage` 的每个任务（`CoverageJobView`）有
`engine`（`legacy` / `agent`）和 `has_editorial_events`（有事件可看）。

## 事件

每条都有 `v`（`editorial.v1`）、`ts`（Unix 秒，带小数）、`type`。格式只加不改：不认识的 `type`、多出来的字段忽略。
`page` 是这次跑的第几页（1 起），通读时是 0；`label` 是页码标签。续跑（额度用完后重试）接着往后写，会再有一条 `run_started`
（`resumed` 是已经做完的页数），已经做完的页不再出现。

| type | 字段 |
|---|---|
| `run_started` | `pages`、`model`、`doc_title`（文档里标题块的原文，没有是空串）、`resumed` |
| `reading_started` / `reading_done` | — / `genre`、`name_policy`、`terms`、`headings` |
| `page_started` | `page`、`label`、`blocks`（要翻的块数） |
| `translate_call` | `page`、`attempt`、`blocks`（块 id 列表）、`role`（translator / reviewer / reviser / reader） |
| `check_result` | `page`、`attempt`、`ok`、`warn`、`error`（整页各几块）、`codes`（问题代码 → 次数） |
| `retry` | `page`、`blocks`（要重翻的块 id） |
| `fallback` | `page`、`block`、`reason`（第一个不合格的问题代码） |
| `review_started` / `review_done` | `page`、`blocks` / `page`、`tickets`、`applied`、`rejected` |
| `glossary_changed` | `version`、`action`（add / promote / revise / widen / candidate）、`source`、`target` |
| `ticket_opened` | `term`、`current`、`proposed`、`page` |
| `page_done` | `page`、`statuses`（`ok`、`warn`、`error`、`fallback_source` 总在） |
| `run_stopped` | `reason`（quota_exhausted / auth_failed / rate_limited），可以接着跑 |
| `run_done` | `pages`、`glossary_version`、`tickets` |

`genre`、`name_policy`、`codes` 的取值全集见 [编辑部可视化和事件格式](../../ops/planning/translation-agent/20261030-编辑部可视化和事件格式.md)。

事件文件在任务目录的 `translated/agent/run/events.jsonl`，由翻译 agent 包的调度（`DocumentRun`）写。
