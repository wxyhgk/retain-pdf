# 加回单个任务的用量

2026-11-20。

## 起因

《The Interloper》任务 `20261120000035-8c802a` 的进度页顶上写「1040.2 万 token、约 ¥15.58」，重新翻译里 Haiku 的估价却是「约 ¥0.96–1.01」，
看起来估价低了十几倍。查下来估价是对的，进度页的数不是这一次的：

| 进度页的数 | 实际是 |
|---|---|
| 1040.2 万 / ¥15.58 | `GET /documents/{id}/usage`：这本书 10 个任务的合计（逐页版、qwen 对比、按节版……） |
| 翻译节点 999.5 万 | 10 个任务翻译组的合计 |
| 排版节点 40.7 万 | 以前几次精修的合计（精修组挂到了排版节点） |

这一次的台账只有 59 次请求、输入约 60 万、输出约 16 万 token，按 Haiku 5.5 约 $0.134（¥0.96），估价参照的正是它。

## 决定

- 加回 2026-11-14 [第二批删接口](./20261114-第二批删接口.md) 删掉的 `GET /jobs/:job_id/reports/usage`（`getJobUsage`），
  行为和删前一样（读法走 `load_supported_job`，库里没有、目录还在照样给），返回带上后来加的花费字段；契约 `scope` 加回 `job`。
- 进度页（一个任务）用它；书的合计留给概览，写明「全书累计」。前端要改的写在
  [后端改动交接](../../../core/frontend/backend-changes-handoff.md)。
- 当时删它的理由是「没有调用方」：界面只看书和全部。现在有了真实的调用方，加回不违背那次的原则。
