# 使用说明书

2026-11-23 用户提议给前端做一份使用说明书，同意了下面的做法。

## 定下来的

- **读者**：用软件的人，桌面版为主，Docker 网页版另开一节；不讲原理和接口。
- **位置**：Markdown 放在 `docs/guide/`，跟代码一起改，GitHub 上直接能看。以后要做网站再从这些文件生成。
- **分章**：按用户要做的事分，不按功能模块分：安装、填 Key、翻译第一本书、阅读、管理书库、术语表、用量和费用、
  同步和备份、局域网共享、常见问题。
- **截图**：`frontend/web/scripts/guide-screenshots.mjs` 用 mock 数据打开页面截图（`npm --prefix frontend/web run guide:screenshots`），
  隐藏 mock 提示条、冻结时钟，2 倍图存 JPEG（每张 100–200KB）。截不到真实的书和 Key，界面改了重跑。
- **语言**：先只写中文。三份 README 指向这份中文说明书。

## 分两步

1. 第 1–4 章（安装、填 Key、翻译第一本书、阅读）和第一批截图；顺手改掉 README 里过时的两处：
   「读书笔记与 AI」（Studio 11-06 起不归我们，RetainPDF 自己的 AI 11-03 删了）和 macOS「已损坏」要敲 `xattr`
   （安装包已签名公证）。旧截图 `ai-assistant.png` 没人引用了，删掉。
2. 其余各章；设置页每一项旁边加「?」跳到说明书对应一节；加一个测试：设置页每个分区在说明书里都要有一节。

## 还没解决的

- 阅读页的截图：mock 的 PDF 只有一行占位字，截出来看不出效果。要用仓库里 `tests/fixtures/pdfs/` 的公开论文真翻一遍，
  从本机后端截，第 2 步再定。
