# 说明书改成动画 + 图标

2026-11-23 用户：「教程里面文字太多了，我建议多用动画+图标这种」。先改三页试点（快速上手、添加 PDF、书的详情），用户看过预览后说「合并」。

## 定下来的

- **每页的样子**：页首一段自动循环的操作动画 → 三五行带图标的步骤 → 一张「想要 → 点哪里」的表 → 细节收进 `<details>`（默认收起）。
  从别处链到收起块里的标题时，说明书弹窗会先展开再滚过去。
- **动画**：`frontend/web/scripts/guide-media.mjs`（原 `guide-screenshots.mjs`，命令改成 `npm --prefix frontend/web run guide:media`）用 mock 数据录操作，
  画上鼠标和点击波纹，ffmpeg 抽帧（每秒 8 帧、880 宽），img2webp `-mixed` 拼成循环的动态 WebP，存 `guide/images/<模块>/<名字>.webp`。
  纯有损会把界面压出色块，`-mixed` 每帧自己挑；10 秒左右 250–550KB。`GUIDE_MEDIA_FRAMES=<目录>` 能把帧留下来逐帧看。
- **图标**：同一个脚本从 lucide-react（软件界面用的同一套）生成 `guide/icons/<名字>.svg`，灰色描边，深浅主题都看得见；正文用 Markdown 的图片写法引用
  icons 目录下的文件（例如 plus.svg），弹窗里排在文字行内，GitHub 上也能显示。
