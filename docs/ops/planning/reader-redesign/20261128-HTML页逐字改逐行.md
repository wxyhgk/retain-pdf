# HTML 页：逐字浮现改成逐行浮现

2026-11-28。用户：「html 排版速度特别慢啊，什么情况」。

## 量出来的

用渲染任务 `20261128081515-34869a`（照版面画）和 VP ≠ VNP（按 OCR 框画）在无头 Chromium 里量，1440×900。主线程长任务按 PerformanceObserver 记。

| 情况 | 滚 15 下用时 | 长任务合计 | 最长一次 |
|---|---|---|---|
| 照版面画，不开动效 | 6.0 秒 | 0.29 秒 | 0.06 秒 |
| 照版面画，缩放过 | 6.1 秒 | 0.19 秒 | 0.07 秒 |
| **照版面画，开逐字浮现** | **19.7 秒** | **12.8 秒** | **0.8 秒** |
| 按 OCR 框画 | 5.7–6.1 秒 | 0.38–0.64 秒 | 0.09 秒 |

- 打开 HTML 页：两种画法都是 0.65–0.73 秒出第一页，2.7–2.8 秒稳定，长任务合计 0.1–0.35 秒。
- 照版面画打开时请求 96 个：清单、两份字体、每页一个、每个公式一个 SVG。
- 慢的是**逐字浮现**：
  - 屏幕上同时有 1641 个动画（一个字一个）。SVG 的字合不了层，每帧整页两千个字重画。
  - 浮完的动画留着（`fill: both`），以后每次样式变化都要再算一遍。

## 改了什么

- **逐行浮现**：每行包一个 `<g class="reader-layout-line">`，一行一个动画（每行晚 70ms，一块最多 1.4 秒才开始，每行浮 520ms），一页几十个。
- **浮完撤掉**：滚进来标 `data-risen="run"`，算好放完的时间后改成 `"done"`，`done` 没有动画。
- 字上不再写 `--i`（两千个行内样式也省了）。菜单里的开关改叫「逐行浮现」。

改完同样滚 15 下：长任务合计 0.1 秒，最长 0.06 秒，屏幕上剩 2 个动画。

效果：一块滚进来 0.5 秒时第 0 行已经出来（不透明度 0.97），第 3 行一半（0.66），第 8 行还没出；0.9 秒时都出来；3.2 秒时 `done`。

## 还可以再省的（这次没做）

- 公式 SVG 一个一个取（一页十几到三十几个请求）。可以让后端按页给一个合并的，或前端按页批量取。
- 底图每页再画一次整页画布，缩放时跟着重画。现在量着不慢，大书、慢机器上再看。
