# 书页选字：清洗、锁栏、整个选公式、复制 · 收藏 · 提问

2026-11-28。用户一次说了几条：

> 对选区 copy 和提问取值做 PDF 断行 / 连字符清洗；
> 对照模式按下拖选时锁定当前栏（防左右串栏）+ 把 ::selection 颜色从黄色 --warn 换成浅冷色；
> 取消开着 AI 时 selectionchange 自动偷塞出处，并在划词右键 / 轻浮条里补齐「复制 + 收藏 + 提问」闭环。
> 尤其是行内公式的选择显示得做好。
> （截图：「VNP ⊈ VP」整块一个色块）类似这样可以真正的选中公式。

这推翻了 11-20 起「书页上选字只留浏览器自己的复制、不弹东西」的做法（那时否掉过选字弹「问 AI」）。
它也推翻了 11-27「提问窗开着时选字带进下一问」的做法。

## 先查到的

拿用户截图里那篇论文（本地有，VP ≠ VNP Over Every Field）在真页面上看：

- pdf.js 文字层给的公式字：
  - `PERM` + `𝑚`（数学字母区 U+1D45A）；
  - `VNP`、`̸`（U+0338）、空格、`⊆`、空格、`VP`，否定号排在符号前面，中间还隔个空格；
  - 复制出来是 `VNP̸ ⊆ VP`。
- 后端给阅读页的块只到段落一级，没有行内公式的位置（OCR 的行内公式框没往前端送，后端不归这边改）。
  所以「整个选公式」只能从文字层认。
- **以前的黄色选区一直没生效**：
  - 阅读页还挂着 pdf.js 自带的 `pdf_viewer.css`，它不在任何 `@layer` 里，它的 `.textLayer ::selection`（系统强调色 25%）压过所有分层的样式，实际看到的一直是浅蓝；
  - 字框互相叠着，叠的地方深一块，公式里最明显（`̸`、空格、`⊆` 三段叠在一起）。

## 做了什么

**收拾选出来的字**：`shared/content/selection-text.ts` 的 `cleanPdfSelectionText`。

- 行尾断词：字母加连字符、下一行小写开头，去掉连字符接上；大写、数字开头的留着连字符。
- 其余换行接成一个空格，中日韩字两边不加；空一行是段落，留一个换行。
- 软连字符去掉；数学字母区、连字（ﬁ）逐字 NFKC，别的字不动，全角、中文标点不能跟着变。
- 否定号：排对了的先 NFC（`≠` → `≠`）；剩下排在前面的挪到后面那个符号上再合成，前面的字隔一个空格（`VNP̸ ⊆` → `VNP ⊈`）。
- 用在三处：
  - 复制：`copy` 事件里换掉剪贴板的字，⌘C 和浮条都走这里；
  - 提问取出处：`ask/anchor.ts` 的 `selectedPageText`；
  - 收藏。

**选字的那一层**：`ReaderSelectionLayer`，画在书页区里。

- **锁栏**：按下时根节点写 `data-select-pane`，另一栏的文字层 `user-select: none`（`selection.css`），松手去掉。
- **整个选公式**：`formulaRunAt`。
  - 一行里连着的几段，至少一段带数学符号（数学字母、希腊字母、运算符、箭头、上下标、组合符号），中间夹着的短段也算：空白，或 ≤ 6 个字、没有三个以上小写字母连成的词。
  - 松手时选区的头或尾落在这样一串里，就撑到整串。
  - 只有短段、没有数学符号的（正文里的「VP」）不算。
- **选区自己画**：
  - 文字层里浏览器那层用 `!important` 设成透明，要压过不分层的 `pdf_viewer.css`。
  - 选区里每个字框先裁到它那一栏露出来的范围，按行收成色带（`mergeSelectionRects`）。
  - 上下有一半以上重叠的算一行。行高按这一行里够高的框（≥ 最高的 75%）定，上下标的小框不把色带撑高。
  - 同一行隔两个行高以上的分开画（双栏）。只有空格的那几段不画。
  - 颜色是浅冷色 `rgba(64, 140, 230, 0.24)`；深色文档时亮一点。
- **浮条**：在书页上按下、松手后选着字才出，在选区第一行上面；顶上那 56px 放不下就放最后一行下面。
  - 按钮：复制 · 收藏 · 提问。
  - 提问是扩展的右键项里标了 `inSelectionBar`（浮条上写的字）的那一项，提问扩展的「问这段」写「提问」。
  - 滚动时跟着选区走；`Esc` 收起，选区还在。
- **右键**：选着书页上的字时，菜单最上面是「复制」「收藏这段」，后面是扩展的「问这段」「截一块问」。

**收藏**：`shared/state/reader-favorites.ts` 和 `use-reader-favorites`。

- 和书签同一个 scope，存在本机 localStorage。
- 新收的在前，同一页同一段不收两份，最多 500 条，每条最多 2000 字。
- 左下角的星（11-28 上午只有一句「还在做」）现在是列表：两行截断、灰的页码，点一条 `goToPage` 翻回去，悬停出 × 删掉。
- 星在收过东西时填实。

**提问**：去掉 `use-reader-ask` 里听 `selectionchange` 的那段，连同 11-27 的「换成这段 / 再加一段」（`contextOffer`）。

- 提问窗那边的 `AskContextOffer` 是 `@retainpdf/ask` 包的通用能力，留着，阅读页不再传。

## 量过的（VP ≠ VNP 那篇，1440×900）

- 从「VNP」中间拖到「⊆」中间，松手撑到 `VNP̸ ⊆ VP` 整串。
  - 画出来一条 62×18 的色带，整块盖住，包括 VP 上面的横线。
  - 浏览器那层量出来是透明（`getComputedStyle(span, "::selection")` 是 `rgba(0,0,0,0)`）。
- 复制：
  - 浮条的「复制」，剪贴板是 `VNP ⊈ VP`；
  - 跨行的 `metic cir-\ncuits; Valiant` 按 ⌘C，剪贴板是 `metic circuits; Valiant`。
- 收藏：存进本机，左下角星里列出「VNP ⊈ VP · p.2」。
- 右键：复制 ⌘C、收藏这段、问这段 ?、截一块问。
- 浮条的「提问」打开提问窗，出处是「第 2 页 · 1.1. Results · 选中 8 字」。
- 对照时从原文拖进译文栏：选区头尾都还在原文栏，松手后锁去掉。
- 页面没有报错。

## 没做到的

- pdf.js 有的字框比字宽：它按 PDF 里记的宽度把整段拉长，例如断词那行「cir-」的框比字多出 37px，色带跟着多出一截。
  浏览器自己画的选区也一样；文字层里拿不到每个字的边。
- 公式是从字形认的，`\mathrm` 这类和正文同字体的字只有夹在数学符号中间时才算进公式。
  要准，得后端把 OCR 的行内公式框送给阅读页。
