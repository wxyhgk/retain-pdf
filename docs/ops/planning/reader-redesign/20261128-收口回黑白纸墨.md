# 收口回黑白纸墨

2026-11-28。三行壳层做完后用户要求「先不要继续堆新功能」，按 4 点把现有界面收口回黑白纸墨极简风（对齐 classic.css 和原型
reader-prototype.html）。不加新功能，只收拾已有的。

## 1. 左栏默认收起

- 打开阅读页时左栏总是收着（`use-reader-finder.ts` 初始 `null`），上次钉住、开着也一样；点顶栏开关或 `⌘F` 才展开。
  钉没钉、上次看哪一页签照旧记在本机，展开时用。推翻 11-27「钉住时下次打开照旧开着」。
- 待处理角标（左栏开关上、页签上）从黄色 `--warn` 改成墨色小圆底、纸色字。
- 目录以后改成书页区左缘悬浮的 Minimap，这次没做。

## 2. 提问窗真正放进右边停靠栏

- `AskWindow` 加 `dockHost`：贴右边、宿主给了停靠栏时，用 `createPortal` 画进去（`dock-host.tsx` 的 `HostedDock`，铺满那一格，
  左边缘一条 6px 的线拖宽窄、松手记住），不再是 react-rnd 的 fixed 浮窗。阅读页把 `.reader-dock-body`（`api.panelHost`）给它，
  和 Markdown 共用一个容器；停靠栏放提问窗时宽度写在 `--reader-dock-width`（窄屏照旧铺满中间工作区）。去掉 `.reader-dock-spacer`。
- 没给 `dockHost` 的宿主照旧浮在右边（`dockInsets` 留着）。
- 去掉：贴右边时往左 32px 的投影；聊天区正中的彩色模型水印（`.ask-watermark`）；回答底部用量按钮上的彩色厂商标志
  （换成灰的图标，模型名进 title 和点开的小表）；所有厂商标志 `grayscale(1)`。
- 思考强度：以前染窗口边、四面发光、输入框底色、大片光晕、发送键；现在只给输入框一圈细边（`--ask-composer-edge`，28%），
  按钮上档位名灰字、前面一个 6px 的小色点。`--ask-composer-bg` / `-glow`、`--ask-send-*` 不再定（照搬组件里读它们的写法留着，没定时照原样）。

## 3. 顶栏按钮一套

- 删掉 chrome.css 里浮动胶囊时代的残留：下载、返回、面板按钮的 36px 高、描边、阴影、`backdrop-filter`、按下时缩放 / 阴影、
  面板开着时整颗填墨色。
- 返回、左栏开关、提问 / Markdown / 对比、下载、实时译文几颗：高 32px、同一种圆角（`--reader-chrome-radius`，8px）、透明底，
  悬停 6% 墨、按下 / 开着 10% 墨；字 12px、600。
- 皮肤变量 `--reader-chrome-press-transform`、`--reader-chrome-press-shadow` 没人用了，从登记表删掉。
- 书名照旧在顶栏左段（`.reader-workspace-title`）。

## 4. 底栏一个密度

- 「书签」带轻字（加了写「已加书签」），紧挨着「收藏」入口；「收藏」还没有功能，点开一张小卡说明还在做（用户要先留入口，
  推翻三行壳层那份「不画点了没反应的按钮」）。
- 底栏按钮一套：高 26、图标 14px、字 12px 500、图标和字一条基线；缩放的「−」「+」从文字换成图标。
- 底栏书签按钮类名改成 `.reader-bookmark-mark`：以前和左栏书签树的展开箭头同名（`.reader-bookmark-toggle`，22px 宽），
  加了字以后被挤成竖排。
