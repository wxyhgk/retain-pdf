# 顶栏、底栏做减法

2026-11-28。用户：「架已经对了，接下来只需要做减法、清多余图标、补齐对称感」，4 点。

## 1. 原文 / 对照 / 译文只写字

`ReaderWorkspaceTabs` 去掉三个页签字前面的图标（FileText、Columns2、Languages），左右各 14px。
窄屏以前退成只有图标，现在没有图标可退，只把两边收到 9px。

## 2. 顶栏右边收拢，对比版本挪走，补上书名

- 「对比版本」挪到中间胶囊里「对照」后面的一个 ▾（贡献表的新位置 `place: "compare"`，`ReaderWorkspaceTabs` 的 `compareExtra`），
  点了往下弹版本列表；只有一份译文时没有。选了一份照旧切到对照。用户给的两个去处（「放进对照模式下或并入二级菜单」）里选了前者：
  对比本来就是对照的一种看法，挨着「对照」最好找。
- 右边只剩「提问 / Markdown」包在一个浅灰胶囊里（边框、底色、圆角和中间页签胶囊一样，开着的那颗纸色底加淡阴影），
  最右边一个下载图标（去掉了旁边的 ▾，点了照旧弹出三种 PDF）。
- **书名没显示的原因**：后端任务详情（`GET /jobs/:id`）顶层没有书名，书名在 `book_summary.title`（书库里显示的名字）；
  前端 `pickDisplayTitle` 只读 `title`、`display_name`、`source_file_name`、`book_summary.source_file_name`，
  而 `source_file_name` 只有带上传记录的任务才有——重排版、续跑出来的任务顶栏没有书名。现在先读 `book_summary.title`
  （后端没有标题时填的是任务号，照旧被 `isJobIdLikeTitle` 滤掉）。演示模式本来就有书名，所以以前在演示里看不出来。

## 3. 底栏左右同密度

- 右边改成「● 画笔 ▾」「截图」「?」：画笔前面是当前笔色的小圆点（贡献表的新字段 `mark`，画在图标的位置），
  截图是 14px 的轻图标，两颗都带灰字（和左边「书签」「收藏」一套：高 26、图标 14、字 12 500）；
  快捷键说明从键盘方框图标换成一个轻的「?」字，前面那根竖线也去掉了。
- 窄屏（≤ 900）字收起，只剩圆点和图标。

## 4. 目录不再切书页左边

去掉 `toc-minimap.css` 里有目录时滚动容器 `left: 48px` 的硬切（上一步加的），短横线直接浮在整块阅读区背景的左边缘。
对照模式书页贴边时短横线会落在纸的左边空白上，用户要的就是这样。

## 量过的（演示模式 1440×900）

- 页签「原文」「对照」「译文」都没有图标；右边胶囊 1212–1386、高 36，里面「提问」「Markdown」；下载 1396–1428 单个图标。
- 底栏右边「画笔 截图 ?」，小圆点是红笔的 rgb(255, 59, 48)；书页滚动容器从 0 起满宽。
- 演示书只有一份译文，「对照」后面的 ▾ 不出现（组件测试里量过有两份时出现、点了弹版本列表）。
