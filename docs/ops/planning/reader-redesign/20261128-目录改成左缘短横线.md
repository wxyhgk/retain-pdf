# 目录改成书页区左缘的短横线

2026-11-28。「收口回黑白纸墨」那次只把左栏改成一进来收着，目录还在左栏里。用户：「目录部分还是不对啊……不是让你参考那个
html 吗」。参考的是原型 `reader-prototype.html`（「适配百页大书的左侧 Minimap 目录」，用户本机的设计稿，不在仓库里），这次照它做。

## 原型怎么做的，我们照搬了什么

- **短横线**（`ReaderTocMinimap`，`styles/toc-minimap.css`）：书页区左边 14px、竖着居中；章 16px、节 9px 长，2.5px 高，间隔 9px；
  当前节墨色、当前章深灰（36%）、别的淡灰（16%）。
- **大书不撑爆**：条目（章 + 节）超过 24 条时只画全部章 + 当前章的节。原型没管的情况我们补了：章本身就很多时隔几章画一根
  （当前章一定画），总数最多 28 根。
- **目录卡**：移上去（`:hover`）短横线淡出、出 268px 宽、最高 `min(480px, 72vh)` 的卡（条目 ≤ 15 条时高度随内容）；
  当前章展开、别的章收着（▸ / ▾），点一条时把它那一章留着展开（别让鼠标底下的行跳走），每次打开把当前节滚到中间；
  页码只在悬停和当前那一行出；超过 15 条顶上有过滤框（章名中了列整章，只有节中了列这一章和中了的节），光标在框里时卡片不收。
- **左栏**只剩「搜索」「待改」（原型的叫法，以前叫「待处理」），屏够宽时是实占的一栏（原型 248px），没有图钉；
  顶栏左边是「🔍 搜索」带待改几处的灰数字。

## 和原型不一样的地方

- 原型目录行悬停变蓝（`--rp-blue`），按「黑白纸墨」改成变墨色。
- 「书签」页签留在左栏：原型把书签并进底栏的「收藏」，收藏还没做，书签列表先没有别处放。
- 键盘：Tab 到短横线上也出卡片（`:has(:focus-visible)`；鼠标点了一条不算，移开就收）。
- 有目录时书页的滚动容器左边让出 48px（`.reader-stage:has(> .reader-toc-minimap)`），短横线落在书页外的空白里。
  原型书页本来就居中留白，我们对照模式下书页贴边，不让的话短横线压在纸上。

## 数据

`shared/content/reader-toc.ts`：有 PDF 书签用书签（只有一个书名根时拆开它，用下一层当章；更深的层级摊进所在的章，卡片里多缩进），
没有就用认出的标题（`readerOutline`，二级挂在前一个一级下）。去掉了以前左栏目录的「按 PDF 目录 / 按标题」切换和
`ReaderBookmarkTree`。眼下在哪一节和 `currentBookmark` 一个规矩（同一页取第一条，章和它的节同页标那一节）。

演示模式的段落数据补了四个节标题（和演示 PDF 四页的标题一样），不然演示时没有目录可看。

## 量过的（演示模式 1440×900）

- 打开时：4 根短横线在 14–46px，卡片透明；书页滚动容器从 48px 起，书页 60px 起。
- 移上去：卡片 268px 宽、124px 高（4 条，随内容），当前「1 跨语言阅读文档」带 p.1。
- 点「3 检查结果」：跳到 3 / 4，移开后第三根是墨色。
- 点「搜索」：左栏 0–248 实占，页签「搜索、书签」（演示书没有待改），书页区 248 起，短横线跟着到 262。
