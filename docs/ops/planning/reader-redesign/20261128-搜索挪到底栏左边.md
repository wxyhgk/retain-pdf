# 搜索挪到底栏左边、顶栏不再有「目录」（2026-11-28）

用户：「把顶部左侧的"目录","搜索"去掉,把搜索放在底部的左侧」。

## 做了什么

- 顶栏左边只剩返回（‹）和书名。
- **搜索**（`ReaderFinderToggles`：放大镜 + 待改的灰数字，打开左栏 搜索 / 书签 / 待改）挪到底栏最左边，书签、收藏前面。底栏加了一个口子 `ReaderZoomHud` 的 `startSlot`（左边最前面），阅读页把它放进去。样子照底栏按钮（26px 高、灰图标、悬停 / 按下墨色，`hud.css`）。`⌘F` 照旧。
- **目录**：顶栏的「目录」按钮（`ReaderTocToggle`）删掉，固定目录只用目录卡上的图钉（[目录可以固定成一栏](./20261128-目录可以固定成一栏.md)）。`hasToc` 只给那颗按钮用，一起删了。

## 现在的布局

```
顶栏    左：‹ 书名                       中：原文 | 对照 ▾ | 译文           右：空
中间    左缘：目录短横线（图钉固定成一栏）  正中：书页                      右缘：提问 / Markdown / 下载
底栏    左：搜索 书签 收藏                中：页码 深色 − 缩放 +             右：画笔 ▾ 截图 ?
```

## 验证

演示模式 1440×900：顶栏左边按钮只有「返回主页」；底栏左边 搜索 / 书签 / 收藏，都是 26px 高、图标 16px；点搜索左栏 0–248 打开、按钮按下；`⌘F` 也打开；无页面报错。
