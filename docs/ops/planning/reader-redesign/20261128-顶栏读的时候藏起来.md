# 顶栏读的时候藏起来

2026-11-28。顶栏刚改成[悬浮的两颗胶囊](./20261128-顶栏改成悬浮.md)，用户接着说：「停留的时候，不应该显示顶部的三个按钮，我觉得这样心流更强，你觉得呢？」
我赞成，并给了做法；问到返回 ‹ 要不要一起藏，用户答「要一起藏」。做的过程中用户又说「滚动的时候得出现这些按钮，不然用户可能看不到」，
所以滚动书页时也让它们出来。

## 什么时候露、什么时候藏

- **鼠标到书页区顶上 72px 以内才出来**（`TOPBAR_REVEAL_ZONE_PX`）。只在书页上动鼠标（悬停段落、选字）不会出来，否则读书时会一闪一闪。
- **滚动书页时也出来**，停下 1.5 秒后淡掉。不分往上还是往下滚，跳页、目录跳转这类代码触发的滚动也算。
- **离开那一条，或移出书页区，1.5 秒后淡掉**（`TOPBAR_HIDE_DELAY_MS`，淡出 180ms）。刚打开先露 2 秒（`TOPBAR_FIRST_SHOW_MS`），让人知道它在哪。
- **换模式时闪出来 1.2 秒**（`TOPBAR_FLASH_MS`），按 `1` `2` `3` 时看得到切到了哪个。
- **返回和页签一起藏**，一起出来。
- **这几种不藏**：
  - 正在翻译或刚翻完，页签旁边的那一组挂着（进度要看得到）；
  - 「对照」▾ 开着；
  - 用 `Tab` 键走到上面；
  - 触屏设备（`@media (hover: hover)` 以外的不藏，那里没有悬停，藏了就出不来）。
- 书页顶上照旧让出 56px（`--reader-float-bar-room`），出来、藏起时书页不会上下跳。

## 怎么做的

- `src/components/react-pdf/use-topbar-reveal.ts`：
  - 在书页区（顶栏的父元素）上听 `pointermove` / `pointerleave`，算是否到了顶上那一条。
  - `scroll` 不冒泡，所以在书页区上用捕获阶段听；每次滚动都重新计 1.5 秒。
  - 书页区的顶只在进来和窗口改大小时量，不在每次移动时量（WebKit 每量一次就整页重新排版）。
  - 结果写到顶栏的 `data-revealed` 上。
- `chrome.css`：在 `(hover: hover)` 下，`data-revealed="false"` 且没有 `.reader-bar-tools-popup`（▾ 的菜单只在开着时有）、`.reader-live-strip` 时，两颗胶囊 `opacity: 0; pointer-events: none`。
  - 按钮还在 `Tab` 顺序里。
  - 系统设了「减少动态效果」时不做淡入淡出。
- **键盘焦点不用 CSS 的 `:has(:focus-visible)` 判断**：
  - 用鼠标点过页签再按 `1` `2` `3`，浏览器会把那颗按钮改算成 `:focus-visible`，顶栏就一直挂着。
  - 实测，收起时现查 `:focus-visible` 也会卡住。
  - 改成在 `focusin` 那一下记住焦点是不是键盘带进来的；在顶栏上按下鼠标就清掉这个记号。

## 量过的（演示模式 1440×900）

| 情况 | 结果 |
|---|---|
| 刚打开 / 2.6 秒后 | 露着 / 两颗都淡掉、不接点击 |
| 鼠标在书页中间从 500 移到 300 | 不出来 |
| 鼠标移到顶上 30 | 出来；停 2.5 秒仍露着 |
| 移回 400：0.7 秒 / 1.9 秒 | 露着 / 淡掉 |
| 按 `1` | 闪出来，1.65 秒后淡掉，模式切到原文 |
| 点「对照」、移开，再按 `3` | 1.7 秒后淡掉（不卡住） |
| `Tab` 走到顶栏 | 出来；焦点停在上面 2 秒仍露着 |
| 页签旁挂上进度那一组 | 藏着时立刻显示；拿掉后又藏 |
| 390 宽触屏 | 一直显示 |
