# 顶栏改成悬浮

2026-11-28 下午。用户：「我的想法是顶部的 bar 不要保留了，用悬浮的方式，你觉得呢？这样我感觉更有沉浸感」。
我赞成，并提出了做法，用户回「可以，按照你说的来搞」。做的过程中用户又说「左侧的返回按钮不要给书籍的标题啊」，
左上那颗只放返回，书名不画了（`.reader-workspace-title` 删掉）。

## 为什么现在可以浮

上午的[三行壳层](./20261128-三行壳层.md)把顶栏改成实占一行，是因为那时浮着的东西太多（顶栏、左右两组按钮、右下角小球），
互相遮挡，还要靠 `--reader-stage-*` 计算谁给谁让位。几轮减法以后，顶栏只剩两组：左边是返回和书名，中间是原文 / 对照 / 译文，右段是空的。
为这两组占一整行 54px 不划算。

## 做法

- **浮在书页区里，不浮在整个窗口上**：`ReaderWorkspaceTabs` 从根节点挪进 `.reader-stage`，和右缘竖条一样。
  左边固定的目录、搜索栏和右边停靠栏都不会被盖住；页签相对书页区居中，不用算偏移。
- **两颗胶囊**：`.reader-workspace-bar` 改成 absolute（top 8、左右 12），这一层透明，`pointer-events: none`，书页照常能点、能选字；
  只有左上胶囊 `.reader-workspace-start`（只有返回，40×40，纸色底、细边，和竖条一个样子）和正上方页签 `.reader-workspace-center` 接点击。
  页签胶囊换成纸色底。两颗高都是 40。三段写死在哪一列：左上那颗不渲染时，页签也不会跑到第一列。
- **一直显示，不自动收起**：模式页签用得多；上午也因为不好用删掉过底栏的自动收起。
- **书页让出顶上**：根节点 `--reader-float-bar-room: 56px`（8 + 40 + 8）。第一页上方的留白（`.reader-react-pdf-wrap` 的 padding-top）
  和源栏右上角的「译文」叠加开关（`.reader-react-pdf-pane-action` 的 top）都用这个数。对照时这个开关正好在书页区正中，会压在页签底下。
  阅读线 `READER_SCROLL_FOCUS_PX` 从 48 改成 56，跳到某一页时页顶停在胶囊下面 8px，和第一页一样。
- **叠放**：z-index 29，比右缘竖条（30）低一档；窄屏（< 900）停靠栏铺满中间工作区（30）时盖住它们，不会压在 Markdown 的页签上。
- **实时译文那一组**：照旧挂在页签右边；窄屏（≤ 720）改成挂在页签下面（以前 fixed 在顶栏下面）。
- `shell-metrics.ts` 去掉 `READER_TOPBAR_HEIGHT`，`READER_DOCK_INSETS.top` 改成 0，提问窗贴右边时上面不用让；CSS 去掉 `--reader-topbar-h`。
- 皮肤变量 `--reader-chrome-bar-shadow` 从「整条顶栏的底部阴影」改成「两颗胶囊的阴影」，兜底值是淡影。
- `ReaderWorkspaceTabs` 去掉没人用的 `end`，右段只是一个占位的空元素，让页签居中。
