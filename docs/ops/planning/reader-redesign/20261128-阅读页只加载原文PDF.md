# 阅读页只加载原文 PDF

2026-11-28。HTML 页照排版引擎的版面画通了以后，用户：「我觉得还有一个好处就是我们只需要加载一个 pdf 了！」

## 现在下载几份

照版面画时，阅读页同时下载三份 PDF。拿 JACS 那本（渲染任务 `20261128084736-08ff64`）算：

| 文件 | 大小 | 用来做什么 |
|---|---|---|
| 原文 PDF | 约 6.5 MB | 原文那一栏、HTML 页的底（没有底图时） |
| 译文 PDF（`rendered/*-translated.pdf`） | 7.0 MB | 译文那一栏 |
| 底图（`rendered/reader-layout/background.pdf`） | 6.5 MB | HTML 页的底 |

合计约 20 MB。译文那一栏也改成「原文页 + 版面」画，就只剩原文这一份，约三分之一；打开快，内存里也少两份 PDF。

译文 PDF 照旧生成，下载、打印、导出还用它，只是看书时不下载。

## 要做的

### 1. 后端：版面里写明「要抹掉的原字」，不再需要底图

- 底图和原文页的差别，是渲染前在去字 PDF 里抹掉的原文（`source-bbox-text-stripped`），例如英文小标题「INTRODUCTION」「COMPUTATIONAL METHODS」。它们不在 `covers` 里，现在只有底图有这个信息。
- 请在版面每页里把这些位置也给出来：可以并进 `covers`（带估的底色），也可以另起一个字段，例如 `erase: [{ rect, fill }]`。只加字段，旧的不动。
- 前端拿原文页做底、先画这些框、再画 `covers` 和字，就和译文 PDF 一样。
- 代价：盖的是估的底色。彩色、渐变底上没有真抹掉干净，白底的书看不出。前端会保留「有底图就用底图」这条路；以后要不要停止生成底图，后端看着办。

### 2. 后端：表格放进版面

- 表格译文是 `rpr-table` 在正文排完以后另一遍叠到 PDF 上的，不在 `layout.json` 里（后端 2026-11-28 回话）。
- 不放进来的话，译文那一栏的表格会是原文表格。
- 请把表格排出来的结果也写进版面：盖原表的框，加每个单元格的字簇（和正文一样 `x / baseline / font`）。表格线如果是新画的，也一并给出（例如 `rules: [{ x0, y0, x1, y1, width, color }]`）。字段名后端定，写进 `docs/api/12-阅读`。

### 3. 前端：译文那一栏改成 HTML

- 「译文」「对照」两种模式下，书有完整版面时：
  - 右边那一栏不再加载译文 PDF，改成原文 PDF 的页加版面（底：原文页 + 要抹掉的框，再画 `covers`、字、表格、公式）。
  - 只下载一份原文 PDF，两栏都用它。
- 没有版面的书（Typst 路线、双栏对照、字体不是思源宋体、合并阅读、后端还在补的）照旧加载译文 PDF。
- 选字、搜索、悬停框、改译文这些现在按 pdf.js 文字层做的功能，在 HTML 页上都要接上：选字已经接了，搜索、悬停框要跟着改。
- 验收：
  - 同一本书，HTML 那一栏和译文 PDF 逐像素对比，差别只在字边；
  - 网络面板里只有一份 PDF；
  - 打开时间和内存比现在少。

## 顺序

1. 后端做第 1、2 条（只加字段），做完告诉前端会话。
2. 前端做第 3 条，先在开发栈上对 JACS 那本和一本带表格的书逐像素比，再切成默认。
