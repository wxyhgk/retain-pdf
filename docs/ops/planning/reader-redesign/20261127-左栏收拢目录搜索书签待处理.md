# 左栏：收拢目录、搜索、书签、待处理

2026-11-27。重新设计阅读页外壳的第二步，接着[书页区和右边一个停靠位](./20261127-书页区和右边一个停靠位.md)。用户说「继续干，要做」。

## 为什么

「按某种线索在书里跳」的东西散在四处：左上角「目录」（点开一张浮卡）、底栏「搜索」（点开同一张卡，从底栏往上弹）、
底栏「书签」（加书签一颗，旁边一颗弹出列表）、底栏「⚠ N 待处理」（又一个弹出框）。底栏塞了七组控件。

## 和以前的决定怎么对上

11-20 用户说「点击『目录』最好是悬浮的」，目录、搜索从挤开书页的左栏改成了浮卡（`feat/reader-toc-float`）。
这次不推翻：**默认照旧浮着**（点卡外、Esc、在目录或书签里点一条都收起）；栏头多一颗**图钉**，钉住才是左边一整栏、书页区让位。
钉不钉由用户选，记在本机。

## 做了什么

- **一个左栏，四个页签**：目录、搜索、书签、待处理（`ReaderFinder`，沿用原来的组件和类名）。待处理没有就不出这个页签，开着时没了退回目录。
  目录里原来的「按书签 / 按标题」改叫「按 PDF 目录 / 按标题」，不和新的「书签」页签撞名。
- **入口**：顶栏左边那一颗开 / 收左栏（开的是上次那一页签），待处理有几处时角上带个数；`⌘F` 打开搜索页签。底栏的搜索按钮去掉。
- **钉住**（`data-pinned`）：顶栏以下到窗口底一整栏，宽 `--reader-sidebar-width`（300px）；根节点 `is-sidebar-pinned`，
  书页区让出 `--reader-stage-left`（接上一步的 `.reader-stage`，只加了左边这个变量）。钉住时点书、Esc 都不收，搜索框里按 Esc 只把光标交还给书。
  钉住也算进「对照放不放得下」（`compareFitsStage` 看左右两边）。窄于 900px 钉不住（`SIDEBAR_PIN_MIN_VIEWPORT`），照旧浮着。
- **记在本机**：`retainpdf.reader.sidebar.v1` 存钉没钉、钉住时开着没开、哪一页签；钉住、上次开着，下次打开阅读页直接开着。
- **书签**：底栏只留「给这一页加书签」一颗；列表进左栏（`ReaderBookmarkList`，点一条跳页、× 删）。两处用同一个
  `useReaderBookmarks`，书签存储加了订阅（`subscribeReaderBookmarks`），一处改了另一处跟着变。
- **待处理**：底栏的 `ReaderIssuesControl` 删掉；读数据、N / Shift+N 挪进 `useReaderIssueNav`，挂在左栏的外壳上（左栏收着也能按 N）；
  列表是 `ReaderIssueList`。
- **底栏**只剩：页码、给这一页加书签、深色文档、缩放、快捷键。
- 书页区窄（钉住左栏又开着右边面板，只剩四百来宽）时底栏居中放不下小球：书页区设成容器（`container: reader-stage / inline-size`），
  窄于 560px 小球抬到底栏上面。
