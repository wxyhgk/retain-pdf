# 目录可以固定成一栏（2026-11-28）

用户：「左侧的目录的弹窗增加一个 pin 按钮，这样就能左侧固定了」。

接着 [顶栏右边挪到书页区右缘](./20261128-顶栏右边挪到书页区右缘.md)：那一版顶栏「目录」按钮只是让浮着的卡片一直开着，卡片仍然盖在书页左边。这次改成真的固定在左边。

## 做了什么

- 目录卡顶上加一行：左边「目录」两个字，右边图钉（`Pin` / 固定后 `PinOff`，「固定在左边」/「取消固定」）。
- 图钉和顶栏「目录」按钮是**同一个开关**（`tocPinned`，阅读页拿着）。
- 屏够宽（≥ 900px，和左栏实占一栏用同一条线 `finderState.pinned`）时，固定 = 中间工作区最左边实占的一栏（`nav.reader-toc-dock`，248px，纸色底、右边一道线，和左栏一个样子），书页往右让，书页区左缘的短横线不画；对照放不放得下也把它算进去（`compareFitsStage(..., sideDocked || leftDocked || tocDocked)`）。
- 窄屏固定只是卡片一直开着（浮在书页上），`Esc` 收起——不占一栏，免得书页太窄。
- 目录栏和左栏（搜索 / 书签 / 待改）可以同时开：目录在最左边，左栏在它右边。
- 固定只在这一次打开里记着，不写本机：11-28 收口时定了左栏一进来收着，目录跟它一样。

## 验证

演示模式 1440×900：悬停卡片右上角有图钉；点了以后目录一栏 0–248、书页区从 248 开始、短横线没了、顶栏「目录」按下；点「4 局限」跳到 4/4 一栏还在；再开左栏，目录 0–248、左栏 248–496；点图钉取消后书页区回到 0–1440、短横线回来；窄屏 760 固定后没有一栏、卡片一直开着。
