# 按使用者收拾提问窗标题栏和底栏

2026-11-27。重新设计阅读页外壳的第三步。用户贴来一份图层问题分析后说「从使用者的角度出发考虑一下如何设计，至于思考部分让后端去搞」，
看了下面的方案说「可以，按照你的建议去搞」。思考档位交给后端（retain-pdf-21，`feat/ask-thinking-levels`）。

## 先想人在阅读页上做什么

| 多常做 | 做什么 |
|---|---|
| 一直 | 读、翻页、缩放 |
| 经常 | 问一段、追问、点回出处 |
| 有时 | 目录、搜索、书签（第二步的左栏） |
| 偶尔 | 换谁来答（agent、模型、思考）、开个新对话、翻以前的对话 |
| 很少 | 看 AI 记住了什么、装本机 agent |

越常做的越顺手，越少做的越往里收；读书时页面安静。

## 提问窗：按「对话」组织

以前标题栏一行十个东西：标志、主对话、选 agent、插头（没装的 agent）、记忆、历史、归档、贴边、放大、关。

现在：

```
[主对话 ▾]                         [···] [贴边] [放大] [×]
```

- **「主对话 ▾」**（阅读页的 `ReaderAskConversationMenu`）：按钮写现在看的是哪段（主对话 / 副对话 · 标题 / 以前的对话 · 日期）。
  点开：在主对话里是「开个新对话」（现在这段收进「以前的对话」，点了先问一句——11-27 用户要的二次确认），下面列以前的对话（只读看）；
  看着以前的或副对话时最上面是「回主对话」。用户不用知道「归档」这个词。
- **「谁来答」只在一处**：输入框下面那颗按钮（写「模型 · 思考」，别的 agent 写「Claude Code · Opus」）。点开从上到下：agent 一排
  （`agent-row.tsx`；没装的写「要先装」，点了给安装命令——取代标题栏的插头）、模型列表、思考。agent 不给设置时也有这颗按钮（写 agent 名）。
- **「···」**：不常用的（阅读页：记忆）。`@retainpdf/ask` 的 `AskWindow` 新属性 `headerMenu`；标题栏的下拉是通用的 `AskHeadMenu`
  （`@retainpdf/ask/window` 导出，对话菜单也用它），Esc 只收下拉不关窗。

## 底栏：一条，不再药丸加黑球

以前底部中间白色药丸（页码、缩放），右下角一颗黑色实心球（提问、画笔、Markdown、对比），最显眼的是最不常用的。

现在并成一条（`ReaderHudTools` 放进底栏的 `toolsSlot`）：

```
[1 / 11] [书签] [深色] [− 50% +] [键盘] │ [提问] [画笔] [Markdown] [对比]
```

- 提问排竖线后面第一个（`FIRST = ["ask"]`），别的照扩展登记的顺序。
- 跟底栏一起往下翻时收起；带弹出的（对比版本的列表）弹在底栏上面，开着时底栏不收（`aria-expanded`）。
- 书页区窄于 640px（手机、左栏钉住又开着面板）一排收成「···」，点开往上一列；有面板开着时「···」带个点。
- 推翻了 11-20 用户定的「Markdown 和对比版本进右下角悬浮小球」，这次用户点了头。
- 窄屏面板铺满整屏时底栏照旧藏（以前小球还浮在面板上），关面板用面板头上的 ×。
- 删掉 `ReaderToolBall`；皮肤变量 `--reader-float-press-shadow`（只有小球用）去掉。

## 量过的（演示模式）

- 1400 宽：底栏 461–939，工具是 提问 / 画笔 / Markdown（演示只有一份译文，没有对比）；右下角没有小球。
- 标题栏：「主对话 ▾」「···」、贴边、放大、关。对话菜单：开个新对话、以前的对话；Esc 收下拉、窗口还在。
