# 三行壳层：顶栏、中间工作区、底栏

2026-11-28。用户贴来的方案：把阅读器从「全屏堆叠 + 浮动胶囊 + --reader-stage-* 偏移计算」改成标准的「上-中-下三行全宽 Flex 壳层」，
解决遮挡书页、栏位错位、工具条打架；功能逻辑先不动，先改整体布局；视觉沿用黑白灰纸墨，不加彩色标签和 emoji。

```
+------------------------------------------------------------------------------+
| 顶栏 54px：< 返回 · 左栏 · 书名      原文 | 对照 | 译文      提问 · Markdown · 对比 · 下载 |
+------------------------------------------------------------------------------+
| 中间工作区（flex: 1; min-height: 0; overflow: hidden；横排）                    |
|  [左栏，钉住时] | [书页区 flex: 1] | [右边停靠栏 / 提问窗贴右边的空位]              |
+------------------------------------------------------------------------------+
| 底栏 36px：书签 · 改译文待重排     页码 · 深色 · 缩放     画笔 ▾ · 截图 · ?       |
+------------------------------------------------------------------------------+
```

## 推翻了以前的什么

- 11-06 用户选「书页铺到窗口底，页码缩放浮在书页上」——现在底栏实占一行，不浮、不再往下翻时收起。
- 11-20 面板按钮进右下角悬浮小球、11-27 小球并进底栏浮条——现在提问、Markdown、对比版本在顶栏右段，画笔、截图在底栏右段。
- 画笔模式下左下角常驻的那一条工具去掉：平时不展开，要换笔点底栏「画笔」旁边的 ▾。

## 做了什么

- **根节点**（`.reader-react-root`）：`display: flex; flex-direction: column; height: 100dvh`。两条栏的高是 `--reader-topbar-h: 54px`、
  `--reader-bottombar-h: 36px`；JS 要用的在 `src/app/shell-metrics.ts`，测试对着两边。
- **顶栏**（`ReaderWorkspaceTabs` 多了 `start` / `end`）：`grid-template-columns: minmax(0,1fr) auto minmax(0,1fr)`，页签正好在视口中间；
  左段返回（‹）、左栏开关（带待处理角标）、书名；右段 `ReaderBarTools place="top"`（提问排第一、Markdown、对比版本）、下载。
  去掉了 `--reader-tray-width` 和 fixed 的托盘、左上角按钮组。
- **中间工作区**（`.reader-workspace`）：左栏钉住时是横排里实占的一栏（浮着时 absolute 盖在左上角）；书页区 `flex: 1; min-width: 0`，
  里面只有 `ReaderCompareGrid` 和它的加载、出错提示（提示 absolute、按书页区居中）；右边停靠栏 `.reader-dock` 实占一栏
  （宽度 `--reader-ai-split-width`，分栏线照旧能拖），tab 条下面的 `.reader-dock-body` 由扩展用 `createPortal` 把面板画进去
  （新的 `ReaderApi.panelHost`）；面板关了这一栏只是 hidden，Markdown 面板留着滚动位置。提问窗贴右边时横排里留一栏一样宽的空位，
  提问窗本身照旧是浮层，用新的 `dockInsets`（顶栏、底栏的高）落在这一栏上。窄屏（< 900）停靠栏铺满中间工作区。
- **底栏**（`ReaderZoomHud`，类名 `.reader-bottombar`）：左书签、改了译文还没排进 PDF 的一行小字和「重新排版」（以前是右下角浮着的胶囊）；
  中页码、深色、缩放；右 `ReaderBarTools place="bottom"`（画笔 ▾、截图）、快捷键。底栏不再自动收起（删掉 use-hud-autohide）。
- **贡献表**：`ReaderToolbarItem` 加 `place`（"top" / "bottom"）和 `dropdown`（旁边的 ▾）；提问扩展多登记一颗底栏的「截图」。
- 去掉所有 `--reader-stage-left / -right`、`--reader-right-inset`、`--reader-hud-room`；皮肤变量 `--reader-hud-shadow`、`--reader-hud-radius`
  （浮动药丸的阴影、圆角）没用了，从登记表删掉；顶栏接回 `--reader-chrome-bar-shadow`。

## 没做的（布局里留了位置，现在没有这些功能）

- 底栏左边的「收藏」、顶栏右边的「白板」、书页区左缘的目录短横线 Minimap：功能还没有，不画点了没反应的按钮。
- 方案说左栏「仅搜索 / 待改」：现在的左栏还有目录、书签，目录要等 Minimap 做出来再考虑挪。
