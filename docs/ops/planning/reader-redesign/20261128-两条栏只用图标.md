# 两条栏只用图标

2026-11-28。「顶栏底栏做减法」之后用户：「顶部的三个图标我觉得得加回来，然后去掉文字，目前最大的问题是左右两侧的图标不合理」。
问了是哪种不合理，四项都选：带字不带字不统一、大小粗细不一样、图标选得不贴切、底栏左右也一样。

## 定下来的规矩

- **顶栏、底栏只有图标**，名字在 `aria-label` 和悬停 `title` 里。页码、缩放百分比、待改个数这种数字照旧是字。
  「返回」「下载」的字本来就只给读屏，保留。
- **一个尺寸一种线宽**：`src/components/react-pdf/bar-icon.ts` 的 `BAR_ICON = { size: 16, strokeWidth: 1.75 }`，
  ▾ 用 `BAR_CARET`（12）。以前 14 / 15 / 17 / 18px、线宽 2 / 2.1 / 2.15 / 2.2 / 2.25 混着用，还有两个手画的 svg（书签、深色）。
  测试钉住：两条栏的组件都用 `{...BAR_ICON}`，不再自己写尺寸。
