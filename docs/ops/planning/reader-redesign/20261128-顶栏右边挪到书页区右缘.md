# 顶栏右边挪到书页区右缘、顶栏加「目录」按钮（2026-11-28）

用户给的布局：

```
顶部 Bar（16px 纯图标 + 书名）
  左：[< 返回] [目录] [搜索]  书名        中：[ 原文 | 对照 | 译文 ]        右：空
中间阅读区
  左缘：悬浮 Minimap 短横线（悬停出目录卡；点顶栏[目录]可固定展开/收起）
  正中：PDF 书页
  右侧：AI 回答 / Markdown 面板停靠位，下载

  左：[书签] [收藏]      中：[页码] [深色] [- 缩放 +]      右：[画笔▾] [截图] [?]
```

并明说「去掉顶部的 右：[AI回答 | Markdown] [下载]」。问了「面板关着时从哪里打开」，用户选「右缘一条竖图标栏」，补了一句「建议使用悬浮的」。

## 做了什么

- **顶栏右段空着**：`end` 不再传东西，网格照旧左右同宽，页签留在正中。
- **书页区右缘的竖条**（`ReaderSideRail.tsx`、`styles/side-rail.css`）：浮在 `.reader-stage` 右边、竖着居中（`right: 14px; top: 50%`），不占一栏，和左缘的目录短横线对称。上面是面板按钮（提问、Markdown，贡献表 `place` 不写或 `"side"`），一道细线，下面是下载；下载菜单往左弹。按钮 30px 方、图标照 `BAR_ICON`。停靠栏开着时竖条在书页区里，跟着停在停靠栏左边。
- **贡献表 `place: "top"` 改名 `"side"`**：没有扩展显式写过 `"top"`（默认值），对外只差类型里的字面量。
- **顶栏「目录」按钮**（`ReaderTocToggle`，图标 `ListTree`）：返回和搜索中间。点了钉住目录卡（`data-pinned`）：移开鼠标、点一条跳过去都不收，一钉住就展开当前章、滚到当前节；再点按钮或在卡片里按 `Esc` 收起。书里没有目录时灰掉。钉不钉只在这一次打开里记着，不写本机。

## 没做的

- 以前删过一个右侧竖条 `.reader-assistant-rail`（两个启动器各管一半）。这次的竖条是唯一的面板入口（顶栏不再有），测试照旧钉着「只有一份面板按钮」。
- 用户写的「AI 回答」：按钮名字还是「提问」（和右键「在这里提问」、使用说明一致），没改。
