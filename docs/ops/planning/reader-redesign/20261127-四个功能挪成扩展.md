# 四个功能挪成扩展

2026-11-27，接着 [阅读页贡献表](./20261127-阅读页贡献表.md)。

用户：「继续把更多功能挪成扩展：Markdown 面板、画笔、交叉引用、版本对比。缺口子（比如面板、工具栏按钮）时再加，不预先铺」。

## 做了什么

四个功能各挪成一个内置扩展（`packages/reader/src/extensions/builtin/`），一个功能一个提交；阅读页主组件里不再出现这四个功能
（`ReaderAppReactPdf.tsx` 341 → 301 行，贡献表那一侧的接线挪到 `app/use-reader-extension-host.ts`）。
内置扩展的顺序：画笔、Markdown、对比版本、交叉引用、提问（小球里的按钮、右键菜单、快捷键说明里的组都按这个顺序，和挪之前一样）。

## 每个功能缺的口子

| 功能 | 加的口子 | 说明 |
|---|---|---|
| Markdown 面板 | 扩展定义上的 `panels` | 面板名字、图标、要不要任务是死的，写在扩展定义上、不走运行时登记：面板开没开要按书存、重开恢复，`id` 仍须是 `shared/types/reader-assistant-panels` 里登记过的（类型卡住），启动器和 tab 条照旧能静态对账。面板内容扩展自己画（看 `api.activePanel`）。删了 `reader-base-panels.ts`、`use-reader-panel-slot.ts` |
| 对比版本 | `toolbarItems`（小球里的按钮，可带弹出）、`comparedDocument`（对照时左栏换成的那一份） | 「这本书几份译文、正在读哪份」拆成阅读页自己的 `useReaderTranslationVersions`：提问要记读的是哪份，不能放在对比版本扩展里 |
| 交叉引用 | `textMarks`（一段字里要包成 `<mark>` 的几段） | 书页文字层改走通用的 `renderMarkedText`：几个扩展的标记合在一起，重叠的先到的赢，只认 `data-*` 属性，搜索词照旧在段里高亮；`renderXrefText` 成了它的特例。预览和「回到第 N 页」扩展自己画 |
| 画笔 | `menuSection`（右键菜单里的一块）、`takesPointer`（占着书页上的指针）；`pageLayer` 多传 `width`、`pane`、`active` | 右键菜单从画笔里拆成通用的 `ReaderPageMenu`（菜单项一行 + 各扩展的块；什么都没有时照旧是浏览器的菜单）。画笔模式下书页不出悬停框、双击不放大，根节点标 `data-pointer-taken`（以前 `data-ink-mode`，文字层不让拖选）。对比版本时左栏的笔迹按 `pane: "compare"` 分开存，和以前一样 |

阅读页接口（`useReaderApi`）跟着加了：`sourceOnly`、`activePanel` / `closePanel`、`translationVersions`、`visibleMode` / `setWorkspace`、
`jumpToBlock`、`shellEl`、`primaryPane`、`pdfDocuments`。

快捷键说明：「画笔」「引用」两组从固定表挪进各自的扩展；「Shift+右键 = 浏览器自己的菜单」是书页菜单本身的，留在固定表里单独一组「右键」。

## 守住的东西

- 启动器和面板对账（`reader-single-launcher` 那组）：面板 id 真源 ↔ 扩展定义里的 panels ↔ 扩展里的 open 和懒加载闸，改成逐个扩展文件对账。
- 每个扩展交给表的东西都是稳定对象（`useReaderVersionCompare` 的返回也做成了 memo），不然扩展每画一次就登记一次、整个阅读页跟着重画。
- 真机（开发栈，不调模型）逐个点过：Markdown 开 / 关 / 刷新恢复；对比版本挑一份切对照、两栏水印、切走收掉；引用标出、悬停预览、点了跳、
  Alt+← 回来；右键菜单（提问一行 + 画笔一排）、进画笔、画一笔、画笔模式不出悬停框、小球和 P / Esc；书页「?」点了开这本书的主对话。
