# 断行规则和文字规范化

2026-11-22。用户从排版细节清单里先挑了"断行"和"文字规范化"两类。

## 做了什么

**rpr 引擎断行**（retain-pdf-rendering 分支 `feat/cjk-linebreak`，`src/text/linebreak.js`）。断行加了规则档 `rules`：
默认 `"cjk"`，`"typst"` 保持 Typst 0.15.1 原样（和 Typst 逐行对照的 1196 个样本用它，守住断行核心没被改坏）。`"cjk"` 多了：

- 不在这些地方断开：`– / —` 两侧都是字母数字（10–20、kJ/mol、C—H）、数字编号的连字符后接汉字（1,3-丁二烯）、`·` 之前、
  引用词紧跟编号（图3.23、式(1.22)、第3章）、数字紧跟量词（第3章的"3|章"）。
- 段尾孤字（有汉字的段落最后一行只剩一两个字）：两端对齐的优化断行记罚分 200（约等于愿意让上一行每缝多拉 0.13 个字宽）；
  rpr 引擎排正文走逐行贪心断行，贪心排出孤字时用优化断行重排这一段，行数不变、孤字没了才用。

**retain-pdf 文字规范化**（`render/layout/inline_content/core/cjk_text.py`，在 `mode_router.build_item_render_markdown` 最后一步，
Typst 和 rpr 引擎两条路线都经过；公式原样，没有汉字的文字不动）：

- 不该断开的空格换成不可断空格：引用词和编号之间（图 2.7、式 $(2.21)$、第 3 章）、数字和单位之间（300 K、40 kJ/mol），
  缺空格的数字和单位补上（250kJ/mol）。单位里单个字母的只收 K（1s、3d 轨道不当单位）。
- 引号：成对的英文直引号配成“”，「」『』换成“”‘’。
- 括号：半角括号里有汉字的换全角；全角括号里全是西文的引文换半角，里面的全角逗号、分号、冒号一起换（括号外的全角逗号是中文标点，不动）。
- 段首列表符号 `- ` `* ` 换成 `• `；汉字间单个 `…` 换成 `……`。
- 注释号这类纯上标公式（`$^{14}$`）：`surround_inline_math_with_spaces` 不再给它补空格，规范化再去掉它和汉字之间原有的空格。

## 效果

| | 计算化学（40 页） | 电磁学（200 页） |
|---|---|---|
| 引用词和编号被拆开 | 5 → 0 | 52 → 0 |
| 数字和单位被拆开 | 1 → 0 | 2 → 0 |
| 范围、斜杠、化学键被拆开 | 3 → 0 | 1 → 0 |
| 段尾孤字（两行以上的段落） | 6 → 5 | 71 → 57 |

剩下的孤字大多（约四分之三）带行内公式：公式不能拉伸字缝，把一个字推下去要把上一行拉得很开，代价超过罚分，按设计宁可留孤字。
要再少，得有字距微调（引擎还没有）或小幅缩字号，另做。

## 关于 Typst

用户 11-22 问还要不要 Typst：82 个真实任务里 79 个由 rpr 引擎排完、3 个退回 Typst（2 个引擎报错、1 个缺 document）。
建议分步去掉（先修退回原因 → 不再自带 Typst → 删 Typst 路线），单独立项，还没开始。不可断空格这类规则放在文字规范化里，
两条路线都生效；引擎的断点和孤字规则只在 rpr 引擎路线生效。
