# 跨栏、跨页的段落按容量顺流（2026-11-22）

## 问题

一段话在原文里跨了栏或跨了页（接续组 `continuation_group`），翻译时合成整段去译，译完由
`translation/core/payload/parts/group_split.py` 切回各块：按**原文各块的长度比例**，前一块原文以句号结尾时只在译文句号处切。

比例和句号都不是“这个框装得下多少”：中英文句子长短不对应，切在句号上常常一块装不满、下一块装不下，
下一块只好缩字号、压到页眉（3bfb0b 第 63 页顶部）。而且翻译阶段不知道排版字号和每行能放几个字。

用户 11-22：“跨栏、跨页是按照句号分配的，这样不好”；方案“按容量顺流”可以，“重要的是你不能把公式分割出去”。

## 做法

切分挪到 rpr 引擎里，排版时按框的容量切（引擎 `src/retain/continuation-balance.js`）：

1. retain-pdf（`render/output/rpr_fit/renderer.py` 的 `_continuation_flows`）把组里各块已经转好的引擎文本按
   `translation_unit_member_ids` 的顺序接成整段（两边都是西文才加空格），标在每个成员的 `flow { group, index, count, text }` 上。
   翻译阶段的切分照旧放在各块的 `translated_text` 里，引擎不切时用它，阅读页、导出的文字也照旧用它。
2. 引擎按各框自己的宽度排整段，在**行末**切：第一块排到它的容量为止，剩下的流到下一块，依此类推（串联文本框）。
3. 容量按框高算：估计的全书统一字号（本次所有正文框初始字号的中位数，放大 3% 留余量）、基础行距、段后留白
   `reserveEm`。最初取原文行数，那些框按原文排得很紧，排满就溢出（3bfb0b 溢出 4→18），弃用。
4. 顺流到最后一块装不下时，改成各块按相同比例超出（balance），不再全压给最后一块。

### 公式不拆

- 行内公式在断行器里是一个不可分的整体，切点只落在公式前后；渲染不了的公式也按一整块切，写回 `$tex$`。
- 下一块不会以闭标点开头（断行规则本来就不许）。
- 不交给引擎切、保留翻译阶段切分的组：成员之间夹着独立公式（翻译阶段已在公式处切开）、译文有 `$$` 或 `$` 不成对
  （认不出公式边界）、逐行排的块、文本里有换行、有成员没有译文、成员不全在这次渲染里、成员不全是正文框。

## 效果（同一份译文，改前 → 改后）

| 书 | 接续组 | 溢出 | 溢出超过 3pt | 字号比全书小 |
|---|---|---|---|---|
| 计算化学 p40–79 | 23 | 4 → 3 | — | 2 → 0 |
| 电磁学 p80–279 | 118 | 46 → 41 | 26 → 23（合计 247 → 213pt） | 11 → 10 |

电磁学剩下的溢出大多是整段译文本来就比几个框加起来还长，怎么切都装不下。2 组有成员不是正文框，没有切。

组内各块的填充差变大了（中位 13% → 14% / 29%）：这是顺流本来的样子，前面的框排满、最后一块放剩下的。

## 没做的

- 阅读页按 PDF 的切分显示：要引擎把切分写回去，阅读页和 PDF 每块的分界现在会略有不同（整段内容相同）。
- Typst 退路仍用翻译阶段的切分。

引擎报告 `report.json` 加了 `continuation`：每组的成员、模式（flow/balance）、各块行数和填充，没切的写原因。
