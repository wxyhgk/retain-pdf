# 按原书字号另排先关掉

2026-11-23。[列表和同一框里的几段合成一块排](./20261123-列表和同一框里的几段合成一块排.md)里的第 2 条
（原书字号偏离正文的段落移出正文组另排，以及同字号几段合成一块）合进去当天，用户在一篇 JACS 论文上看到排版变差，改成默认关掉。

## 出了什么问题

这篇论文的 COMPUTATIONAL METHODS 一节原书是 9pt，正文 10pt。这一节四段：

- 前两段被认成同一字号的一组，移出正文组按 9pt 排；
- 第三段是跨栏接续的段落，按规则留在正文组（接续切分要在正文流之间做），排成正文的 10pt。

同一节前小后大，比都按正文排还难看。移出去的那组也没了正文的填充策略，框底空着一截。

## 怎么改的

引擎里这一步改成默认不做（`sourceSizeClasses: true` 才做），列表合并、悬挂缩进、两字缩进照旧。
这篇论文的这一节回到三段都是正文字号（9.98pt），第二段有两字缩进，框填满了；溢出、碰撞不变。

代价：电磁学例题框里原书 9pt 的段落又按正文排，溢出回到 169（超过 3pt 的 92），和加这条以前差不多（176 / 92）；计算化学不受影响（16 / 7）。

## 要做好得怎么做

在正文排版里把原书字号偏离正文的段落当成单独一类定字号（还留在正文组里，接续的段落一起算，走正文的填充），
而不是移出正文组。同一节的段落（包括跨栏接续的）字号就能一致。
