# 行内粗体暂缓

2026-11-23。排版细节清单第 4 级“结构”里的“行首小标题和图注编号的粗体丢了”。查了来源，用户决定先不做（“这部分先不管算了”）。

## 查到的

- 原 PDF 文字层里粗体是现成的（字体标着粗体）：电磁学 644 条图注、154 段正文以粗体开头（“Figure 8.32.”、“Example (…)”），
  计算化学 241 条图注、222 段正文。
- OCR 视觉模型能标粗体，但这两本书里几乎没标：电磁学成对的 `**…**` 75 处全在目录（`**4.1**`），计算化学一处都没有。
  原文里大多数 `**` 是习题标题行尾的难度星号（电磁学 586 处），不是粗体。
- 翻译模型会保留原文里的 `**`（电磁学 470 → 420，89%），能把粗体对到译文的对应位置（“Example (Charges in cavities)” → “例（空腔中的电荷）”）。
- 引擎一个块只能整块常规或整块粗体（测量、断行、输出都按块选字重），一段里混排两种字重要改断行和输出。

## 要做时的路子

1. 原文标粗体：有文字层的从文字层读段首粗体，送翻译前标成 `**…**`；扫描件靠 OCR 模型标的。行尾的难度星号要和粗体区分开。
2. 翻译提示词要求保留 `**…**`（改提示词要重录快照；只对新翻译生效，已翻好的书要重翻）。
3. 引擎支持一段里混排两种字重。
4. 省钱的部分：图注编号（“Figure 8.32.” → “图 8.32”）规则固定，可以不经模型，渲染时把开头的“图 X.X”加粗，已翻好的书重排就生效。
