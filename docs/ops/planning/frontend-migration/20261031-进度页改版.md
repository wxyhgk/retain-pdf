# 书籍详情「进度」页改版

2026-10-31。用户：「重新设计"进度"这个 tab，看看如何把错误、重试、详情、取消任务什么的全部整合在一起，多用图标，少用文字」；
示意图过目后定：流水线保留 2.5D 画面（「我建议使用我们的 2.5d」），完成后重做的动作照旧挂在各站上。

## 以前

从上到下：摘要、流水线、最近活动、「查看实时译文」大卡、带「取消任务 / 详情」的状态卡、一行说明；失败时再加一张自带
「从断点继续 / 复制诊断信息 / 查看日志 / 展开完整错误」四个按钮的失败卡，取消时一张取消卡；还没开始时最下面一行勾选框和按钮。
用时写三遍（摘要、活动、状态卡），按钮散在三处。

## 现在：一张卡，四层

1. **状态行**：状态图标、一句标题（「翻译中」「翻译失败」「已停止」「已完成」）、一行带图标的小字（用时、批次、停在哪站、
   翻了几页）。右边是这一刻能做的事，只有「下一步」带字，其余是图标（悬停和读屏有名字）：

   | 状态 | 带字的 | 图标 |
   |---|---|---|
   | 翻译在跑 | 实时译文 | 详情、取消（红） |
   | OCR 在跑 | | 取消 OCR |
   | 失败 / 停下 | 从断点继续（按续跑计划） | 日志、详情 |
   | 单独的 OCR 失败 | 重新 OCR | |
   | 还没开始 | 翻译整本 | 只做 OCR、指定页码 |
   | 完成 | | （重做在各站的 ↻ 上） |

   进度条只在跑的时候画。停下的任务不画：任务记录里的进度常是最后一个阶段自己的（渲染 100%），画出来像跑完了。
   「指定页码」一个开关，翻译和只做 OCR 共用一份页码（以前是两个勾选框、两个输入框）。
2. **流水线**：2.5D 画面不变。站点标签只用图标说状态，「已完成」「等待中」这类字留给读屏；失败、取消才画成小标签。
   各站重做的入口从「重新 OCR ▾」文字胶囊换成 ↻ 图标；手机宽度上挂在站名那一行右边。
3. **细节区**：错误 / 编辑部 / 活动，只摆有内容的那几页，一排带图标的小切换；有错误时默认停在「错误」。
   失败那一块：标题一行（右边复制诊断），图标小标签说谁的问题、重试有没有用，后端的根因，主按钮沿用什么、花不花钱，
   「完整错误」点开才取。重试解决不了的才写该做什么（换 Key、换文件）。
4. **结果操作行**（下载 / 对照阅读），不变。

## 没变的

- 契约 id 和 data 属性：`book-detail-translate-btn`、`book-detail-start-ocr-btn`、`book-detail-cancel-ocr-btn`、
  `book-detail-retry-failed-btn`、`book-detail-resume-cancelled-btn`、`book-detail-status-section`、
  `book-detail-job-status-card`、`book-detail-translate-progress`、`data-job-failure`、`data-processing-region` 等。
- 轮询的主人还是 `BookTranslateProgressPanel`（任务在跑或失败时把本书的任务挂到全局状态卡 store 上）。
- `StatusCard` 只剩详情、取消两个图标；阶段导航、文案、阶段重试这些节点照旧渲染在隐藏容器里（store 往这些 id 写字，
  状态卡组件测试也按它们检查）。以前它们就是用 CSS 藏起来的，现在明说。

## 以后可以再收

- `StatusCard` 隐藏容器里那批节点和 `TranslationStageActions` 的 inline 变体，现在没有画面用到，确认没人读之后删。
- 完成态状态行没有「详情」：任务详情弹窗跟的是全局状态卡 store 里的任务，完成的任务不会挂上去，点了可能显示别的任务。
  要加得先让弹窗能按任务号打开。每次任务的明细现在在「历史」页签。
