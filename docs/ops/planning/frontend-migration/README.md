- 2026-11-01 [接口设置多用图标](./20261101-接口设置图标化.md)：OCR 服务商、Agent 运行模式、操作确认都换成一排图标卡片，字段名前加小图标。
- 2026-11-01 [Agent 只留 OpenAI 兼容](./20261101-Agent只留OpenAI兼容.md)：AI Agent 卡片去掉运行模式选择和 FX 的字段，保存总是写 OpenAI 兼容。
- 2026-11-01 [进度页去掉翻译覆盖](./20261101-进度页去掉翻译覆盖.md)：「进度」页底下的翻译覆盖条去掉，任务记录照旧在「历史」页签。
- 2026-11-01 [翻译去掉 chat 接口](./20261101-翻译去掉chat接口.md)：接口协议去掉 /chat/completions，只留 OpenAI Responses 和 Anthropic；思考深度默认关闭。
- 2026-11-01 [放在笔记里](./20261101-放在笔记里.md)：`?embed=studio` 时和笔记 Studio 握手、跟着换亮暗、收跳转；阅读页悬停框多「摘到笔记」；嵌入时不软开阅读层。
- 2026-11-02 [阅读页笔记按钮](./20261102-阅读页笔记按钮.md)：放在笔记 Studio 里时阅读页顶栏多「笔记」，让 Studio 在旁边开、收这本书的笔记。
- 2026-11-02 [告诉 Studio 读到哪](./20261102-告诉Studio读到哪.md)：放在笔记 Studio 里时阅读页翻页停下来发 `reading`（书和页），给 Studio 的 AI 回答「这一页」。
- 2026-11-02 [阅读页的「AI」交给 Studio](./20261102-阅读页AI交给Studio.md)：Studio 认 `ask-ai` 时阅读页的「AI」打开 Studio 的 AI，不再打开自己的终端。
- 2026-11-02 [同一本书原地翻页](./20261102-同一本书原地翻页.md)：Studio 打开正在读的这本书的另一段时原地翻过去，PDF 不重新加载。
- 2026-11-03 [阅读页先修最烦的几处](./20261103-阅读页先修最烦的几处.md)：模式页签写上字；竖条、底栏不压书；目录、搜索到 PDF 这边（左边一栏，从块来）。
- 2026-11-03 [大书打开要快](./20261103-大书打开要快.md)：页面不等块数据（regions），PDF 下完就出；726 页 3.3 → 0.5 秒。
- 2026-11-03 [RetainPDF 不要自己的 AI](./20261103-RetainPDF不要自己的AI.md)：删掉阅读页的 agent 终端和画板、主页「AI 问答」、设置的 AI Agent，只留 Studio 的 AI。
- 2026-11-03 [选 GLM-OCR 时不限页数](./20261103-GLM不限页数.md)：上传的页数上限跟着设置里选的 OCR（PaddleOCR 999、MinerU 600、GLM-OCR 不限）。
