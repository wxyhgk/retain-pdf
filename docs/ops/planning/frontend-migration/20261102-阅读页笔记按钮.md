# 阅读页「笔记」按钮（放在笔记 Studio 里时）

2026-11-02。接着 [放在笔记里](./20261101-放在笔记里.md)。后端交接见 [backend-changes-handoff](../../../core/frontend/backend-changes-handoff.md)
「阅读页唤出笔记」，方案见 [阅读页唤出笔记](../studio-workbench/20261101-阅读页唤出笔记.md)，契约 `contracts/studio-bridge.v1.schema.json` 只加不改。

## 做了什么

- **hello.features**：握手时记下 Studio 认哪些我们发的消息。没有这个字段的是早先的 Studio，只认 `quote`；
  「摘到笔记」也按它来（Studio 列了 features 却没有 `quote` 就不出）。`ready` 的 features 加 `notes`。
- **「笔记」按钮**：阅读页顶栏托盘（下载、关闭旁边），只有图标（NotebookPen），悬停「打开这本书的笔记」/「收起笔记：书名」。
  握过手、Studio 认 `open-notes`、地址里有任务才出。收着时点发 `open-notes`（任务、书编号、书名，和 quote 同一套），开着时点发 `close-notes`。
- **按下没有跟着 Studio 走**：收到 `notes` 才变（点了不先自己翻），Studio 那边收起、换了笔记也会告诉我们。按下时填成墨色。
- 阅读器包加可选适配 `notesPanel`（`getState`、`subscribe`、`toggle`），按钮用 `useSyncExternalStore` 读；
  和「关闭」共用托盘按钮（`ReaderCloseHome.tsx` 里的 `ReaderTrayButton`），托盘让出的宽度随按钮多 44px。

## 验过的

用一个假 Studio 页（另一个本机端口）放 RetainPDF：握手、开笔记时 iframe 缩到 56%（约 800px）阅读页跟着重排、托盘不压分栏切换，
收起后恢复；只发了 GET。
