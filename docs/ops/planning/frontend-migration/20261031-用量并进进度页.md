# 用量并进「进度」页，字再少一些

2026-10-31。用户：「我感觉进度页面可以更加的减少文字，增加图标，然后将"用量"tab 里面的东西搬到我们的"进度"里面来」。
接着 [进度页改版](./20261031-进度页改版.md)。

## 用量

- 右栏的「用量」页签去掉。用量放进「进度」页：
  - 状态行小字多一项：金币图标 + 合计（「87.5 万」），悬停写精确值和请求次数。任务在跑时数还在涨，不摆。
  - 细节区多一页「用量」：一排图标 + 数（输入 ↓、输出 ↑、缓存命中 ⚡、思考、合计 Σ），名字和精确值在悬停里；
    下面按环节一行一条条形；说明（早期任务按报告折算等）一行小字。思考为 0 时不摆。没有记录就整页不出。
- 用量在「进度」页可见时才读（以前是页签懒加载），任务跑完或换了任务再读一次。读用量要打接口，
  `tabs/` 下的组件不碰接口，所以由 `ProcessingTabWithUsage` 读好交给页签。
- 设置里的「总用量」不变（还用 `UsageSummary`）。

## 字再少一些

- 状态行小字只留图标和数：「已运行 12 分」→ 钟表「12 分」，「停在渲染」→ 暂停「渲染」，「已翻译 4 / 6 页」→ 文件「4 / 6 页」，
  「最近 10/31 11:52」→ 时钟「10/31 11:52」。整句在悬停和读屏里。
- 流水线各站的时间同样：钟表图标 + 数，「用时 / 已运行 / 共」在悬停里。
- 各站 ↻ 点开的清单：每行的说明句换成一个费用小标签（不产生费用 / 产生费用，淡黄底），整句在悬停里；
  不能做时照旧写原因。
