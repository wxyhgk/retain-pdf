# 「接口设置」多用图标

2026-11-01。用户：「前端"接口设置"部分我觉得得重新整理一下,多用图标整理 ui」。

## 改了什么

- **OCR 服务商**：卡片头右边的下拉框换成卡片下面一排图标卡片（PaddleOCR、MinerU、GLM-OCR）。
  GLM-OCR 用智谱的标志（和翻译「智谱」同一个文件），另外两家没有标志文件，用线条图标。说明在悬停里。
- **Agent 运行模式**：下拉框换成同样的图标卡片，画面上写短名（Markdown 检索 / OpenAI 兼容 / FX Gateway），全名在悬停里。
- **操作确认**：原来就是两张卡片，换成同一个组件，三处长一个样子；外面那层框去掉。
- **字段名前加小图标**：服务、地址、模型、Key、并发、协议、思考深度。
- 翻译卡片头的「OpenAI 兼容」小标去掉：下面的「接口协议」也能选 Anthropic，这个标签反而不对。
- 窄屏（≤560px）图标卡片改成图标在上、名字在下，不截断名字。

## 怎么做的

- `credentials/ui/ChoiceTiles.tsx`：包一层 `SegmentedControl`（radiogroup，方向键换选项），只换样子。
- `credentials/ui/FieldLabel.tsx`：字段名 + 小图标。
- OCR 服务商卡片的 id 还是 `browser-ocr-provider-select`，挂在外框上；每张卡片带 `data-ocr-provider-option`，
  Agent 模式卡片带 `data-agent-mode`，测试按它们点。
- 服务商标志是黑色的（img 里的 currentColor 只能是黑），标志的小底一直留白，选中和深色主题都看得见。

## 没动的

- 接口协议、思考深度还是原生下拉框：它们的值由凭据域直接读写元素（`translationProtocolSelect.value`），
  换成卡片要先把这部分改成走状态，留到以后。
- 保存、检测的流程和文案没变。
