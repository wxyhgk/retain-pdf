# 翻译接口去掉 /chat/completions，思考默认关闭

2026-11-01。用户：「直接去掉 "/chat/completions" 思考深度,默认关闭」「思考深度比如是默认不思考」。

## 改了什么

- 「接口设置 → 翻译 API → 接口协议」只剩两项：OpenAI Responses 格式（/responses）、Anthropic 格式（/messages）。
  `TRANSLATION_API_PROTOCOL_OPTIONS` 去掉 `openai`。
- 除 Anthropic 外的服务商预设（Qwen、DeepSeek、OpenAI、智谱、OpenCode Go、自定义）协议都改成 `openai_responses`。
- 以前存下的 `openai`（/chat/completions）读进来时落到服务商的默认协议（`normalizeTranslationApiProtocol` 的回落值改成 Responses），
  所以已有设置**不用重新保存**，下一次提交任务就走 /responses。
- 思考深度照旧可选，默认从「自动」改成「关闭」（选项里「关闭」排第一）。以前存下的档位照旧。
- 桌面端从 `~/.retainpdf` 读配置时，没写协议、思考深度的按 Responses、关闭（`retainpdf-home.js`）。

## 要注意的

- 走 /responses 要服务商支持 Responses 接口。DeepSeek、智谱、Qwen 和中转站是否支持没核实；不支持的话翻译和「检测接口」会报错。
  用户知道这一点后仍定下只留 Responses。
- 管理后台（多用户，已停止维护）的协议列表来自后端，没动。
