# AI Agent 只留「OpenAI 兼容」

2026-11-01。用户：「前端部分的 ai agent 使用"OpenAI 兼容" 就行了,其他的我感觉没有用」。

## 改了什么

- 「接口设置」的 AI Agent 卡片不再给选运行模式（Markdown 检索问答、OpenAI 兼容、FX Gateway 三张卡片去掉），
  只剩模型 API URL、模型、模型 API Key 和操作确认。FX Gateway 的地址、模型、Key 三格也去掉。
- 保存时总是写 `agent_runtime: "openai"`，不再发 `fx_*` 字段（接口里这些字段本来就可选，后端保留原值）。
- 后端现在配的不是 OpenAI 兼容（以前选过另外两种）时，卡片里说一句「现在用的是「…」，保存后改用 OpenAI 兼容 Agent」。
  卡片头右上角的小标照旧写实际在跑的是哪种。

## 没动的

- 后端的三种模式、接口字段都没动（前端不改后端）。「AI 问答」页的可用性判断（`agent-runtime-gate.ts`）照旧按后端实际的模式判断：
  没保存过之前后端还是原来的模式，问答页要能照常用。
- 后端要不要也删掉另外两种模式，由后端和用户定。
