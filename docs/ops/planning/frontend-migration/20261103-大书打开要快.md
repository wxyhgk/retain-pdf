# 大书打开要快：页面不等块数据

2026-11-03。接着 [阅读页先修最烦的几处](./20261103-阅读页先修最烦的几处.md)。

## 量到的

用户选了「打开大书要快」，先量（开发栈、无头浏览器、本机、冷打开）：

| 书 | 第一页出来 | reader/regions | 两个 PDF |
|---|---|---|---|
| 89 页 | 0.8 秒 | 0.37 秒，1.4 MB | 各 0.04 秒 |
| 726 页 | 3.3 秒 | 3.0 秒，8.4 MB | 0.1 秒（10 + 13 MB） |
| 720 页 | 4.0 秒 | 3.5 秒，8.3 MB | 0.3 秒（45 + 36 MB） |

卡的是块数据（regions）：后端每次现算，没压缩、没缓存头，同一本书第二次照样 3 秒；而阅读页要等它（和页尺寸 metadata
一起）到了才拿掉启动遮罩，PDF 早下完了。后端那半（存下算好的、gzip、ETag）请后端会话看。

## 改了什么（前端）

- `session-assets.ts`：拆开加载可选产物时，PDF 下完就就绪，块和页尺寸到了再补进会话（`regionsSettled` 置上）。它们只给悬停、
  高亮、目录、搜索、引用用，排版靠 PDF 自己。PDF 下载失败也不等块就报。
- `use-url-anchor-jump.ts`：只给了 `block_id` 的锚点，块没到先不处理（不把第 1 页写回 URL、冲掉 block_id），块到了跳到它所在的页；
  同时给了 `page_idx` 的先按页跳，块到了按块所在的页校一次。

## 改完

| 书 | 改前 | 改后 |
|---|---|---|
| 89 页 | 0.8 秒 | 0.3 秒 |
| 726 页 | 3.3 秒 | 0.5 秒 |
| 720 页 | 4.0 秒 | 0.75 秒 |

新加「只给块的锚点等块」。
