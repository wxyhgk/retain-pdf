# 「进度」页 HUD 收成一条，信息挪回流水线

2026-10-31。用户看了 [进度页 HUD](./20261031-进度页HUD.md) 之后：「卡片太大了，此外，我们在流水线上的东西太少了，啥信息都没有了」。

## 改了什么

- **HUD 收成一条**：小进度环（中间状态图标）+ 页数 / 进度、计时器 + 总耗时、服务商标志 + 模型名、金币 + token 合计，一行排开。
  四张大卡、耗时分段条、输入 / 输出比例条去掉（分段挪到流水线各站，输入 / 输出在细节区「用量」页）。
- **流水线各站带信息，但不用整句**：
  - 徽标里是这一站自己的图标（文件、扫描、翻译、排版、旗子），状态靠颜色：完成墨色描边，在跑墨色实心加一圈转动的虚线，
    失败实心红加淡红光，没轮到虚线圈、图标淡；
  - 徽标右上角 ↻（能重做时）；
  - 徽标下面一列小标签：钟表 + 「1:28」（每站用时，完成站写总用时），在跑的站百分比，OCR 站页数，
    翻译站服务商标志 + 这一站的 token（翻译 + 译前准备），版面站精修的 token，没翻全时翻译站一个提醒图标；
  - 整句（「OCR 识别 · 已完成 · 用时 1 分 28 秒 · 共 134 页」）在悬停和读屏里。
- 手机上画面上方留一段空，前两站的标签不压到 HUD 条。

## 用量怎么挂到站上

用量接口按环节分组：翻译、译前准备归翻译站；精修与编辑部跑在渲染阶段，归版面站；助手（问这本书）不归哪一站，只算进合计。
在跑时 token 还在涨，不挂。数是整本书的累计，不是这一次任务的。
