# 「进度」页 HUD 面板，流水线只留徽标

2026-10-31。用户（经后端会话转达）：「卡片部分的多用图标，可以把页数、耗时、模型+使用的 token 的量组成一个图，类似游戏画面里面的那种感觉，
流水线部分的也得去掉文字，尽量用图」。示意图出了两种（A 浅色数据条、B 深色游戏面板），用户选 A。
接着 [用量并进进度页](./20261031-用量并进进度页.md)。

## 状态行下面一块 HUD（四块白底小卡，一行排开，放不下折行）

| 块 | 画面上 | 悬停 / 读屏 | 数从哪来 |
|---|---|---|---|
| 进度环 | 中间状态图标（勾 / 转圈 / ✕ / 暂停），环，下面一个数 | 「已翻译 134 / 134 页」「进度 120 / 900 批」「停在渲染」 | 在跑：任务进度；完成：覆盖接口翻了几页；停下：流水线走到第几站；还没开始：页数 |
| 耗时 | 计时器图标 + 「2:51」，下面按站分段的一条（OCR / 翻译 / 版面按深浅分），图例写每站「1:28」 | 「共用时 2 分 51 秒」「OCR 识别 用时 1 分 28 秒」 | 任务详情的分段计时（job timeline） |
| 模型 | 服务商标志 + 模型名（翻译 agent 带一个 agent 小标） | 「模型 claude-haiku-5-5」 | 覆盖接口里这次任务的 model，没有就用最近一次翻完的 |
| token | 金币图标 + 「128.7 万」，下面输入 / 输出比例条 | 精确值、请求次数 | 这本书的用量（含助手），在跑时不摆 |

算不出来的块不出，不编数。以前这些是标题旁边一个大图标和一行小字，进度条单独一条；现在进度只在环上说一次。

## 流水线只留徽标

- 每台机器上方一个徽标：完成是墨色勾，在跑是转圈（旁边一个百分比），失败是实心红 + 一圈淡红光，没轮到是虚线圈。
  能重做的站旁边一个 ↻，没翻全时翻译站旁边一个提醒图标。
- 站名、状态、用时、实时说明都不画：在每站的悬停（title）和读屏（sr-only）里。各站用时在 HUD 的耗时条上。
- 手机上也一样挂在画面上（以前手机上各站排成一列字放在画面下面）。

## 以后

- 后端在做「OCR 和翻译并行」：两站可能同时亮，翻译多一个 substage `ocr_stream`。HUD 的耗时分段按站各算，流水线徽标按站各画，
  合进来时再看事件。
- token 现在是整本书的累计；要「这一次任务」的，得后端给按任务的用量。
