# 阅读页改进

2026-11-12。

## 为什么

用户：「前端阅读页面我觉得得重点搞。」2026-11-06 起 Studio 不再嵌 RetainPDF，阅读页回到「用户在 RetainPDF 里自己读书」，
而它 10 月以来 73 个提交大半是为 Studio 嵌入和几次大书卡顿修的。三路评估（现状与用户反馈、同类产品对比、代码与性能），
关键结论核对过代码：

- Cmd/Ctrl+F 是浏览器自带的查找，文字层只给眼前的页挂，所以只找得到眼前几页（`use-reader-keyboard.ts` 遇到带 Ctrl/Cmd 的键
  直接放过）；书内搜索回车永远跳第一处（`ReaderFinder.tsx`），书页上不标命中。
- 缩放上限 100%（`reader-zoom.ts` 的 `READER_ZOOM_MAX = 1`），没有适合页宽 / 整页，不接 Ctrl+滚轮和捏合；#151 字太小。
- 目录只靠 OCR 认出的标题块，原 PDF 自带的书签不读（包里没有 `getOutline`）；#146、#133。
- 悬停框给每个读者显示内部翻译编号（`ReaderTextHoverLayer.tsx`）。
- 对照时打开 Markdown 面板退成只剩原文一栏（`ReaderAppReactPdf.tsx` 的 `pdfMode`）。
- 阅读位置、书签只在本机 localStorage；暗色主题不作用到书页。
- PDF 下载失败、段落数据读失败只显示一行字，不能重试。
- 同类产品读者最在意：公式图表不走样（我们的强项）、对照方式能切、原文译文按段互相定位（Doc2X）、引用和图表悬停预览并能
  返回原处（Zotero）、高亮笔记和进度跨设备、护眼配色。

不做：RetainPDF 自己的 AI（2026-11-03 删了）；选中文字弹出菜单（否过两次）。

## 分三批

**第一批（只改前端，快）**

1. 清掉遗留代码：选中菜单的 `selection-pop.css`、AI 批注的样式、`keepMounted` 那套（给终端留的）、`chart-spec.ts`、`entry.tsx`、
   一直是空的 `assistantPdfPane`，过时的说明。多面板的 dock 机制还在为 Markdown 面板用，留到第三批改面板时一起收。
2. 搜索好用：Cmd/Ctrl+F 打开书内搜索（再按一次交还浏览器），回车 / Shift+回车跳下一处 / 上一处，书页上标命中，输入防抖。
3. 悬停框默认不显示内部编号。
4. PDF、段落数据读失败时给「重试」。

**第二批（读起来舒服，只改前端）**

5. 缩放：适合页宽、整页，上限 300%，Ctrl+滚轮和捏合。
6. 目录：先读原 PDF 书签，多级可折叠；没有再用标题块。
7. 护眼和暗色作用到书页（夜间、羊皮纸、豆沙绿），图片公式不反色。
8. 引用和图表悬停预览，跳过去后 Alt+← 回原处。
9. 对照时按段互相定位。

**第三批（要后端或改动大）**

10. 阅读进度存服务端，书卡显示「继续读第 N 页」，打开书自动「在读」。
11. Markdown 面板改成正式的读法：跟着当前页滚、不挤掉对照、只渲染看得到的部分；收掉只剩一个面板的 dock 机制。
12. 大书性能：当前页计算不随页数线性、用元数据预填页高、段落数据按页取（后端）。
13. 真浏览器大书冒烟测试，记下耗时。
