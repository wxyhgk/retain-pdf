# 块分类草案和查看器（2026-10-29）

## 起因

讨论归一化的块分类时，用户提出：**先设计我们自己的分类，再在可视化页面上显示出来**看。
现有 `document.v1` 的分类是从各家服务商的标签一路演化来的：一个块"是什么"写在 `block_class`、`layout_role`、`semantic_role`、
`structure_role`、`sub_type`、`tags` 等多个字段里，同一个概念出现在好几处，细分角色之间不互相核对（9 份快照里有 3 个块自相矛盾），
"翻不翻"由四家适配器各写各的（命令型 OCR 的图注不翻，MinerU、Paddle 的翻）。

这一步只做"我们自己的分类"和看它的工具，不改 `document.v1`、不改归一化。

## 草案（`backend/pipeline/devtools/ocr_viewer/taxonomy.py`）

- **每个块一个类别**，29 个，分在 9 个大类里：版面（页眉、页脚、页码）、前言（文档标题、作者、机构、出版信息、摘要、关键词）、
  标题（章节标题，带级别）、正文（段落、列表项、目录条目）、图表（图、图注、表、表题、图表注、代码块、算法块、代码题注、印章）、
  公式（行间公式、公式编号）、注释（脚注、边注）、文末（致谢、参考文献条目）、未知。
- **属性**：章节标题的级别；图的类型（照片、数据图、示意图）；文字块的排版方向（横排、竖排）。
- **区单独记**：前言区、正文区、文末区、版面。"摘要""参考文献"这类标题都是章节标题，靠区区分，不另立类别。
- **关系只记一处**，在发出关系的块上：题注属于（可指向多张子图，代码题注也用于算法块）、注释属于、编号属于、接续（跨栏、跨页的后半段指向前半段）。
- **行内片段**不是块：行内公式、脚注标记、引用标记、注音。
- 每个类别写明载体（文字、图片、表格、公式、代码）和默认翻不翻。

### v0 → v1：对照 PaddleOCR 和 MinerU 的标签补齐

用户指出 PaddleOCR 有算法块。查了 PaddleOCR 的版面模型 PP-DocLayoutV2（25 类标签，输出按阅读顺序排好）和仓库里 MinerU 的标签表，补上 v0 漏掉的：

| 服务商标签 | 现在归一化 | 草案 v1 |
|---|---|---|
| `algorithm`（两家）、`algorithm_caption`（MinerU） | 并进代码（`legacy_compat.py`） | 新增**算法块**（翻不翻待定：伪代码里的自然语言）；题注用代码题注 |
| `chart`（两家） | 图 | 图，`figure_type = chart` |
| `seal`（Paddle） | 图 | 新增**印章** |
| `aside_text`（两家） | 段落 | 新增**边注** |
| `header_image`、`footer_image`（两家） | 页眉、页脚 | 页眉、页脚，载体是图片 |
| `vertical_text`（两家） | 段落 | 段落，`writing_mode = vertical` |
| `vision_footnote`（Paddle）、`image/table/chart/code_footnote`（MinerU） | 混着处理 | 表注扩成**图表注** |
| `phonetic`（MinerU） | 段落 | 行内**注音** |
| `reference`（Paddle，整个参考文献区） | 区域 | 文末区，不算块 |

参考：PaddleOCR 文档 https://www.paddleocr.ai/latest/en/version3.x/module_usage/layout_analysis.html

## 待定

- 文档标题翻不翻（现在 MinerU、Paddle 翻，命令型 OCR 不翻）。
- 关键词翻不翻；翻的话按词翻。
- 算法块里的自然语言翻不翻（关键字、变量名、符号一律不翻）。
- 这套分类怎么落到 `document.v1`：新加字段，还是把现有几个角色字段改成由它推出（见块分类图解里的两版提案）。

## 查看器

`python -m devtools.ocr_viewer --out DIR`（在 `backend/pipeline` 下）生成 `complex_paper.pdf`、`truth.json`、`viewer.html`。
样例 63 个块，用到 27 个类别（目录条目、未知没有），含跨栏和跨页的接续、两张子图共用一个图注、图表注、算法块、边注、印章（压在文字上）、
页边竖排的 arXiv 编号、公式编号、中英文段落、行内公式和脚注标记。答案在排版时记录，测试检查每一行的框都落在画出来的字上。
