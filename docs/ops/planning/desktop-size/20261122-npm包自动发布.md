# 字体、Typst 的 npm 包自动发布

**日期：** 2026-11-22
**用户：** 「不能自动化的发吗？我不想每次自己搞」

## 做法

`.github/workflows/publish-runtime-assets.yml`：`backend/config/runtime_assets.json` 或 `ops/runtime-assets/` 改了、合进 `main`
时自动跑（也能手动触发）。按清单生成包（`ops/runtime-assets/build_npm_packages.py`，逐个文件核对 sha256），清单里的版本
已经在 npm 上的跳过，其余 `npm publish`。

用 npm 的受信任发布（Trusted Publishing，GitHub Actions 的 OIDC）：仓库里不存 npm token，发布不要验证码。npm 只认登记过的
仓库和 workflow 文件。

## 只做一次的事

1. 第一个版本手动发（受信任发布要在「已经存在的包」的设置页里登记）：2026-11-22 用户在自己终端里 `npm publish` 了 4 个包。
2. 在 npmjs.com 上，每个包（`@retainpdf/font-source-han-serif-sc`、`@retainpdf/typst-darwin-arm64`、`@retainpdf/typst-linux-x64`、
   `@retainpdf/typst-win32-x64`）的 Settings → Trusted Publisher → GitHub Actions，填：
   - Organization or user：`wxyhgk`
   - Repository：`retain-pdf`
   - Workflow filename：`publish-runtime-assets.yml`
   - Environment：留空

以后换字体、升 Typst：改清单（版本号、sha256、大小，`package_version` 要升），合进 `main`，CI 自动发。
