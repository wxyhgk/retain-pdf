# 字体和 Typst 按需下载

**日期：** 2026-11-22
**用户定的：**
- 安装包能小就小，大文件用国内外 CDN、装好后自动下载，电脑上有缓存就不重复下载；
- 首次启动后台下载（不是第一次生成 PDF 时才下）；
- 断网、下不下来时先用自带的后备字体排版；
- npm 包发在 `@retainpdf` 组织名下（组织由用户在 npm 上建）。

## 现在包里是什么

v2026.11.22 的 Linux 包（.deb，压缩后 234MB，解开 733MB）逐项单独用 xz 压缩量出来的大小：

| 部分 | 解开 | 压缩后 | 处理 |
|---|---|---|---|
| Electron 本体 | ~280MB | 84MB | 留着（换外壳是另一件事） |
| Python 标准库和解释器 | 76MB + 死重 | ~40MB（含死重） | 删死重（第 1 步） |
| Python 第三方包 | 96MB | 25MB | PyMuPDF 一个 16MB，以后换掉（顺带解 #97 的 AGPL 冲突） |
| 字体（思源宋体两个字重 + DroidSansFallback） | 52MB | 33MB | 思源宋体按需下载；DroidSansFallback 3.8MB 留着当断网后备 |
| Typst | 53MB | 16MB | 按需下载 |
| Rust 程序 | 64MB | 15MB | 留着 |
| 排版引擎、前端、Word 导出 | ~60MB | 7MB | 留着 |

Python 运行时里的死重（Linux 实测，Mac、Windows 有对应的）：`lib/python3.11/config-3.11-*/libpython3.11.a`
静态库 46MB；`libpython3.11.so` 和 `.so.1.0` 两份一样的 22MB（`rsync -aL` 把软链接解开了）；打进包里的构建日志
`build_output.txt`、`tools_structure.txt` 3.5MB。删这些要改 `frontend/desktop/scripts/runtime-prune.mjs`，交前端会话。

做完以后 Linux 包估计从 234MB 到 170MB 左右，三个平台降幅差不多。

## 第 2 步怎么做

### 发成 npm 包

npm 当 CDN：国外走 `registry.npmjs.org`，国内走 `registry.npmmirror.com`（淘宝源，自动同步，国内稳），不用自己买对象存储。
思源宋体是 OFL 1.1，原样再分发可以；Typst 是 Apache-2.0。

- `@retainpdf/font-source-han-serif-sc`：`SourceHanSerifSC-Regular.otf`、`SourceHanSerifSC-Bold.otf`、OFL 许可证原文；
- `@retainpdf/typst-<平台>`（`darwin-arm64`、`linux-x64`、`win32-x64`）：Typst 官方发布的可执行文件、许可证原文。

`ops/runtime-assets/` 下放生成这些包目录的脚本（取文件、写 package.json、算 sha256 填进清单），由用户 `npm publish`。

### 清单

`backend/config/runtime_assets.json` 是唯一来源（Rust、Python 都读）：每个资源的编号、版本、npm 包名和版本、各文件的路径和
sha256、Typst 按平台分。下载源按顺序试（中国时区先 npmmirror），一个文件 sha256 不对就整包作废、换下一个源。

### 缓存

`<数据目录>/runtime-assets/<编号>/<版本>/`：先下到旁边的临时目录、校验完整再改名，所以要么是完整的一份、要么没有。
升级软件时清单版本没变就不重下；版本变了下新的，旧版本的目录下次启动删掉。

### 谁下载、什么时候下

- Rust 后端启动后，包里没带这份资源、缓存里也没有，就在后台下（首次启动）。接口 `GET /api/v1/runtime-assets` 报每个资源
  的状态和进度，`POST /api/v1/runtime-assets/download` 手动重试；设置页显示进度（前端）。
- 渲染前（runner 进渲染阶段之前）等它下完，最多等一会儿；还没好就照下面的后备走，不让任务卡住。

### 找文件（Python）

`foundation/config/fonts.py`、`external_tools.py` 找字体和 typst 时，在包里带的、环境变量指定的之后，再看缓存目录。
包里带着的优先：Docker 镜像、开发环境、还带着字体的旧安装包，行为都不变。

### 断网后备

思源宋体没有时用包里的 DroidSansFallbackFull.ttf 排（黑体风格、没有粗体），PDF 照样出；渲染报告里记一句用了后备字体。
Typst 没有时只走默认的 rpr_fit，失败就报清楚是缺 Typst、要联网。

## 分三步

1. 删 Python 运行时死重——前端会话（只改打包脚本，没有行为变化）。
2. 后端：清单、下载和缓存、接口、渲染前等待、Python 找缓存和后备字体；包里照旧带着，先不影响现有安装包。
   附带 `ops/runtime-assets/` 的发包脚本。用户建 npm 组织、发包。
3. 前端：打包不再拷思源宋体和 Typst（留 DroidSansFallback），去掉「缺 typst 就报错」，设置页显示下载进度。
