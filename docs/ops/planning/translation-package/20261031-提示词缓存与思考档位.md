# 提示词缓存与思考档位

2026-10-31，接着[普通翻译提速](./20261031-普通翻译提速.md)。四个 Sonnet 子代理调研（开源 PDF 翻译、Anthropic API、我们自己的时间开销、
长尾延迟与商业产品）后用户定："缓存很重要，其他的按你说的做"。

## 发现

- **`thinking=off` 没关掉思考。** Anthropic 协议下 `off` 和 `auto` 都不加思考字段；Claude Haiku 5.5 不加字段时按默认 effort（medium）
  自适应思考。Jensen 第 12 章译文约 2.6 万—3.3 万 token，实际输出 6.4 万 token：一半是思考。
- **没用提示词缓存。** 每个请求带同一份规则，而领域指导和按批检索的记忆夹在规则中间、后面还跟着输出格式和公式规则，
  整段系统提示每批都不一样，就算打了断点也缓存不住。

## A/B（付费，各用空输出目录冷跑一次）

| | Jensen 逐块 / 输出 token | 量子化学-14 逐块 / 输出 token | 质量 |
|---|---|---|---|
| Haiku medium（≈ 以前的默认） | 15.7 秒 / 4.7 万 | 24.7 秒 / 8.6 万 | 句首留了一个英文 "where" |
| Haiku low | 19.8 秒 / 5.0 万 | 18.9 秒 / 5.9 万 | 同 medium，"where" 译成"其中" |
| Haiku `thinking: disabled` | 14.9 秒 / 3.8 万 | 23.5 秒 / 4.4 万 | 5 个短标题（"EXAMPLE"、"We have"）原样交回不翻 |
| qwen3.8-flash 关思考 | 24.7 秒 / 2.2 万 | 33.5 秒 / 2.9 万 | 干净；没有 429；DashScope 自动缓存命中 55% |

`$` 不成对、公式外露、`$$` 漏进正文四组都是 0。逐块时长一次一个数、波动大，档位之间看不出稳定的快慢；low 稳定省输出 token
（输出单价比输入贵得多）。`p014-b022`（"which has the same form as Eq. (8.94)."）medium、low 都被原样交回，是另一个问题。

## 改法

- **系统提示分两段**（`prompt_protocols.protocol_system_parts`）：全书不变的规则（规则、中文体例、输出格式、公式规则）在前，
  文档指导和按批记忆在后，各一条 system 消息。Anthropic 协议下第一段打 `cache_control`（`model_wire.anthropic_system_blocks`，
  第一段不到 800 字不打，关了缓存或太短时照旧一个字符串）；OpenAI 格式接口和 Rust 执行器发送前并成一条（`merge_system_messages`），
  规则仍在前面。内容一个字没改，只是挪了领域指导的位置；冻结基线 28 个用例逐例脚本核对过。
- **缓存预热**：Anthropic 协议开了缓存时先只放 1 个请求，它开始返回后缓存条目才能用；长的先发时首条要跑十几秒，所以最多等
  2.5 秒就放开全并发（`configure_adaptive_concurrency(warmup_max_wait_s=…)`）。
- **思考**：Anthropic 协议下 `off` 发自适应思考 + `effort: low`；`auto` 对 claude-haiku-5-5 也发 low（实测过的模型才调，和
  qwen3.8-flash、glm-5.3-flash 一样）。没用 `disabled`。不支持自适应的旧模型挨一次 400 后不加字段，并记住被拒的字段组合
  （只在报错确实在说思考时记，免得无关的 400 让进程从此不再调档位）。

## 验证（付费，默认参数 `thinking=off`）

| | 逐块 | 输入 / 缓存读 | 输出 | 质量 |
|---|---|---|---|---|
| Jensen | 22.6 秒 | 31.5 万 / 11.6 万（37%） | 4.9 万 | 271 块译文、1 块 "First angle" 原样（medium 也是） |
| 量子化学-14 | 23.9 秒 | 30.8 万 / 11.9 万（39%） | 6.1 万 | 330 块全译 |

缓存读按一折计费：输入费用约省三分之一；输出比以前的默认少两到三成。速度和以前差不多（卡在账号吞吐）。

## 没做 / 以后

- 翻译 agent 引擎（`backend/translation-agent`）有自己的请求，没动；它的初译不发思考字段，同样在按 medium 思考。
- qwen3.8-flash 可以作为便宜的选项（建任务时选，不用改代码）。
- 剩下的第 2、4、5 条（OCR 期间识别领域、OCR 轮询、渲染准备提前）另开分支。
