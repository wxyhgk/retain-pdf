# 原样交回与句首英文

2026-10-31，提速 A/B 里看到 legacy 把模型留下的英文悄悄收下，用户："这两个看看如何搞比较好" → "可以"。

## 现象（付费实测，量子化学-14 / Jensen 第 12 章，claude-haiku-5-5）

| 块 | 原文 | 交回 | 结果 |
|---|---|---|---|
| p014-b022 | which has the same form as Eq. (8.94). | 原样（medium、low 两档都是） | 当成保留原文 |
| p011-b006 等 | EXAMPLE、We have、Matrix Form of the Roothaan Equations | 原样（关思考时） | 当成保留原文 |
| p014-b022（另一次） | 同上 | `which has the same form as Eq. (8.94).其具有与式 (8.94) 相同的形式。` | 英文 + 中文一起显示 |
| p020-b015 | from the electronic Hamiltonian … Let | 先抄原文、空行、再接中文 | 同上 |
| p003-b022、p034-b004 | where … | `where $ \mathbf{r}_{i} $ 是……` | 句首留着英文 |

## 原因

- `llm/result_canonicalizer.py`：译文和原文一字不差、又不是"必须翻"的长正文，就当成保留原文。那条规则是给代码、人名、编号留的，
  可"必须翻"对短文本一律放过（`should_force_translate_body_text`：不到 5—8 个英文词就不算），短句、短标题也一起放过了。
- 抄了原文再接译文、句首留 "where"：和原文不完全一样，过了上面那条；英文残留检查对短文本也放过。

## 改法

- 原样交回、原文里有正常英文单词（首字母后至少两个小写字母，或四个字母以上的全大写词；不算代码、网址、参考文献、
  `DFT` 这类缩写）时**带一句提示重翻一次**（`llm/shared/orchestration/identical_copy.py`，提示走块级风格提示进 prompt）。
  第二次还是原样就照旧保留原文——人名、代号、软件名本来就不该硬翻。批量请求里原样交回的那几块不收、不进缓存，交给单块路径。
- 规整结果时（`result_canonicalizer`）：开头一字不差抄了原文、后面有中文的，去掉抄的那段（`drop_echoed_source`）；
  中文译文以英文 "where" 开头的换成"其中"（`translate_leading_where`）。拿以前所有实测的 4690 块离线跑：只改了上表 4 处，都对。

## 顺带：网络抖动也只降一次

同一次实测 Jensen 逐块翻译 35.6 秒：同一刻两个连接被对端重置（ConnectionError），超时类失败每个都把并发砍一半
（32 → 16 → 8），之后按 12 次成功加 1，结束时才 11 路。现在超时和连接错误也和 429 一样：降速之前发出去的请求不再降，
把降之前的路数记成回升目标、每 2 次成功加 1（`artifacts/aggregator.py`）。

## 验证

- 单测：重翻一次带提示、第二次原样就保留、哪些不算英文、批量交给单块且不进缓存、去掉抄的原文、句首 where、
  连接重置只降一次并很快升回。
- 付费：量子化学-14、Jensen 各冷跑一次（重翻部分）：没有块再被当成保留原文；后两条规则是那次跑出来的新问题，离线验证。
