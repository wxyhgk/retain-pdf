# 桌面端自动更新和 Mac 签名

2026-11-22。用户要桌面端能自己更新，Mac 要签名加公证。用户已有 Apple Developer ID Application 证书和
App Store Connect API key，存在 GitHub 仓库密钥 `MAC_CSC_LINK`、`MAC_CSC_KEY_PASSWORD`、`APPLE_API_KEY`、
`APPLE_API_KEY_ID`、`APPLE_API_ISSUER` 里。

## 用户定的

- **签名放在测试之后**：桌面打包和测试并行跑，打包那一步不许碰任何密钥（合约测试钉着）。签名单独一个
  job，在测试确认通过以后才跑。
- **调试用试验分支**：推到 `trial/mac-sign` 分支就只打 Mac 包、签名、公证（`mac-sign-trial.yml`），不碰 main。
- **同一天再发版**：当天第一版照旧 `YYYY.MM.DD`（如 `2026.11.22`），同一天再发写成「日 + 两位序号」：
  `2026.11.2201`、`2026.11.2202`……。不能写 `2026.11.22-1`：带横杠是预发布版本，比 `2026.11.22` 还小，
  装了旧版的人收不到更新。

## 怎么做的

### Mac 签名和公证

- `build-desktop-packages.yml` 照旧打未签名的包，另外把 `RetainPDF.app` 打成 tar 上传（保留软链接和可执行位）。
- `sign-macos.yml`：一次性钥匙串导入证书 → `frontend/desktop/scripts/sign-mac.mjs` 用 `@electron/osx-sign`
  给包里每个二进制签名（hardened runtime + `build/entitlements.mac.plist`）、`@electron/notarize` 公证并 staple
  → 校验每个 Mach-O 都是 Developer ID + runtime、`stapler`、`spctl` → `electron-builder --prepackaged` 出 dmg、
  zip、`latest-mac.yml` → 解开 zip 再验一次签名 → 钥匙串删掉。
- dmg 不再单独签名：签了 sha512 会和 `latest-mac.yml` 对不上；里面的 App 已经签名、公证、staple。
- 第一次试验时发现 Mac 打包的 `Python.framework` 一直不对：构建机上 `Current` 指着它自己的 Python 3.15，
  清理脚本按它算删除，打包的 3.11 一样都没剪，顶层 `Python`、`Resources` 还是断链。改成先只留打包的版本、
  再剪，最后清掉所有断链：Mac 包里的 Python 从 273MB 到 159MB。
- 苹果账号要先同意最新的开发者计划许可协议，否则公证返回 403（2026-11-22 用户签过）。

### 发版

- `release-desktop.yml` 两条路径都加签名：完整构建走 `sign-macos-build`（等 `quality-gate`、`build`），
  提升走 `sign-macos-promote`（`resolve` 已确认这个提交的 Tests 成功，跨运行取预构建的未签名 `.app`）。
- 发布按平台下载：Windows、Linux 用打包产出，Mac 只用签好名的那一套。
- `release_candidate_manifest.py` 的清单多了 `extras`：Windows 的 `Setup.exe.blockmap`、`latest.yml`，Mac 的
  zip、`zip.blockmap`、`latest-mac.yml`。发版时 `--require-extras`，一个都不能少、sha256 要对，SHA256SUMS 也列上。
- Release 多传这些文件，electron-updater 从 GitHub Release 读 `latest*.yml`、按 `.blockmap` 增量下载。

### App 里

- 主进程 `frontend/desktop/src/main/app-updater.js`：只在打包后的 Windows、Mac 上启用；启动 30 秒后检查一次，
  之后每 6 小时一次；有新版自动下载，状态推给页面；`update_install` 调 `quitAndInstall`，走正常退出（先收尾后端）。
  不点也行：下次正常退出时自动装。
- 页面：设置里的「检查更新」在桌面端改走主进程；下载中显示进度，下好以后给「重启并更新」。后台检查出错不打扰，
  自己点的检查出错才显示。Linux 的 deb、旧版桌面壳、网页端照旧查 GitHub Releases、跳转下载。
- Windows 没签名也能自动更新，只是第一次安装时 SmartScreen 会提示。
