# Release 说明放下载表（2026-11-23）

## 问题

v2026.11.23 的 Assets 有 11 项：三个安装包，加上自动更新用的 `latest.yml`、`latest-mac.yml`、Mac 的 `.zip`、两个 `.blockmap`，
还有 `SHA256SUMS.txt` 和 GitHub 自动加的两个源码包。用户觉得乱，想只留三个安装包。

## 决定

- **保持现状**，不删文件：
  - `latest*.yml` 是已安装的软件检查更新时读的，删了所有人都收不到更新；
  - Mac 的自动更新只能用 `.zip`；
  - `.blockmap` 让更新只下载变了的部分；
  - 源码包是 GitHub 加的，删不掉。
- GitHub 的 Assets 只按文件名字母序排（不分大小写），**不能调整顺序**，`latest*.yml` 总排在安装包前面。
  改名不划算：`latest*.yml` 的名字是 electron-updater 定死的。
- 改为在 Release 说明里放一张三个安装包的下载表（中英文），写明自动更新用的文件不用下载。
  发版 action `.github/actions/publish-desktop-release/action.yml` 的「Write release notes download table」生成，
  `softprops/action-gh-release` 用 `body_path` 写进说明；v2026.11.23 已手动补上同样的说明。

## 没选的

- 把更新文件挪到单独的固定 Release（例如 `updates`）：要改桌面端的更新地址，还要先发一版过渡，旧版本才接得上，划不来。
- 只留安装包：等于关掉自动更新。
