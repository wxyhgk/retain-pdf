### 提问

- **右键 →「在这里提问」**，和画笔小菜单是同一个菜单（Shift + 右键照旧是浏览器自己的菜单）。
  - 选着字时问这段字（菜单里写「问选中的这段」），没选字时问点到的那一块。
  - 点了以后**不在书上弹输入框**：白板浮窗打开（关着就开），新放一张卡片，卡片顶上写着出处和引的那段原文，光标在卡片的输入框里。
- 问过的地方，书页左边白边里一个**小问号**（三栏都画：锚在原文上，译文栏按对应的块画）。点问号 → 白板打开、移到那张卡片、闪一下。
- 白板底下也能直接问一句（不挂在书上的问题），卡片照样放在白板上。

### 白板（无限画布）

- 一本书一张白板（以后要分章再说）。拖空白处移动，滚轮 / 触控板缩放，「回到全部」一键看全。
- 上面有三种东西：
  1. **问答卡片**：问题、AI 的回答、出处（点了书跳过去并亮那一块）、追问记录。回答是文字和公式；要推导的在卡片里用现在的白板讲解
     （`@retainpdf/whiteboard` 的脚本，一步步写）。卡片能拖、能折叠。
  2. **你写的东西**：文字框、公式框（LaTeX）。手写笔迹第二版（`perfect-freehand`，MIT）。
  3. 以后：卡片之间的连线。
- 新卡片放在当前视野里没占的地方，不压住别的卡片。

### 笔记

- 一本书一份，按段落写，支持公式（`$…$`）。
- 卡片上「记到笔记」：把这条问答的要点和出处加到笔记末尾（出处是链接，点了书跳过去）。
- 笔记里也能插「这一页」的出处（按钮，取左栏当前页）。

### 浮窗

- 白板、笔记各一个浮窗：标题栏拖动，四边和角拖着调大小，「_」收成一个小条，「□」放大到盖住书（再点回来），「✕」关掉。
- 位置、大小、开没开**按书记住**；窗口不出屏幕（拖的时候按窗口真实大小算边界——上次浮窗就坏在估高度上）；点哪个哪个在上面。
- 快捷键：**W** 开关白板、**M** 开关笔记（现有的 1/2/3、J/K、D、P、N、E 都不动）。
- 窄屏（手机）：浮窗变成从底下拉上来的整宽面板，一次一个。

## 代码怎么分（解耦）

阅读器不认识白板、笔记、AI，只多开几个**通用能力**（替掉 `sidePane`）：

| 阅读器给宿主 | 说明 |
|---|---|
| 右键菜单加项 | 宿主给 `{ id, label, onSelect(ctx) }`；ctx 是这个位置：页码、块编号、块开头原文、选中的字、哪一栏 |
| 页上标记 | 宿主给一组 `{ key, anchor, kind, label }`，阅读器在三栏的页边画（问号等）；点了回调 |
| 按锚点跳 | 现有的 `navigateToAnchor`（块编号 → 页上原文 → 只翻页） |
| 浮层 | 宿主的东西（浮窗）画在阅读页上面一层；拿到上面这些能力和「现在第几页」 |

包：

| 包 | 管什么 |
|---|---|
| `@retainpdf/ui` | 通用的浮窗 `FloatingWindow`（拖、调大小、收起、放大、记住位置、不出屏） |
| `@retainpdf/whiteboard` | 加无限画布 `Board`（平移缩放、卡片、文字框、公式框）；现有的讲解脚本播放器留着，卡片里用 |
| `@retainpdf/learning` | 问答（提问、卡片、追问、问号标记的数据）、笔记、两个浮窗的内容；不认识阅读器 |
| `frontend/web` | 一个文件把阅读器的能力接到 `@retainpdf/learning` 上（取代 `learning-side-pane.tsx`） |

## 数据

- 都锚在**原文**上（页码 + 块编号 + 开头几个词），和批注的决定一样（2026-11-21），换译文版本不受影响。
- 第一版存在本机（IndexedDB，按书），带版本号。以后进书库的「条目」（数据库重做时定的 Zotero 式条目表：笔记、批注都是条目），可以同步。

```text
Question   { id, anchor, quote?, selectedText?, createdAt, thread: [{ role: "user" | "ai", text, scriptId? }], cardId }
BoardItem  { id, kind: "question" | "text" | "math", x, y, w, h, collapsed? , questionId? , text? }
Note       { bookKey, blocks: [{ id, text, sources: [anchor] }] }
```

## AI 的回答从哪来

**这一步不接模型**：演示数据（Szabo 第 3 章）里配几条写死的回答（自洽迭代、交换积分、总能量），其余写「还没接模型」。
真接模型要后端（或桌面端的 AI 通道）给一个「带上下文问一句」的接口：上下文是锚点那一块的原文、译文、前后几段，以后加学习记录。
这件和后端一起定，不在这份里。
