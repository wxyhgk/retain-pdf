# 学习区界面（「学习」页签的右栏）

2026-11-25。用户：「先设计前端」，看过下面的画面后说「可以」。原型代码在 `frontend/packages/learning`，
数据全是写死的（Szabo 第 3 章），不接模型、不接后端。「怎么讲才能让这个人懂」的教学法另议。

## 结构：右栏三层

```
┌ 右栏 ───────────────────────────────────┐
│ ① 顶：在哪一章                       ✕ │
├────────────────────────────────────────┤
│ ② 中：主区（A 本章地图 / B 知识点卡 /      │
│        C 做题 / D 讲解 / 问答，换着显示）   │
├────────────────────────────────────────┤
│ ③ 底：随时提问  [第129页 · Fock 算符 ✕] … │
└────────────────────────────────────────┘
```

提问框一直在底部，自动带上「第几页、在看哪个知识点」（正在看的点优先，否则是这一页上的第一个点），点 ✕ 不带。

- **A. 本章地图**：会了 / 卡住 / 疑似误解 / 未测的计数和进度条；按小节列出知识点，状态点和书页左边的小圆点同一套颜色；
  左栏翻到哪一页，这一页上的点高亮；每行带 `p.129 ↗` 回书里看；底部「从卡点开始」「测一下这一章」。
- **B. 知识点卡**：出处（回书里看）、一句话说明、**依据**（做过的题、对没对、哪天、第几级提示——不显示掌握度小数）、
  前置（带状态，点了去那个点）、问过几次；「测一下」「讲给我听」「看一道例题」。
- **C. 做题**：题干、选项（公式用 MathJax）、「我不知道」；诊断题问 1–5 分信心；答错后「给我一点提示（第 N 级）」「讲一讲」；
  提示一次只升一级，最后一级直接给答案、这题记为答错。
- **D. 讲解**：白板（@retainpdf/whiteboard）一步步讲，下面「这一步在书里 p.129 ↗」；只有三个按钮：还是不懂 / 换个说法 / 懂了，出题验证。
  说「懂了」不改状态，只出下一道题。
- **问答**：问题在上、回答在下，带推导的回答直接用白板；下面「懂了，出题验证」；问过的按知识点计数。

## 规则写在代码里（`state/session.ts`，原型版的 Orchestrator）

| 情形 | 状态 |
|---|---|
| 不看提示、第一次答对 | 会了 |
| 看了提示才答对 | 不变（没测过的记成卡住） |
| 答错、选「我不知道」、看了答案 | 卡住 |
| 诊断题信心 4、5 分答错 | 疑似误解（以后走推理 → 预测 → 反例三步确认，原型只标出来） |

## 和阅读器怎么接

学习区不认识阅读器，只要三样（`LearningHost`）：跳到书里、设页边小圆点、现在第几页。`frontend/web/src/app/reader/learning-side-pane.tsx`
把阅读器的第二栏口子（[阅读页第二栏](../../../core/frontend/reader-side-pane.md)）接到它上面。原型里「学习」页签演示模式一直有，
真书只在 Szabo 那本任务（`20261101161029-662f61`）上出现，锚点是那本书的块编号，页边小圆点画在真书上。

## 原型没做的

- 「放大」（白板临时占满整个阅读页）：要阅读器多给一个能力，等确定要再加。
- 答题记录不存（刷新就回到演示的起始状态）；没有复习排期、Hook、记录时间线。
- 「换个说法」只有一种讲法；提问只按关键词配三条写死的回答，其余回「还没接模型」。
- 题、提示、讲解是草稿，物理内容等用户审。
