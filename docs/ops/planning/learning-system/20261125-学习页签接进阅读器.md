# 学习页签：学习系统怎么接进 PDF 阅读器

2026-11-25，设计稿，未开工。接 [白板讲解板](./20261125-白板讲解板.md)。

## 定下来的（用户 2026-11-25）

1. **「学习」做成阅读页顶栏的第四个页签**（原文 | 对照 | 译文 | 学习），左边是书、右边是学习区；不做成右侧窄面板。
2. **页边小圆点第一版就做**：学习页签里，书页旁边标出这一段对应的知识点会没会，点了跳到右边那个点。
3. **demo 用 Szabo & Ostlund《Modern Quantum Chemistry》**，书库里的任务 `20261101161029-662f61`（翻译过），第 3 章 Hartree-Fock。

## 不变的规矩

阅读器以前加过又删掉的：划词弹「问 AI」、浮条、批注、收藏（见 git 历史和记忆里的说明）。所以：

- **原文 / 对照 / 译文三个页签一点不变**：不加按钮、不加标记、不加弹窗。学习相关的东西只在「学习」页签里出现。
- 学习页签里也不做划词弹窗；书和学习区之间靠「回书里看」和页边小圆点来回跳。

## 布局

```
┌ 原文 │ 对照 │ 译文 │【学习】 ─────────────────────────────────────────┐
│ 左：书（原文 / 译文可切）            │ 右：学习区（宿主提供）              │
│                                      │ ┌ 第 3 章 · 知识点 ─────────────┐ │
│ ●  3.1.2 The Fock Operator           │ │ ● 变分原理            会了    │ │
│ ┃  ...（当前知识点的出处，左边细色条）│ │ ● Slater 行列式       卡住 ◀ │ │
│ ○  ...                               │ │ ○ Fock 算符           未测    │ │
│ ↑页边小圆点：这一段对应的知识点       │ └───────────────────────────────┘ │
│                                      │ ┌ 题卡 / 白板讲解 / 新题 ─────────┐ │
│                                      │ │                  [回书里看 ↖]  │ │
│                                      │ └───────────────────────────────┘ │
└──────────────────────────────────────┴───────────────────────────────────┘
```

- 左右各一半，分隔条能拖（复用对照模式的布局，但右栏不是 PDF，不做行对齐）。
- 左栏顶上一个小开关切原文 / 译文，默认跟上次一样。
- 右栏两种状态：**知识点列表**（本章所有点和状态：会了 / 卡住 / 未测 / 疑似误解）和 **一节学习**（题卡 → 白板讲 → 新题 → 结果）。开始学习后列表收成一行，给白板让位置。
- 窄屏（手机）：左右改成上下，或者学习区盖在书上、带「回书里看」返回。

## 书和学习区之间怎么跳

- **学习区 → 书**：题卡、讲解、结果上都有「回书里看」，左栏滚到出处并闪一下（细色条，和改译文后的定位同一种效果）。
- **书 → 学习区**：页边小圆点。颜色表示状态（会了绿、卡住红、未测灰空心、疑似误解橙），悬停写知识点名字，点了右栏跳到那个点。
- **跟着读**（可选）：左栏翻到哪一页，右栏列表里这一页上的知识点高亮。

## 锚点：知识点挂在书的哪里

每个知识点记一个或几个锚点：

```json
{ "page": 129, "item_id": "p129-b000", "quote": "3.1.2 The Fock Operator" }
```

- `page` 是 PDF 页码，`item_id` 是 OCR 块编号，`quote` 是那一块开头的一小段原文（只存几个词，书有版权，仓库里不放大段原文）。
- 定位顺序：先按 `item_id` 找块；找不到（重新 OCR 过）就在那一页上找 `quote`；都找不到就只翻到那一页。
- 锚在**原文**上，不锚译文：换译文版本、改译文都不影响。和 2026-11-21 定的「批注锚在原文上」是同一套，以后笔记、批注共用。

## 代码怎么分

| 包 | 管什么 | 认不认识阅读器 |
|---|---|---|
| `@retainpdf/whiteboard` | 只渲染讲解脚本 | 不认识 |
| `@retainpdf/learning`（新） | Orchestrator（纯函数，按事件决定下一步）、答题事件、题卡 / 学习区界面（内部用白板） | 不认识 |
| `@retainpdf/reader` | 只加通用口子（下面三个） | 不认识学习系统 |
| `frontend/web` | 把学习区装进阅读器 | 两边都认识 |

阅读器加的三个通用口子，以后插件系统「往阅读器里加面板」也走这几个：

1. **第二栏内容由宿主提供**：宿主给了，顶栏才出现「学习」页签；没给（比如纯本地 PDF、没有知识图的书）就不出现。
2. **按锚点跳转并闪一下**：`navigateToAnchor({ page, item_id?, quote? })`，返回找到了没有。
3. **页边标记**：宿主给一组 `{ anchor, tone, label, onClick }`，阅读器只在这个页签里画在页边。

另外阅读器往外报「当前看到第几页」，给「跟着读」用。

## demo 的数据

- 知识图、锚点、题目、误解表、讲解脚本放在 JSON 里，按书对应（书的 `document_id`；demo 阶段先按任务编号）。
- 答题事件先存在浏览器里（IndexedDB），不碰后端；学习者状态由代码从事件重新算。
- 演示模式（mock）另放一份小的假书和假知识图，给截图测试和没有 Szabo 的人用。
