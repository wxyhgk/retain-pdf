# 人文书初译写法：按句群重组、通读不钉日常词、章首小型大写

2026-11-19。

## 起因

用户贴了一本民族志开头三段的出版译本，问为什么明显比我们的好，是模型不行还是流程不对。我们的版本是任务 20261118122219-8976b1，用 deepseek-v4-flash 初译，同一个模型当编辑。

我逐句对了原文、我们的初译、编辑终稿和出版译本：

- **出版译本**：顺得多，但有错。
  - 把"觉得该被放行了"写成"我终于获准进入田野了"，和下一段矛盾；
  - "flown"译成"赶到"；
  - 删了 "Nor did he commit to access after I caught…" 一句；
  - 添了"天时地利人和""更糟糕的是"。
- **我们的版本**：意思对，没漏没添。毛病有三处：
  - 一句对一句、照英文语序；
  - 比喻照字面译（"那么多扇门在我面前砰地关上"）；
  - 通读把 access 定成必须照用的"进入"，写出"进入的事始终没有着落""也没有答应让我进入"。
- **编辑那一轮**（同一个 flash 模型）：主要把句子切得更碎，文笔没提上去。

## 实验

用户同意后跑了一组实验：同一本书第 12–14 页、同一份通读和术语表，分四组。测试密钥里没有 deepseek，初译用 qwen3.8-flash 代替。

| 组 | 初译 | 编辑 | 流程 | 输入 / 输出 token |
|---|---|---|---|---|
| A | qwen | qwen | 现在的 | 17.9k / 2.6k |
| B | qwen | Haiku | 现在的 | 21.6k / 4.0k |
| C | qwen | qwen | 人文写法 + 术语表去掉 access | 18.4k / 2.0k |
| D | Haiku | Haiku | 人文写法 + 术语表去掉 access | 27.1k / 6.5k |

结果：

- **A → C**：习语和个别句子好了一点（"处处吃闭门羹""似乎是个好兆头"），句式还是一句对一句。术语表里已经没有 access，qwen 照样写"谈妥进入的事""承诺让我进入"。
- **B**：编辑在直译的底子上换了几个词，改不动句式。
- **D**：最接近出版译本的节奏（"一时没看清""他也没有因此松口""这一关"），也没犯出版译本的那几处错。但有一个硬错："CATCH," HE CALLED OUT LOUDLY 被 Haiku 初译成"咔嚓一声，他朝我大喊"，编辑也没改回来。书的章首用小型大写，OCR 出来是全大写，模型把 CATCH 当成了拟声词。

结论：模型是主因，流程是放大器。光改流程，flash 模型只能好到 C 的程度；要接近 D，人文书的初译得用 Haiku 这一档的模型（由用户按费用定）。

## 用户定的：改三处

1. **人文书的初译写法**：通读判成人文社科、通俗读物（`rewrite.REWRITE_GENRES`）的书，初译和重翻在系统提示后面接一段 `NARRATIVE_PROMPT`，内容是：
   - 按句群用中文语序重组，可以拆句、并句，不必和原文长度相当；
   - 比喻、习语换成中文惯用说法；
   - 抽象名词化成动词和具体说法，不写"进入的事"这种名词腔，术语也只照用概念；
   - 意思不增不减，保留语气，不提前说出作者当时还不知道的结果。

   改稿（缩字数）不接这一段，免得和"不超过 max_chars"冲突。理工书的请求逐字节不变。调度从通读结果设 `agent.narrative`，续跑时从 `reading.json` 读回，跑完复位。
2. **通读不钉日常词**：通读提示词的术语一条加了要求：人文社科、通俗读物只收本学科的行话（如 field 译田野、gatekeeper 译守门人）和专名；反复出现的日常词（access、handling、commitment、donation、support）不收。只改了提示词，没有程序兜底：哪些算日常词没有可靠的词表，交给通读模型判断。
3. **章首小型大写**（新模块 `typography.py`）：调度开头把正文段落开头连着两个以上的全大写词还原成句首大写，例如 "CATCH," HE CALLED → "Catch," he called。之后通读、初译、编辑看到的都是修过的原文。
   - 后面至少要有 3 个小写词才动，所以整块大写的标题不动；
   - 标题、目录条目、页眉页脚这几类块不动；
   - 开头那串里的词如果在这段后面又以全大写出现，当缩写保留（如 FBI）；
   - 单独的 I 保持大写。

提示词版本升到 `translation-agent-18`（通读和人文书初译的请求变了）。检查规则没变。

## 验证

- `backend/translation-agent/tests/test_humanities.py`：
  - 小型大写还原：引号、I、数字、后文出现的缩写；
  - 标题、单个缩写、整块大写不动，没改的页原样复用；
  - 人文书的初译和重翻带写法要求，改稿和理工书不带；
  - 调度从通读结果打开、跑完关掉，续跑从 `reading.json` 读回；
  - 小型大写在发出去的请求里已经修好；
  - 通读提示词里有不收日常词的要求。
- 改完没有再跑真模型。上面的实验用的提示词和这里接上的写法要求内容相同；通读那一条改了，要在整本书上重跑才看得出效果。
