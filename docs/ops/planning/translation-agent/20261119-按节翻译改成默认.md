## 评测样例的结果

都是盲评，用户不知道哪份是哪个做法：

| 样例 | 比的是 | 用户 |
|---|---|---|
| 1 · 《The Interloper》导论第 12–17 页 | Haiku 按节翻 vs 最强模型走第一版、翻译社 | 按节翻更好，部分段落比翻译社好 |
| 2 · 《The Interloper》第 46–51 页（田野叙事） | Haiku 按节翻 + 审意思 vs 原来的正式译文（第一版，qwen3.8-flash） | 按节翻更好 |
| 3 · 《Infidelity》手册第 70–75 页（临床讲解夹案例） | Haiku 按节翻 + 审意思 vs 原来的正式译文（老流程，Qwen3.8-27B） | 按节翻更好 |
| 1（qwen） | qwen3.8-flash 按节翻 + 审意思 vs qwen3.8-flash 第一版（正式译文） | 「还行吧」，第一版好一些些 |

qwen 按节翻没有压缩内容（三份译文每段的汉字数差不多，6 页合计 3201 / 3275 / 3260），差别在写法：结构给了模型发挥的余地，
qwen 自己写不出明显更好的中文。技术上 qwen 走第二版没问题（一节一次翻、一次审，22 块全译，没退回逐块），OpenAI 协议的换算层
不往下传 `max_tokens`，一节的长回答由共用请求层管。

## 用户定的：A

人文社科、通俗读物一律默认按节翻，不分模型（另一个选项是只给 Anthropic 一档的模型开，qwen、deepseek 照旧第一版）。理由：
Haiku 明显变好；qwen 和原来差不多，请求少四分之三（同样 6 页，第一版十几次请求、约 4.5 万输入 token，第二版 2 次、约 1 万）；
两套流程长期并存，以后改一处要维护两处。

- `agent_flow.agent_structure()`：没设或别的值都按节；`RETAIN_AGENT_STRUCTURE=page` 退回逐页（第一版）。
  论文、教材等别的体裁不受影响，照旧逐页。
- 断点指纹：逐页的指纹不变，按节的带 `+structure:section`。上线时正在翻、之后重试或续跑的人文书会从头按节翻（OCR 照用；
  逐页时的请求缓存用不上）。
- `DocumentRun` 自己的默认、agent_lab 的默认照旧是逐页（做对比用），正式流程由 `agent_structure()` 传进去。
