# 编辑重写和翻译腔

2026-11-18。用户：人文类的书读着还是怪，例如"他最先联系的那位法医同样设置了阻碍"；问要不要加文笔 agent、要不要多轮翻译。

## 实验

The Interloper（Anteby，2024，209 页民族志）第 41–46 页 20 块正文，共用这本书已有的通读结果和术语表，六组各跑一遍：

| 组 | 配置 | 用量（token） | 看下来 |
| --- | --- | --- | --- |
| 1 | 现流程（初译 + 挑错审校），qwen3.8-flash | qwen 入 3.7 万 / 出 0.36 万 | 意思准，翻译腔原样："一堂硬课""厚实的脸皮""表现出阻碍态度" |
| 2 | 现流程，claude-haiku-5-5 | Haiku 入 5.5 万 / 出 0.83 万 | 最像中文书，主动补推测语气；直引号，"设置了阻碍" |
| 3 | qwen 初译 + qwen 编辑重写 | qwen 入 3.7 万 / 出 0.55 万 | 改了 7 块，几乎没变好：qwen 看不出自己的翻译腔 |
| 4 | qwen 初译 + Haiku 编辑重写 | qwen 入 2.3 万 / 出 0.17 万；Haiku 入 1.4 万 / 出 0.36 万 | 改 12 块，拆句、理顺语序，接近第 2 组；会添词（"说实话"），漏改 programs → "程序" |
| 5 | 第二轮：同第 4 组，加下面三条 | qwen 入 2.7 万 / 出 0.2 万；Haiku 入 1.9 万 / 出 0.5 万 | "他联系的第一位法医百般阻挠"；还会添"大概""其实" |
| 6 | 第二轮：全 Haiku（初译 + 编辑） | Haiku 入 5.8 万 / 出 1.1 万 | "他最先联系的那位法医处处设阻，不肯配合"；最稳 |

第二轮的三条：术语 obstructing 从"阻碍"换成"阻挠"（手动改，模拟通读选对词）；初译提示放宽术语的词形；编辑先只读中文、带翻译腔清单、
程序圈出可疑句式。程序数的翻译腔（和交给编辑的清单是同一份规则，偏乐观）：第 1–4 组各 6 处，第 5 组 0、第 6 组 1。

## 结论

- 文笔主要是模型能力：同一个弱模型自己当编辑（第 3 组）没用；强一点的模型当编辑（第 4、5 组）明显变好，花费是全用强模型的三分之一左右。
- 流程上也有毛病，而且是"设置了阻碍"这类怪句的直接原因：
  1. 术语选词：通读按词典第一义项把 obstructing 定成"阻碍"（无主体的妨碍），书里是人有意去拦，该是"阻挠"，后者有现成搭配；
  2. 术语表把名词硬塞进每个词形（proved obstructive → "设置了阻碍"）；
  3. 审校只收"确实错了"，没有任何一步管文笔。
- 不另加文笔 agent，也不做多轮：把每页第二遍从"挑错打补丁"换成"编辑整块重写"，一页仍是一次请求；按需重翻的轮次照旧。

## 做法（feat/agent-rewrite-pass）

- `rewrite.py`：编辑交回整块译文。裁判：校验错误不变多、保留语气和人称不新丢、术语不更违反、长度在初译的 0.7–1.4 倍、
  "说实话""其实""显然""当然""大概""也许""或许"改完比初译多而原文没有对应英文的不收。
- `translationese.py`：按句式圈出可疑处（虚动词配抽象名词、"表现出……态度"、"进行……"、句首"通过……，""作为一名……，"、
  "所……的"、一串"的"、被字句、"风味"、重复的"同样"），放进每块的 `suspects` 交给编辑；编辑提示先只读中文、再对照原文。
- 调度：通读判成 humanities、popular_book 时第二遍用编辑重写，其余照旧挑错。
- 初译提示（版本 17）：术语管概念本身，词形变了按中文习惯说。通读提示：人文概念按"谁在做、是否有意"选词并试搭配。
- 编辑模型复用建任务的 `reviewer_*`：模型名和翻译模型不同、Key 可用时按模型名把审校、编辑的请求分到它的连接；用量台账按模型记。
