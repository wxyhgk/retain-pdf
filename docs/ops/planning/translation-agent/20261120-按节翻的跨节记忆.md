# 按节翻的跨节记忆

2026-11-20。第二批的第一个分支（第二批的另一半是意思闸门，另开分支）。

## 起因

按节翻整本书的术语只来自开头通读那一次，之后谁都补不进去；「前文已出现」只给人名记，缩写没有；节与节之间只传上一节最后两段。
《The Interloper》里 AGVA 三节三种译法（美国综艺艺人工会、美国演员工会……），TSA 第一次写成「TSA（Transportation Security
Administration）」（缩写那一行给的是英文全称），同一个人名在不同节各自括注原文。Sonnet 审读也把「一致性来源单一且静态」列为三个结构问题之一。

## 改了什么

- **节译者附两节**（`SECTION_NARRATIVE_PROMPT`，没有就不写）：「@@ 新词」这一节第一次出现、上面没给译法的人名、机构、缩写、专门说法，
  每行「原文 | 译法」，缩写写中文全称；「@@ 梗概」一句话这一节讲了什么。`section.split_tail` 先切掉这两节再解析段落。
- **核实了才记**（`section.learn_section`）：原文要真在这一节某段里、译法要真在那段的译文里。按样子分：全大写是缩写，
  记中文全称（`Term.zh_full`，第一个为准，`Glossary.learn_abbreviation`）；每个实词大写开头是专名（`NAME`），其余是术语，
  交给 `Glossary.propose`（候选，不同的块报够两次升审定；`propose` 现在也收 `NAME`）。
- **审校采纳的短专名、缩写改法也记**（原文 ≤ 4 个词、改法 ≤ 16 字）。
- **缩写那一行**：知道中文全称时写「第一次写『运输安全管理局（TSA）』，之后只写 TSA」；不知道时要模型把全称译成中文；
  前面出现过的写「前文已出现，只写 TSA」。
- **调度**（`runner._run_sections`）：前面出现过的人名、缩写每节重新取（新学到的也算）；术语表每节存盘；
  本章各节的梗概攒起来传给同一章后面的节（最多 6 句、600 字），续跑时从存盘的页记录读回。
- 版本：`agent-section-6`（提示词变了）。

## 实测（Haiku）

- 第 60–100 页（5 节，复用原来的通读）：学到 60 多条人名、机构、缩写，多数是这几章第一次出现的（吉姆·汉森、全国劳资关系委员会（NLRB）……）；
  AGVA 第一次写「美国综艺艺人协会（AGVA）」之后只写 AGVA（正式那次两处两种译法），TSA 一次全称、9 处只写缩写，HBS 一次全称、4 处只写缩写；
  梗概一节节传下去。
- 这次 3 节第一遍漏了脚注标记、重交才补上（正式那次同样几节一次过）。怀疑是附两节的要求分了心，拿第 79–87 页这一节
  带、不带新要求各翻 3 次：六次都一次过、没有漏标记，带要求的每次报 7–15 个新词、都有梗概。是偶然，不是新要求造成的。
- 学到的词里个别直译得不好（talking head →「说话的脑袋」），只是候选，报两次才升审定。
