# 跨页一段话被拆成几截

2026-10-31。用户："p009-b0005 p009-b0006 你看看为什么没有连上"（ACS 论文，翻译 agent）。

## 查到的

这段话其实跨了 3 页 5 块：`p008-b021` → `p009-b005` → `p009-b006` → `p010-b010` → `p010-b011`（第 9、10 页最上面都是整幅图和图注，
正文只在页底）。接续判定（翻译包 `services/continuation/`，两种翻译引擎共用）把它分成了三份：

- **页首是图注就不算页首**：跨页只接"上一页正文的最后一块 → 下一页正文的第一块"，头尾用的是版面分区的 `layout_boundary_role`，
  而分区排序把图注也算进去。第 9、10 页最上面是图注，下面第一段正文被标成 middle，跨页判定不让直接接。
- **链条延伸时被拒的那一对没人复核**：主循环里"规则说该连、头尾不对"的一对会标成候选交给模型复核；但 `p009-b005 → p009-b006`
  连上以后往下延伸到 `p009-b006 → p010-b010`（"As macro-" / "phages are …"，一个词断在两页）被拒时，直接断开，没标候选。
- **复核连组时覆盖了原来的组**：`p008-b021 → p009-b005` 是复核通过的，程序给这两块另起组号，覆盖了 `p009-b005` 原来和 `p009-b006`
  的那组，`p009-b006` 落单单独翻。

## 改法

- 跨页的头尾只在能接续的正文块里算（`state._body_boundary_roles`）：页首的图注、图片不占页首；分区排序不全（缺块、测试里手写的头尾）时照旧用 `layout_boundary_role`。
- 链条延伸时"该连但头尾不对"的一对也标成候选交给模型复核。
- 复核通过的一对连成组时，两块原来所在的组整组并进来，按阅读顺序排成一串（并查集），不覆盖。

  上一版复核也都判了连；别的组没变。
