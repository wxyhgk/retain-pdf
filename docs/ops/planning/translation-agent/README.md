# 翻译 agent

让大模型像人一样翻译：看块的类别、大概位置、文字和上下文，一次看一整页，逐块交回译文；放不下的块再交回去缩写。
平时不看图，只有翻译图片、表格时才看。译文显示用 HTML（阅读器的实时覆盖）。
文件名用 `YYYYMMDD-主题.md`，新的决定追加新文件，旧文件保留不改写。
