# 书名统一和同文同译

2026-11-20，分支 `fix/agent-book-title`。前端在阅读页看到、用户让后端看怎么处理。

## 起因

《The Interloper》（任务 20261119033954-b3f920）：封面、目录里的书名是「闯入者」，书名页上的 "THE INTERLOPER" 是「不速之客」。
通读员按块号给每个标题定译法；书名页上的大写书名被 OCR 认成正文块，不在标题清单里，由逐页翻的译者自由发挥。
同一个书名、同一个副标题全书译法应当一样。

## 做法

- **通读员交书名译名**：`submit_reading` 加必填字段 `book_title`（书名 `document.title` 的中文译名，不带书名号）。
  设成可选时 haiku 常常不交，所以必填。提示词版本升到 `translation-agent-23`。
- **原文相同的标题只问一次**：`read_document` 按「同一句原文」（不分大小写、不计标点空白，`same_text_key`）合并标题，
  一组里有正文标题就拿正文标题去问，译文套到组里每个块。以前分批时封面、书名页、目录里同一句可能落在不同批。
- **同文同译**（`apply_reading`）：书名做标题时用书名译名；原文和某个已定标题、或和书名（含冒号前的主标题）一样的短块
  （16 个词以内：书名页上被认成正文的大写书名、副标题、页眉上的章名），直接用同一个译文，不再交给译者。
- **书名不进术语表**：术语匹配不分大小写，书名是普通词组（"The Gift"）时会把正文里的 the gift 也锁成书名译法。

## 顺带修的两个问题（同一次实测查出）

- **全大写被当成没东西可翻**：「没东西可翻的块算保留原文」（同一天合并）判断「有没有要翻的英文词」只认带小写的词，
  "THE INTERLOPER"、"CONTENTS"、全大写的副标题都被跳过了。现在四个字母以上的全大写词也算（三个字母的 DNA、USA 仍算缩写）。
- **交给 agent 之前标成保留原文的块没存盘**：只存 agent 交回结果的页，整页都保留原文的（书后索引、注释页、书名页）
  存下来的还是「要翻、没状态」（同一天合并的「书后索引保留原文」也这样，实测那本书 95 块索引都是空状态）。现在标完当场存盘。

## 实测

分支代码真跑《The Interloper》前 20 页（agent + haiku）：通读员交回书名「闯入者」；封面、书名页（第 2、10 页的大写书名）、
目录里的书名都是「闯入者」；大写的副标题和标题下的副标题都是「田野中抵制的启示」；"CONTENTS" 译成「目录」；
算没东西可翻的只剩网址和一串数字。

## 已经翻好的书

不自动改：要统一书名得重翻那几块（重新翻译时通读、请求缓存照用，花费很小）。
