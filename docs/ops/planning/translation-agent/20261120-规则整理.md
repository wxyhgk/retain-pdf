# 规则整理

2026-11-20。第三批第一步（3a）。

## 起因

Sonnet 审读的第 7 条和自己整理的结构图都指出：同一条规则在按节翻、逐页翻的人文附加段、审校里各写一遍，措辞不同，改一处容易漏；
例子多出自《The Interloper》（so many doors had been slammed → 吃闭门羹、no access materialized → 他一直没松口、obstructing → 阻挠），
所有书都带着；审校的「set 是排、points 是磅」来自排版论文，社科书也带着；按节翻没写「词形变了按中文习惯说」，也没说清哪些人名算第一次；
「不夹英文」和「第一次写译名（原文）」互相拉扯；通读员写的文风说明又重写一遍人名规则、编号体例，和译者的规则措辞不一。

## 改了什么

- 新文件 `retainpdf_translation_agent/rules.py`：七条译者规则（意译重组、意思不增不减、习语、习语和术语分清、名词腔、人名、不夹英文）
  只写这一处，`SECTION_NARRATIVE_PROMPT` 和 `NARRATIVE_PROMPT` 从这里拼（逐页附加段不带人名那条：逐页翻的人名靠上下文包的 first_use）；
  审校的「意译不要改回字面」「学科术语按字面直译算 number_term」也从这里取。
- 例子换成不出自任何在译书的通用说法（the elephant in the room、her refusal to cooperate、replication → 复现）。
- 排版论文的一词多义（set、points、fitting）挪进只给理工书审校的 `review.SCIENCE_NOTE`。
- 人名规则写清：标「前文已出现」的只写中文，没标的这一节第一次出现时写「中文译名（原文）」；括号里注的原文不算夹英文。
- 通读员提示词：文风说明只写这本书特有的，不再写人名括注、脚注标记、引号、不夹英文、习语意译这些通用规则。
- 版本：`agent-section-8`、`translation-agent-22`。
