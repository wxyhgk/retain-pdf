## 现状

- 初译、重翻、改稿不发思考字段：Claude Haiku 5.5 按默认 effort（medium）思考。
- 没用提示词缓存：各角色的系统提示（初译 3364 字、通读、审校）一本书里逐字不变，每页都重新算输入。

之前测过关思考（`disabled`）公式外露 6 处，不用。

## 改法

- 请求的系统提示改成带 `cache_control` 的文本块（`TranslationAgent._body`），工具定义在前面，一起缓存。
- `TranslationAgent(effort=…)`：给初译、重翻、改稿发 `thinking: adaptive` + `output_config.effort`；通读、审校强制用工具、本来就不思考，不发。
- 正式流程（`workflow/agent_flow.agent_effort`）按任务的 thinking 换算，和 legacy 同一套（`model_wire.anthropic_thinking_candidates`）：
  off、auto（claude-haiku-5-5）都是 low，明确的档位照用，别的模型 auto 不发字段。
- 提示词版本不变（文字没改）。请求体变了，各任务共用的 agent 请求缓存（按整个请求体的哈希）一次性失效。
