# 学科术语别按字面译

2026-11-20。

## 起因

《The Interloper》第 14 页（`p014-b001`）：

> …alternating for months between a "foot in the door" and "door in the face" strategy to find access…

译成了「在『一只脚踏进门』与『门被甩在脸上』两种策略之间反复切换」。这两个是社会心理学里的说服技巧，通行译名是
「登门槛（效应、技术）」和「留面子（技术）」「以退为进」。下一句就提到《民族志研究中进入的社会心理学》。

## 为什么没拦住

- **通读**：候选词由程序按出现次数挑，只出现一两次的说法不会成为候选，通读员看不到。
- **节译者**：提示词只有「英文习语、比喻换成中文里意思相同的惯用说法」，没写它的另一面（术语不能当习语换），Haiku 按习语处理。
- **审校**：补充说明主要防「把意译改回字面」，没说「按字面直译了术语」也算错。

## 改了什么

- 节译者（`SECTION_NARRATIVE_PROMPT`）和逐页的人文附加段（`NARRATIVE_PROMPT`）加一条「习语和术语分清」：作者引用的别的学科的固定说法
  用中文学界通行的译名，第一次写「译名（原文）」，没有把握的不要硬套中文俗语。示例故意不用这本书的说法（公地悲剧、习得性无助）。
- 审校：按字面直译别的学科的固定说法算 `number_term`，意思一轮也开单子。
- 程序（`section.quoted_phrases`）：把原稿里引号括起来的 2–6 个词的说法挑出来单列在请求里，让模型逐个判断是术语还是作者的强调、反讽。
  一个词的、每个词都大写开头的（多半是书名）不算，最多 20 条。
- 版本：`translation-agent-19`、`agent-section-3`。

## 实测（Haiku，第 12–17 页那一节，复用原来的通读）

| 做法 | 结果 |
|---|---|
| 改前（正式译文） | 一只脚踏进门 / 门被甩在脸上 |
| 只加提示词规则，第 1 次 | 登门槛 / 闭门羹（后一个意思反了） |
| 只加规则、要求带原文，第 2 次 | 一只脚踏进门 / 被关在门外 |
| 规则 + 程序单列引号说法，3 次 | 登门槛效应（foot in the door）/ 以退为进（door in the face）；登门槛 / 留面子；登门槛效应 / 以退为进 |

只靠提示词，Haiku 时认时不认；程序把线索递到眼前以后 3 次都对。
