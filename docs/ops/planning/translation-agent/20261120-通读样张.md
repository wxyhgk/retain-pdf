# 通读样张

2026-11-20。第三批第二步（3b）。

## 起因

Sonnet 审读第 6 条：通读员判体裁、写文风说明靠的样张是全书前 6000 字，出版社的书常常是版权页、目录、致谢；体裁只判一次，
判成 other、textbook 的人文书会走逐页的老流程。

## 改了什么

- `reader.body_paragraphs`：跳过标题是目录、致谢、版权、献词、作者介绍、图表目录之类的部分（到下一个标题为止），
  遇到注释、参考文献、索引、术语表、附录就跳到书尾（尾注里还按章分小标题，不能遇到下一个标题就停止跳过）；
  带 ©、copyright、ISBN、All rights reserved、在版编目的段不要。
- `reader.sample_text`：从第一段长段落（60 个词以上）算起；长的书在正文 8%、40%、70% 三处各取 2000 字，中间用「……」隔开；
  短的（论文）照旧从头连取。第一处不从 0 开始：封底推荐语、作者介绍、出版说明常常没有统一的标题，按标题排不干净。

## 看了什么

7 本书的样张三处开头：《The Interloper》以前从书名页、版权声明取起，现在三处是引言、迪士尼一章、SNECMA 一章的正文；
《Electricity and Magnetism》以前是封底介绍、作者生平，现在是正文和例题；《Infidelity》第一处还会取到一行在版编目，后两处是正文。

7 本书新旧样张各问一次通读员（Haiku）：体裁全部一样（人文社科 2、教科书 2、技术手册 1、论文 2），书库里没有出现判错的情况。
这一步实际的好处在文风说明：通读员看的是正文，不是版权页和推荐语。
