# 译文版本第一期

2026-11-18。用户：后端最好可以存多个翻译版本，设计 API、数据库，前端就能切换版本。

## 现状

- 一本书（`documents`）下面挂多个任务（`jobs.document_id`）。每次「翻译这本书」「重新翻译」都是新任务，旧任务和它的译文一直在，不删。
- 阅读入口（`/documents/:id/reading`）逐页取**最新**的任务拼成一本（合并阅读，虚拟任务 `merged-…`）。旧译文还在，但选不回来。
- 手改译文改的是那个任务自己的页文件，修改历史在任务的 `revisions.v1.jsonl`。
- `documents.active_job_id` 只是书卡上显示哪个任务，不决定读哪份。`document_versions` 表是 2026-11-03 删掉的 AI 改原文 PDF 用的，和译文无关。

## 用户定的

1. 新译文翻完：用户没选过版本（自动）就跟着最新走；选过就不动，只提示「有新版本」。
2. 只重翻一部分页：新版本里其余页沿用来源版本（切过去看到的是整本书）。
3. 第一期只能隐藏版本，不删文件，随时能恢复。
4. 手改译文改在当前版本里（和现在一样），版本列表显示「改过 N 处」。

## 做法

### 表（迁移 v30）

- `translation_versions(version_id, document_id, base_version_id, origin, label, hidden_at, created_at)`：一个版本一行。
  `origin` 是 translate / retranslate / backfill；`label` 是用户起的名字（空 = 按翻译设置生成）；`base_version_id` 是只重翻一部分页时其余页沿用的版本。
- `translation_version_jobs(job_id 主键, version_id)`：一个任务最多属于一个版本。外键到 `jobs`、`documents` 都是级联删。
- `documents.current_translation_version_id`：用户选的版本；空 = 自动（逐页取最新，和以前一样）。
- 回填：已有的每个 book / translate 任务算一个版本（`tv-<任务号>`）；单独建的重新排版（render）加进它来源任务的版本；
  复用了别的翻译任务的，来源版本就是那个任务的版本。以前续跑出来的任务在回填里各自算一个版本（分不出来是续跑）。
- 多设备同步第一期不管：版本表不同步，`current_translation_version_id` 登记成只在本机的列；另一台设备找不到这个版本时读自动。

### 建任务时挂版本（`retainpdf-jobs` 的 `link_new_job_to_document`，`VersionLink`）

| 入口 | 版本 |
| --- | --- |
| 新上传、`POST /jobs` 的翻译任务 | 新版本（translate） |
| 重新翻译（`retry-stage` 翻译阶段，复用 OCR 新建任务） | 新版本（retranslate），来源版本 = 源任务的版本 |
| 书库「翻译这本书」整本 | 新版本，没有来源版本 |
| 书库「翻译这本书」只翻一部分页 | 新版本，来源版本 = 用户正在看的版本（选过就是它，自动模式取最新的版本） |
| 书库拆成几段的翻译 | 第一段开新版本，后几段加进同一个版本 |
| 续跑（`resume`）、OCR 歧义恢复 | 加进源任务的版本 |
| 单独建的重新排版（render） | 加进来源任务的版本 |
| 纯 OCR | 不是版本 |
| 原地重跑（精修、重排） | 已经在版本里，不动 |

挂版本是尽力而为：失败只记日志，不影响建任务（和关联到书一样）。

### 读一个版本（`retainpdf-library` 的 `merge::reading`、`versions`）

- 选择分两种：自动（逐页取最新，隐藏版本的任务不用）；某个版本（这个版本的任务 + 来源版本链，最多 32 层）。
- 版本模式把层号放进排序键最前面：上层（这个版本）的页一定盖住下层（来源版本），和提交先后无关；层内照旧逐页取最新
  （同一份译文的重新排版、原地精修）。之后复用原来的合并目录（指纹由计划决定，计划一样就共用）。
- 阅读入口 `?version=`：给了读那个版本（`auto` 强制自动）；不给读书的当前版本，选的版本还没有可读的译文（还在翻）时读自动。
  回包多 `version_id`（null = 自动）。

### 接口（契约 `library-documents.v1`，追加在末尾）

- `GET /api/v1/documents/:document_id/translation-versions[?include_hidden=true]`：版本列表（从旧到新：按版本里最早的任务排）、
  当前版本、`has_newer`（选了某个版本、后面还有没隐藏的版本）。每个版本：名字（用户起的或生成的，如「精翻 · qwen3.8-flash」
  「普通 · deepseek-flash（第 30–40 页）」）、来源、来源版本、状态（running / succeeded / failed / canceled）、任务、自己翻了哪些页、
  是否整本、引擎、模型、编辑模型、手改了几块、是不是当前版本。
- `PUT /api/v1/documents/:document_id/translation-version` `{version_id | null}`：切换当前版本；隐藏的不能选（409）。
- `PATCH /api/v1/documents/:document_id/translation-versions/:version_id` `{label?, hidden?}`：改名、隐藏或恢复；
  隐藏的正好是当前版本时书回到自动。
- `version_id` 路径参数在多用户的参数分类里登记成嵌套（处理函数核对它属于这本书）。

## 第一期不做

- 两个版本逐块对比；
- 全文搜索、收藏跟着版本走（搜索索引现在按逐页最新建）；
- 真删除版本（连任务目录）；
- 多设备同步版本；
- 「手改另存新版本」（用户选了改在当前版本里）。
