# 主题完全可自定义

2026-11-24。用户：前端每个按钮、书卡和外观能不能全部自定义，方便做主题；给了一张目标图（朱砂手绘风）。
先让 5 个 agent 分区只读调研，再按下面的步骤做。

## 现状（调研结论）

- **颜色已经基本跟主题走**：`src/styles` 里写死的颜色只剩个位数，有只减不增的门禁（css-color-literals、tsx-color-literals）。
- **形状几乎都写死**：网页和 ui 包的 CSS 里写死的字号约 350 处、圆角约 210 处、阴影约 150 处（阴影全是模糊阴影，没有变量），组件代码里的 Tailwind 写死值约 110 处。字号、圆角有只减不增的门禁，阴影没有。
- **书卡没有任何形状变量**：样式全写在 `BookCard.tsx` 的 Tailwind 类里，没有外框、没有挂装饰的位置。卡片数据里有 `reading_status`，卡上没显示。
- **按钮有四套写法**：`@retainpdf/ui` 的 Button（不传 variant 时是裸按钮）、`app-button`、`button-link`、旧的 shadcn `LegacyButton`；首页顶栏切换、底栏又各写一套。
- **阅读器包复制了一份皮肤**：`packages/reader/styles/themes/*`、`src/shared/theme/*` 是网页那份的副本，内容相同但会漂（theme.ts 已经不一样）。新加变量要写两遍。
- **界面字体写死**：`--font-*` 在两份 `tokens.css` 里，皮肤管不到。设置里的「字体」是译文 PDF 的渲染字体，和界面无关。
- **小问题**：`--panel-radius` 定义了没人用，弹窗圆角是 `var(--app-dialog-radius, 28px) !important`；主题文档里的路径还是 `shared/theme`、`shared/decor`（早就挪到 `ui/`）。
- **装饰包**（`ui/decor`）能挂人物、四角图，但没有给单张书卡挂装饰的机制；墨家的装饰是按主题 id 点名写的特例（`mojia-ornaments.css`）。
- **已有一个开发用的 Theme Studio**（`frontend/web/studio/`）：同源 iframe 里实时调颜色变量、导出皮肤 CSS 文本。用户自定义主题可以从它长出来。

## 分六步

1. **皮肤只留一份**（本次）：皮肤 CSS 和注册表、`bootTheme` 挪进 `@retainpdf/ui`（`styles/themes/`、`src/theme/`，导出 `@retainpdf/ui/theme`、`@retainpdf/ui/themes.css`），网页和阅读器都从这里取；删掉阅读器那份副本；修主题文档里的旧路径。构建出来的 CSS 和以前逐字相同。
2. **形状变量**，按模块做（见下一节），默认值等于现在，现有 5 套皮肤看起来不变。
3. **书卡装饰位**：书签丝带、右下折角（纯 CSS，不加图）；书卡根节点补 `data-reading-status`。
4. **「朱砂手绘」皮肤**：用目标图验证变量够不够，缺什么补什么。人物、云纹等素材要用户提供有版权的图。
5. **自定义主题编辑器**：设置「外观」里改变量、实时预览、导入导出 JSON。只认白名单变量名，值只能是颜色、长度、百分比、字体名；挡 `url(`、`image-set(`、`@import`、`;`、`}`、注释，限单值长度和文件大小。网页和阅读页都要注入（阅读页走同一个 `@retainpdf/ui/theme`）。
6. **继续清写死值**：给阴影也加只减不增的门禁，剩下的分批改。

## 形状变量的写法

每处样式三层取值，最后一层就是现在写死的值，所以不设变量时样子完全不变：

```css
box-shadow: var(--btn-shadow, var(--shape-shadow-sm, 0 1px 3px color-mix(in srgb, var(--shadow-color) 6%, transparent)));
```

- **全局旋钮**（`--shape-*`）：描边粗细和颜色、硬阴影小中大、按下位移、圆角倍数、字体。皮肤只设这十几个，全站跟着变。
- **控件变量**（`--btn-*`、`--card-*`……）：想单独调某类控件时用。
- **默认值**：留在用的地方当最后一层兜底，不往 `:root` 写。现有皮肤一个都不设，观感逐像素不变。

变量清单按模块登记在 `packages/ui/styles/themes/_shape-contract.css`（只写注释，不写值），以后自定义主题的白名单从它来。

## 模块划分（第 2 步，多个 agent 并行）

| 模块 | 范围 |
|---|---|
| 全局旋钮 | `--shape-*` 定义和字体从 `tokens.css` 挪进皮肤；先做，其余模块引用它 |
| 按钮 | ui 包 Button、IconButton；`app-button`、`button-link`；按下效果 |
| 表单和弹层 | 输入框、下拉、分段切换、菜单、Sheet、Panel |
| 首页框架 | 顶栏「图书馆 / 合集」切换、底栏、书库标题行和数量框、批量工具栏、纸台 |
| 书卡 | 书卡、网格、列表行、合集卡（Tailwind 类换成 CSS 类） |
| 弹窗和浮层 | 弹窗外壳（接上 `--panel-radius`）、浮层面、Tooltip、Toast；设置和书籍详情外壳 |
| 阅读器 | 顶栏、页签、HUD、工具球、目录和搜索卡等外围控件；PDF 页、译文叠层、标注高亮不跟主题变 |

每个模块：只改自己的文件；`visual:check` 截图对比必须不变；架构测试全过。
