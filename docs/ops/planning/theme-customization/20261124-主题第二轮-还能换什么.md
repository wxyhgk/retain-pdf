# 主题第二轮：还能换什么

2026-11-24。「朱砂手绘」皮肤做完后，用户：只换背景图片没意思，再看看还有什么能抽出来。
5 个 agent 分图标插画、动效、字体、布局、装饰包只读调研，结论和分批如下。第一轮方案见
[20261124-主题完全可自定义](20261124-主题完全可自定义.md)。

## 调研结论

| # | 能换的 | 现状（要点） | 改动 |
|---|---|---|---|
| 1 | 补漏：详情弹窗里的小卡、页签、文件页、进度页卡片；设置里的输入框和卡片 | 还写死 `--line`、`--ui-radius-*`；web 全局 `input/textarea/select`（`web/src/styles/components.css`）没吃 `--field-*`；详情页签有 `!important` | 小，纯样式 |
| 2 | 小细节：选中文字颜色、滚动条、聚焦外框、勾选框颜色、光标 | 全站没有 `::selection`、滚动条规则、自定义光标；聚焦外框各写各的 | 小 |
| 3 | 通用装饰位：组件上挂主题小图（标题印章、弹窗角花、底栏/顶栏贴面、书卡纸胶带、阅读器顶栏两端、空状态插画、封面占位） | 只有墨家点名主题 id 写死的贴面（`mojia-ornaments.css`，base64 内联），钩子各写各的 | 中 |
| 4 | 空状态插画、封面占位图 | 空状态统一组件 `EmptyState.tsx` 写死仪器图标；封面占位是灰底「PDF」 | 小（走 3 的装饰位） |
| 5 | 主题字体：标题用主题自己的字体，字距、阴影字 | 全站没有 `@font-face`，全是系统字体；标题字距、字重写死在 `base.css` | 小到中 |
| 6 | 动效性格：回弹、淡入、按下手感；装饰层待机动画、点击悬停反应 | 只有 3 个缓动变量，没有时长变量；96 条 transition 多数写死；装饰层只有视差和点击语录 | 中 |
| 7 | 人物随状态、时间换图 | 契约里一层只有一张图 | 中 |
| 8 | 布局：书架（每排搁板、封面倾斜、书页厚度）、底栏侧边、标题横幅、阅读页纸张、密度 | 网格是扁平的（没有「行」），但每张卡画一段搁板能拼成整行；PDF 页槽没有阴影描边；没有密度变量 | 中到大 |
| 9 | 整套图标、音效 | lucide 约 124 个 + 手写 svg 50 处，没有映射表；全前端没有音效 | 大 |

另：主题打包成一个文件夹导入导出（变量 + 图片 + 字体 + 装饰位），格式和导入安全检查的草案在调研里有，后面单独做。

## 分批

- **第一批（本次）**：1 补漏、2 小细节、3 通用装饰位（含把墨家贴面改成通用做法）、5 主题字体（朱砂手绘标题用霞鹜文楷，OFL）、
  8 里的书架效果和阅读页纸张。都用「朱砂手绘」当样板验证。
- **第二批**：4 空状态插画和封面占位（要用户出图）、6 动效性格、7 人物随状态换图。
- **以后**：9 整套图标和音效；主题导入导出。

## 第一批的约定

- 所有新变量照第一轮的三层写法：不设时用现在的值，现有皮肤看起来不变（截图逐像素对比）。
- 新增变量登记进 `frontend/packages/ui/src/theme/shape-tokens/`：小细节一个新模块 `details`（前缀 `--selection-` `--scrollbar-`
  `--focus-` `--cursor-` `--check-`）；阅读页纸张归阅读器模块（`--reader-sheet-`）；书架归书卡模块（`--shelf-`）；
  详情弹窗里的卡片和页签归弹窗模块（`--detail-`）。
- **装饰位**：组件里放 `<span class="theme-ornament" data-ornament="<名字>" aria-hidden="true">`，不设图时不显示、不占位；
  图由装饰包 manifest 的 `ornaments` 字段声明（`{"名字": {"src": "相对路径", …}}`），运行时拼成包内地址写进 CSS 变量
  `--ornament-<名字>`。用户只能写包内相对路径，写不了任意 url。名字有白名单。
- **字体**：子集化成常用字，woff2 放在装饰包目录里；只有选了这个皮肤、页面真的用到这个字体时才下载。
