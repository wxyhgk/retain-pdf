# 导出水印

2026-11-20，分支 `feat/export-watermark`。用户：「给 PDF 加上水印，水印是 RetainPDF 的 logo + RetainPDF」；
定了：**默认开**、**右下角**、**Word 也加**。

## 做法

- **只在下载时加**：`/jobs/{id}/files/output/translated.pdf`、`side-by-side.pdf`、`translated.docx` 默认返回带水印的一份，
  `?watermark=0` 返回原版。渲染产物本身、阅读页（`pages/{n}.jpg` 预览图）都不带：阅读、截图不受影响，开关水印不用重新渲染，
  以前翻好的书也直接有。带水印的 PDF 是派生产物（`retainpdf-files` 的 `ensure_watermarked_pdf`），和对照 PDF 同一套：
  按需生成、并发只生成一次、缓存看输入新鲜度、过期回收（`artifacts/<label>.watermarked-v1.pdf`）。
- **水印素材**：`backend/pipeline/devtools/build_watermark_stamp.py` 生成，产物提交进仓库（`render/output/watermark/`）：
  - `stamp.pdf`：logo（`resources/brand/RetainPDF-logo.svg`，和前端的是同一个文件）+ 字样 "RetainPDF"（Helvetica Neue，
    用 Typst 导出 SVG 时画成了路径），#262626、透明度 32%。**不含文字**：复制、搜索、全文检索都不会带出 "RetainPDF"，运行时也不要这个字体；
  - `stamp.png`：同一枚的透明底位图（540×96），Word 用。
- **PDF**：`retainpdf-pipeline watermark-pdf`（`render/output/watermark/pdf.py`）每页 `show_pdf_page` 引用同一个对象，
  位置按**看到的**页面算（/Rotate 90、270 的页也在看到的右下角、是正的）。高度取页面短边的 1.7%（A4 约 10pt，夹在 7～16pt），
  离右边、下边各留约一个水印高。存盘用对象流：不然重新存一遍比原文件大一成（实测 632KB → 690KB），现在只多约 4KB。
- **Word**：排版规格里带水印图和每页位置（和 PDF 同一个 `stamp_rect`），`retainpdf2doc` 每页右下角放一张浮动图片，
  压在文字上面、锁定位置；整份文档共用一张图。缓存文件名带 `-wm1`，带不带水印是两份。
- **版本**：换了图案、位置就把 `WATERMARK_VERSION`（`retainpdf-files` 的 `derived_artifacts/watermark.rs`）加一，旧缓存不会被命中。

## 实测

- 《The Hotel Architectural Design》译文 PDF（16 页）：每页右下角一枚，在期刊页脚下方不重叠；文字层和原文件逐页一样；632KB → 636KB。
- 同一份导出 Word（前 3 页），LibreOffice 打开每页右下角一枚。第一版的位图是按信纸大小渲的（4896×6336，几乎全透明），
  缩到右下角的小框里看不见；生成脚本改成从存好的 `stamp.pdf` 重新打开再渲，测试钉住位图和矢量宽高比一致。

## 没做

- `all.zip` 打包里的译文 PDF 不带水印（打包走另一条路，要的话再加）。
- 前端「导出时加水印」开关：后端已支持 `?watermark=0`，前端怎么改写在 `docs/core/frontend/backend-changes-handoff.md`。
