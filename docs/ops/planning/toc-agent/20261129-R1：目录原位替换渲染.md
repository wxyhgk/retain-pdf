# R1：目录原位替换的渲染

> 日期：2026-11-29（11-28 开工）
> 上一份：[用户定：目录页原位替换](./20261128-用户定：目录页原位替换.md)（R0–R4 的分步）。分支 `feat/toc-replace`，base `feat/toc-title-spans`（R0）。

## 1. 做了什么

渲染参数 `toc_mode`：`reflow`（默认，旧的整条重排 + 页码补画，不变）/ `replace`（原位替换）。参数位置和
`source_cleanup_strategy` 一样：渲染 spec 的 `params.toc_mode`（provider / book spec 在 `render.toc_mode`），
进 `foundation/config/layout.py` 的 `TOC_MODE`。Rust 任务参数、契约、前端开关留给 R4（用户看图定默认以后）。

代码在 `backend/pipeline/retainpdf_pipeline/render/output/toc_replace/`（见那里的 README）：

1. **定计划**（`render_plan.py` → `plan.py`，正文排版前）：逐页读 R0 的 `toc_entry_title_lines`，在原文 PDF 上定每条
   译文写在哪几行、多大字号、擦哪些字；在这一页的副本上真擦一遍、跑检查。擦到别的字（R2）、擦不干净（R1）的条目改成
   保留原文再试；文字层擦干净了图上还有字（看不见的文字层、字在图上）整页改按扫描件；还不行这一页退回 reflow。
   定好的页里，目录条目和页码小块都改成保留原文（`toc_page_labels.held_item`）：正文排版不擦不排。
2. **换字**（`executor.py` → `apply.py`，正文排完以后、表格那一遍之前）：和表格那一遍同一个做法——在译文 PDF 上照计划
   擦字，译文画在一个小 PDF 上（每页一页，字体嵌子集）叠上去，再跑一遍检查，写进渲染诊断 `toc_replace`。
3. **阅读页**：有版面（rpr_fit 排的）就补进去（`reader_layout.add_reader_layout_toc`）：每页 `erase` 加标题原字的框
   （底色按原文页取；扫描件就是盖字的框和底色），`blocks` 加目录的块（和引擎的块一样，一个字一个字簇，`font` 填正文常规体的
   key；这几页引擎只画了粗体标题、清单里没有常规体时补一项排在最前面）。阅读页不用改。

规则照用户定的：
- 擦：文字层每行一根细探针（首字中心到末字中心），PyMuPDF 只删碰到探针的字，同一条绘字指令里的章号、点线、页码留着；
  不在基线上的上下标单独一个点。扫描件（看不见的文字层）按标题行框在图上盖底色：先按同一行的章号、点线、页码，上下行的字，
  章号、标签、页码、作者行的框定出能盖的范围，再从 OCR 的框往外找连着的墨迹（OCR 的框常比图上的字小），盖到墨迹为止；
  底色取这一行周围最多的颜色。
- 写：原首字的 x、原基线，原标题的字号，常规体、黑色（和正文同一份字体：细体 W300 静态实例，没有就思源宋体常规体）；
  每行宽度到右边第一个留下来的字前 0.3 个字。多行标题按原行宽切回原行；没有章号、标签，页码在末行，末几行放得下时放到
  末几行。放不下每次缩 2%，最低 0.8 倍；还放不下保留原文，记进诊断 `needs_model`（留给 R2 交模型）。
- 不换：没译文、译文和原文一样、译文里一个汉字都没有（人名、代码名、模型只交回原文一段）、译文里有公式或标记（`$`、HTML
  标签……，公式要走引擎排，R1 不做）、字体里没有的字。标签列：条目有 `toc_entry_label` 时，译文前面的原标签或译成的
  「第1章」「附录 A」剪掉，只写标题。
- 测宽：PyMuPDF 读正文同一份字体文件的字宽（引擎的字宽表就是从它导出的），汉字和西文字母、数字之间加 1/4 个字
  （引擎和 Typst 的 add_cjk_latin_spacing）；中文标点挤压、行首行尾标点去半个字没做。引擎没有「量一行字」的命令行入口，
  调它的内部模块会和引擎私有代码绑死，所以没改引擎、没用引擎测量。PDF 按同一份位置一段一段画（加了 1/4 字的地方另起一段），
  和阅读页版面里每个字簇的 x 一样。

### 认上下文的 agent（R2，PR #252）写的字段

- `toc_entry_keep_original`：为真的条目原字不动，不擦不写（状态 `kept_original`）；
- `toc_entry_author_lines`：作者行的框记成受保护的框，扫描件盖底色不盖到，盖到了检查 R2 报出来；
- `toc_entry_text_layer`：`invisible` / `visible` 按条目多数定这一页按扫描件还是按字擦；没有这个字段时看标题的字有多少是
  看不见的（文字渲染模式 3）。R2 没跑时这些字段不存在，按上面的默认。

## 2. 检查（R1–R9）

定计划时在副本上跑一遍（决定哪条保留原文、哪页退回），换字时在译文 PDF 上再跑一遍（写进诊断 `toc_replace.checks`、`totals`）：

| # | 量什么 |
|---|---|
| R1 | 文字层：标题的字擦完还剩几个；看图：标题框里还有墨迹的行数；扫描件：盖的框外沿 1.2pt 一圈有墨迹的条数 |
| R2 | 文字层：标题以外的字擦前擦后一个不少（±0.3pt 比位置）；扫描件：盖的框压到别的字、章号标签页码作者行的次数 |
| R3 | 新写的每一行框里有没有留下来的字 |
| R4 | 原字号放下 / 缩字号（最小倍数）/ 放不下保留原文 |
| R5 | 用的行不多于原文（永远成立）；空出的行数 |
| R6 | 页码在末行、用不完原来的行的条目里，放到页码那一行的条数；有章号从首行起的条数 |
| R7 | 写出来的字和译文标题一样 |
| R8 | 写出来的字里没有 `$`、HTML 标签、Markdown 标记 |
| R9 | 标题末尾到点线或页码的距离（字），原文和译文的中位数，只记数 |

测试 `backend/pipeline/devtools/tests/rendering/test_toc_replace.py`（25 条，合成 PDF 现造）：点线和标题同一条指令、每个点一条指令、
页码紧跟标题、两行标题（放页码行 / 有章号放首行）、标签列、没译文和同原文、缩到 0.8、放不下保留原文、扫描件（看不见的文字层）、
文字层压在图上（擦了还有字，改按扫描件）、R2 的三个字段；R1、R2（文字层和扫描件）、R3、R5、R7、R8 各有反例；阅读页版面补块。

## 4. 留下的事

- **R0 的两个漏网**（标签列该留原图却被换了）：80c3ad 的「Annexure IV」这类罗马数字和标题在同一个片段里，没切出标签；
  14e352 的「CHAPTER 2」单独一行、标题在下一行，整条只有标签那一行不切。这两种现在整条换成译文（「附录 IV …」「第 2 章 电势」），
  看着不错但不合「标签不翻」。要不要在 R0（`toc_pages.py` 的 `_split_label`）补，等用户定。

- 默认值不变；看过三栏图再定（R4）。
