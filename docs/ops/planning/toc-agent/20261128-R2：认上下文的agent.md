# R2：认上下文的 agent

> 日期：2026-11-28
> 前一份：[用户定：目录页原位替换](./20261128-用户定：目录页原位替换.md)（分步里的 R2；用户定「规则拿不准才问模型」）。
> 分支 `feat/toc-context-agent`，基于 R0 `feat/toc-title-spans`。没调模型、没调 OCR，测试全用录好的回复回放。

## 做了什么

原位替换只换标题的字，难点是「哪几段字是同一条、每段字是什么」。R2 在翻译开始前做这件事：规则先出草稿，
**有「拿不准」的信号才问模型**，模型只能改每段字的角色和条目归属（不能改字、不能改位置），改完就检查，最多 3 轮。
结果写回归一化文档里同样的条目字段，R1（渲染）照着擦字写字，翻译照着取标题。

| 放哪 | 做什么 |
|---|---|
| 流水线 `ocr/document_schema/toc_pages.py` | `page_draft`：和拆条目同一套规则出草稿（每段字的角色、归哪条）；规则不认的块也给候选（`accepted=false` + 原因）。`context_drafts`：整本书每块目录的草稿。`apply_toc_context`：按改过的草稿重建条目块和页码小块、整页重编块号。条目另记原目录块的框 `toc_split_parent_bbox` |
| 目录 agent 核心 `retainpdf_toc_agent.context`（只用标准库） | 草稿数据、信号、工具、检查、循环；提示词 `toc_context_system.txt`（版本 `toc_context.v1`，sha256 测试钉着） |
| 目录 agent 接线 `retainpdf_toc_agent_engine.context` | 文字层看不看得见、目录区域截图（长边 1400 像素，左边叠淡色行号）、结果和缓存 `translated/toc-context.v1.json`；请求标签 `toc-translate-context`（用量记在 `toc_translation`） |
| 流水线外壳 `translate/toc_context_stage.py` | 翻译开始前跑一遍；子开关；只改本任务自己的文档；出错只打日志 |

## 规则拿不准的信号（核心 `context/signals.py`）

| 信号 | 怎么算 |
|---|---|
| `rules_rejected` | 规则不认这一块（条目少于 3、带页码的不到三分之一、页码倒退），只给出候选——**规则拒掉的页就从这里进 agent** |
| `few_entries` | 条目少于 3 条 |
| `few_page_labels` | 带页码的条目不到一半 |
| `pages_not_monotonic` | 按条目顺序页码往回走（双栏按先左后右再数一遍取少的） |
| `two_columns` | 三行以上，左边 55% 里有页码样的字、右边还有标题的字（左右两栏挤在一个视觉行里） |
| `page_left` | 三行以上第一段是纯数字、这一行又没有页码，且带页码的条目不到一半 |
| `many_fonts` | 标题、标签、作者的字用了 3 个以上字族（按字族数：Times-Roman / Times-Bold 是一族；每族至少两段才算）。按字体名一个个数时，粗体 + 常规 + 数学字体的普通目录也亮（回归集 20 页），改成按字族后 4 页 |
| `author_line_unrecognized` | 没有标成作者的字，但有整行斜体的标题行（这一页标题大多不是斜体），或者同一条里各行字号差 1pt 以上 |
| `multiline_without_page` | 标题两行以上、没有页码的条目 |
| `invisible_text_layer` | 目录区域的字大多是看不见的（扫描件上的 OCR 层，绘字模式 3） |
| `headings_unmatched` | 正文标题有 10 个以上时，两个词以上的条目和正文标题对上的不到 30%（比的时候去掉章号、`Chapter 1:`、`Appendix A` 前缀） |
| `translation_rejected` | 上一次目录翻译（`toc-agent.v1.json`）检查退回过、原因是数字对不上（章号页码混进了标题） |

没有信号的页不问模型、不发请求。没有文字层的页（扫描件，C17）规则出不了草稿，不进 agent，记在摘要的 `no_text_pages`，留给扫描件那一步。

## 给模型的东西

- 截图：目录区域（原目录块的框，左边多留 16pt 写行号），长边约 1400 像素；行号是草稿的视觉行号，淡红色半透明。在临时文档上画，原页不改。
- 规则草稿（JSON）：每个视觉行的片段 `{id, t 字, x, s 字号, b 粗, i 斜, role 规则给的角色, e 归哪条}`，条目 `{id, level, title, page}`，信号，规则认没认。
- 截图在第一条用户消息里、文字前面；模型不收图（比如 DeepSeek）时上游会拒，结果是 `request_failed`，这一页照规则走。

## 工具（核心 `context/tools.py`）

模型一轮回 `{"actions": [...]}`，按顺序改草稿；参数不对的那一步不做，原因和检查结果一起退回。

| 工具 | 做什么 |
|---|---|
| `set_role(fragments, role)` | 改角色：title / number / label / leader / page / author / header / other；改成 header、other 同时移出条目 |
| `merge(entries)` | 后面几条并进第一条 |
| `split(entry, at \| line)` | 从这个片段（或这一行）起拆成新的一条 |
| `attach(fragments \| line, entry)` | 把这些字挂到某条（`entry: "new"` 新起一条）；挂进来的落单字默认当标题 |
| `keep(entry, reason)` | 这条不翻、原字不动（代码名、人名……） |
| `set_level(entry, level)` | 级别 1–6 |
| `continue_from_prev_page(entry)` | 这一页第一条接上一页最后那条（先只记下来，见「没做」） |
| `not_toc` / `done` / `give_up` | 不是目录 / 改完了 / 认不清交回规则 |

## 检查（核心 `context/checks.py`，每次改完都跑；规则草稿也过同一套）

1. 每段字都有角色，片段和字一个不多一个不少（工具改不了字，这里再核一遍）；
2. title / number / label / leader / page / author 的字都归到某一条、只归一条；header / other 不在条目里；
3. 每条有且只有一段标题（标题的字连着，中间不夹作者行）；
4. 每条最多一个页码；标成页码的字像页码、标成章号的像章号；页码不比草稿少；
5. 页码顺序不比草稿乱（草稿认出两个以上页码才比——页码在左的页规则一个页码都没认出，模型认出来的不跟它比）；
6. 级别 1–6；「接上一页」只能是第一条。

不过就把原因和现在的草稿退回，最多 3 轮。一页的结果：

| 状态 | 什么时候 | 对文档 |
|---|---|---|
| `rules` | 没有信号 | 不动 |
| `not_asked` | 有信号，模型这一步没开 | 不动 |
| `model` | 模型改完过了检查 | 改了就重建这一块的条目；规则不认的块按它拆开；扫描件的页也重建（条目上记下文字层看不见） |
| `not_toc` | 模型说不是目录 | 规则认过的页整页保留原文；规则不认的不动 |
| `rules_fallback` | 3 轮没过 / 放弃，规则草稿过得了检查 | 不动（就是规则草稿） |
| `keep_original` | 同上，规则草稿也不过 | 整页保留原文 |
| `unchanged` | 同上，规则本来就不认这一块 | 不动（照旧整块交普通翻译） |
| `request_failed` | 请求失败 | 不动；不缓存，下次再试 |

## 开关和默认值

挂在 `translation.toc = agent` 下面，子开关先用环境变量 `RETAINPDF_TOC_CONTEXT`（加任务参数要动 Rust 的 spec、契约、黄金 fixture，
等 R4 定默认时一起加）：

- `off`（**默认**）：不跑，和以前一字不差（测试钉着：默认跑翻译不写任何文件、不改文档）；
- `rules`：只算信号，结果文件记下会问哪几页，不发请求、不改文档；
- `model`：拿不准的页问模型，改了写回 `ocr/normalized/document.v1.json`（原子写），文档里记 `derived.toc_context`，续跑不改第二遍。
  文档不在本任务目录里（翻译别的任务的文档）时不写。跟着 OCR 翻时文档没出全，不跑。

缓存：输入（草稿、正文标题、上次翻译退回的标题、模式、是否带图、模型、提示词版本）一样就重放 `toc-context.v1.json`，不再发请求；
有请求失败的页不当定局。

## 和 R1 的接口（写回条目块 metadata 的字段）

R1 只读这些字段，不用管 R2 跑没跑：没跑时 R0 的字段照旧，新字段不存在按默认值。

| 字段 | R0 | R2 写回 | 意思 |
|---|---|---|---|
| `toc_entry_title_lines` | 有 | 按模型的归属重算 | 只框标题的字的每一行 `{bbox, baseline, size, text}`：R1 擦这些、在原基线写译文。作者行不在里面 |
| `toc_entry_title` | 有 | 重算 | 去掉章号、标签的标题（翻译取它） |
| `toc_entry_number` / `toc_entry_number_bbox` | 有 | 重算 | 章号，留原图 |
| `toc_entry_label` / `toc_entry_label_bbox` | 有 | 重算 | 标签列，留原图（模型能把和标题同字体的标签标出来） |
| `toc_entry_page_label` / `toc_entry_page_bbox` | 有 | 重算 | 页码，留原图 |
| `toc_entry_level` | 有 | 模型可改 | 级别 |
| `toc_split_parent_bbox` | **新**（R0 拆的时候就记） | 原样 | 原目录块的框，重读文字层用 |
| `toc_entry_keep_original` | 没有（= false） | 有 | 这条不翻、原字不动；同时 `policy.translate = false`（翻译不发请求、排版不擦不画），它的页码小块也是 |
| `toc_entry_keep_reason` | 没有 | 有 | `name`、`code`……；整页保留原文时是 `not_toc` / `keep_original` |
| `toc_entry_context_source` | 没有（= 规则） | `model` 等 | 这条是谁定的（状态名） |
| `toc_entry_author_lines` | 没有 | 有（可为空） | 作者行 `{bbox, baseline, size, text}`，留原图，R1 不碰 |
| `toc_entry_continues_prev_page` | 没有 | 有 | 接上一页最后那条 |
| `toc_entry_text_layer` | 没有 | 有 | `visible` / `invisible`；`invisible` 是扫描件，R1 要在图上盖底色（擦文字层擦不掉图上的字） |

点线（`leader`）、页眉（`header`）、别的（`other`）不进条目字段：原位替换本来就不碰它们。

## 没做 / 拿不准要用户定的

1. **子开关默认 off、用环境变量**：R3 实测前不开；R4 定默认时进任务参数（Rust spec、契约、TS）。`rules` 档（只记信号、不花钱）要不要先默认开，等用户定。
2. **改写归一化文档**：模型改过的条目直接写回 `ocr/normalized/document.v1.json`（R1 和翻译都读它）。另一个办法是只写 `toc-context.v1.json`、
   翻译和渲染各自读——要动渲染，R1 那边定。
3. **「接上一页」只记不合**：跨页的半条现在只标 `toc_entry_continues_prev_page`，两半还是各翻各的；要不要把上一页最后一条和它拼起来翻，看 R3 有几处。
4. **翻译检查退回的信号**第一次跑拿不到（目录翻译在认上下文之后）：只有续跑、重跑时用上一次的结果。要用上得把目录翻译挪到它后面再核一次，看 R3。
5. **扫描件没有文字层（C17）**不进 agent：模型不能改字，没有字就没有片段；留给扫描件那一步（看图出行框，要花钱）。
6. **正文标题对不上**这个信号最吵（本机 11 页，List of Figures、俄文图纸、版权页标题），要是 R3 看下来问了也改不出东西，就调高门槛或去掉。
7. 双栏只认「左栏页码夹在一行中间」这一种（视觉行把两栏拼在一起）；栏间距大、规则按两块读的，没这个信号。
