# 提问窗七处改进

2026-11-27。用户先说「我们的 ai 问答设计我总感觉不太爽」，接着贴来一份七条的意见（加一条长公式的小建议），要照着改。
实现说明见 [阅读页提问](../../../core/frontend/reader-ask.md)「2026-11-27 一轮改进」。

| # | 意见 | 做法 | 取舍 |
|---|---|---|---|
| 1 | 入口太隐蔽，新书看不到任何按钮，想问整本书不知道点哪 | 小球里「提问」，开 / 关这本书的主对话；用户指南补「问 AI」 | 没放顶栏：顶栏是全局导航，小球是阅读工具（Markdown、画笔、对比版本都在那） |
| 2 | 摆法、尺寸、agent 每次重开都重置；贴右边盖住译文 | 记在本机；贴右边时书页让位（贡献表 `reserveRight`） | 放大不记（下次一打开就盖满屏不对）；窄屏不让位（让了书页不到 480px） |
| 3 | 常问只在空对话出现，主对话一直延续就再也看不到 | 带着出处、输入框空着时出处下面一排 | 没出处时不显示：「讲讲这段」没有「这段」 |
| 4 | 核对译文后改不回去；对话里定的术语进不了术语表 | 回答底下「改这段译文」（跳过去、先填建议、自己存）；记忆面板「加进术语表」 | 不自动存译文；建议译文先取选中的字，再取 ```` ```译文 ```` 代码块（提示词要后端教，见下）。术语表是用户自己的那几张（没有「本书术语表」这个东西），翻译时选了才用 |
| 5 | 看图、公式、表格得自己截屏 | 右键「截一块问」、输入框「带上这一页」 | 书页上不加浮动按钮（选中浮条两次拿掉过）；pdf.js 重新画，缩放再小也清楚 |
| 6 | 窗口开着时选字静默覆盖已经选好的出处；想同时比两段 | 已带着出处就问「换成 / 再加一段」，一问最多三处 | 还没出处时照旧直接带上（最常用的路不多一步）；问在提问窗里，不在书页上 |
| 7 | 归档没确认，归档后找不回 | 标题栏里确认；「以前的对话」只读看 | 不做「恢复」：一本书同一时间只能有一个开着的主对话，恢复要先归档现在的，规则后端没定 |
| 附 | 窄窗口里长推导横着滚 | 1.5 倍以内自动缩，再宽给「放大看」 | 不往 Markdown 里插按钮（React 管的节点），提示放在对话区角上 |

## 交给后端

- 自带 agent 的 `ask_system.txt`：用户问译文准不准、要改译时，把建议的整段译文放进 ```` ```译文 ```` 代码块（只放译文本身）。
  前端认 `译文` / `translation` / `zh` / `zh-CN`，取最后一个。没有的话用户要自己在回答里选那段字再点「改这段译文」。
- 「再加一段」的另外几处只在发给 agent 的那段字里（`AskContext.extra`），没进消息的结构化出处（`selection` 只有一处）。
  要在书页上给另外几处也画「?」、重开时还原，得给消息加多处出处的字段。
