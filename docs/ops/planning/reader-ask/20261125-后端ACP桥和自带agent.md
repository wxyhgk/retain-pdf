# 阅读页提问：后端的 ACP 桥和自带 agent

2026-11-25。前端的方案在同目录的「20261125-阅读页提问.md」（前端分支 feat/reader-ask，跟问答窗一起合）：问答窗只说
[ACP](https://agentclientprotocol.com/protocol/overview)，浏览器经 WebSocket 连本机桥，桥起 agent 子进程转发。

## 用户定的

- 桥**全放后端**（不放桌面壳）：前端只接一个 WebSocket 地址。起本机进程的那条路要在后端多守几道（见「安全」）。
- **先做 ACP**，目录线 1 剩下的两件（拆条目规则、扫描件目录页）放后面。

## 接口（给前端）

1. `GET /api/v1/ai/agents`（signed，by web）：能用哪些 agent。

   ```json
   {
     "agents": [
       {"id": "retainpdf", "name": "RetainPDF 自带模型", "kind": "builtin", "available": true, "reason": ""},
       {"id": "claude-code", "name": "Claude Code", "kind": "local", "available": true, "reason": "",
        "launch": "npx -y @agentclientprotocol/claude-agent-acp"},
       {"id": "codex", "name": "Codex", "kind": "local", "available": false, "reason": "没找到 codex 命令"},
       {"id": "gemini", "name": "Gemini CLI", "kind": "local", "available": true, "reason": "", "launch": "gemini --acp"}
     ],
     "local_agents": {"enabled": true, "reason": ""}
   }
   ```

   `local_agents.enabled = false` 时（服务器、Docker、多用户、监听非回环地址、`RUST_API_LOCAL_AGENTS=0`）只有自带的那个，
   本机 agent 都是 `available: false`，`reason` 写原因。

2. `GET /api/v1/ai/agents/{agent_id}/acp`（WebSocket）：一条文字消息就是一条 JSON-RPC 2.0（ACP 原样，桥不改协议）。
   - 认证：`X-API-Key` 头，或者 `?api_key=`（浏览器的 WebSocket 带不了头；请求日志不记查询串）。来源照 CORS 那套查。
   - 自带 agent 要带模型配置（查询参数）：`model`、`base_url`、`api_protocol`（`openai` / `openai_responses` / `anthropic`）、
     `thinking`、`credential_ref`（凭据库里的密钥引用；不收明文 key）。
   - 桥只改一处：客户端发的 `session/new`、`session/load`，`mcpServers` 里没有 `retainpdf` 就补一个（`retainpdf mcp`，
     带 AI 专用密钥）；`cwd` 空着就填书文件夹。其余消息两头原样转，`session/request_permission` 也是原样转给浏览器。
   - 连接断开就结束 agent 进程；agent 退出就关连接（关闭码 1011，原因写 agent 的退出码和 stderr 最后几行）。
     握手前就不行的（没有这个 agent、本机 agent 没开、凭据读不到）回 HTTP 错误，不升级。

3. 问答记录（以后，第三个分支）：按书存会话和锚点，ACP 的 `session/load` 重放。

## 自带 agent

- Python，`retainpdf-pipeline ask-agent`（和翻译 worker 同一个环境）：stdio 上说 ACP，桥把它当一个普通 agent 起。
- `initialize`：`promptCapabilities.image = true`（扫描页的截图），`loadSession` 等有记录以后再开。
- `session/prompt`：用请求里的模型流式回答，`agent_thought_chunk`（思考，模型给的话）、`agent_message_chunk`（正文）；
  结束发 `usage_update`（ACP 的 `used`、`size` 照填），输入 / 输出 / 缓存命中 token 放在 `_meta.retainpdf.usage`
  （ACP 的 usage_update 还没有这些字段）。Anthropic 打开提示缓存。
- 一个会话的前几轮记在进程里（连接断了就没了，等记录做好用 `session/load`）。
- 第一版不调工具（书的上下文由前端放进 prompt：位置、选中的字、那一块的原文译文）；`retainpdf mcp` 交给外部 agent 用。

## 安全

起本机 agent（Claude Code、Codex 能在本机跑命令）只在这些都满足时打开：

- 单机模式（多用户版一律关）；
- 后端监听回环地址（Docker、服务器部署监听 `0.0.0.0`，自动关）；没设 `RUST_API_LOCAL_AGENTS=0`；
- 这次握手的 `Host` 是回环地址或 `localhost`，没有 `Forwarded` / `X-Forwarded-For`（经过代理、局域网共享的不放）；
- 来源检查照 CORS（`OriginPolicyConfig::allows_origin`），`null` 不认；
- 只起登记表里写死的命令，参数不收客户端给的。

自带 agent 不起本机任意程序，服务器上也能用。
