  回答先不进白板，放浮动窗口。

## 前端

- **右键**（书页上；Shift + 右键照旧是浏览器的菜单）：画笔那一排上面多一行
  - 没选字：「在这里提问」——问鼠标下面那一块（悬停框认出的块）；没认出块（空白处、扫描页没段落数据）就问这一页这个位置。
  - 选着字：「问这段」——问选中的字（要有文字层；扫描版原文没有文字层，选不了，这时只能「在这里提问」）。
- **选中后按 `?`**：同「问这段」。`?` 原来是快捷键帮助：只在选着书页上的字时拿来提问，没选字照旧开帮助。
- **回答窗**：浮在书上，标题栏拖动、右下角拖着调大小，Esc / ✕ 关；顶上写出处（第几页、哪一节、引的那段原文 / 选中的字），
  下面是问答（Markdown + 公式，流式出字），底下输入框可以追问。打开时光标在输入框里，先打问题再发。
- **书页上的「?」**：问过的地方，书页左边白边里一个小问号，点了打开那次问答。第一版只记在这次打开里（后端能存以后从后端读）。
- 阅读器只认一个端口 `ReaderAskPort`（`contracts`），由宿主（web）传进来：没传就没有提问入口。端口说 ACP（见下）；演示模式传一个假 ACP agent。

## 问答窗用开源的，协议用 ACP（同一天后面定的）

用户：「这种问答窗口可以直接找最新的一些别人的开源的东西」「尤其要看其功能，包括思考，还有缓存，还有 token 的速度什么的，以及多 agent」
「还得能接入 ACP，这样我们就能接入本地 ChatGPT，claude code 等」→「可以，按这个方向做」。

- **界面**：assistant-ui（MIT，只给结构不带样式，套我们的皮肤）拼问答窗；回答用 streamdown + `@streamdown/math`（Apache-2.0，
  流式 Markdown，写到一半的 `$$` 不乱，KaTeX）；浮窗拖动、调大小用 react-rnd（MIT）。问答窗单独一块，用到才加载。
- **协议**：问答窗只说 **ACP**（[Agent Client Protocol](https://agentclientprotocol.com/protocol/v1/schema)）。它本身就有：
  思考（`agent_thought_chunk`）、工具调用（`tool_call` / `tool_call_update`）、计划（`plan`）、要许可（`session/request_permission`）、
  用量（`usage_update`，还在 RFD）。界面照这些画：思考折叠、工具调用小卡片、计划列表、「允许 / 拒绝」、底下一行用量 / 缓存命中 / 每秒 token / 用时
  （速度前端自己算）。多 agent 等协议和 agent 有了子 agent 再加。
- **本机桥**：浏览器起不了子进程，ACP 客户端那头放在本机（后端或桌面壳，后端定），浏览器经 WebSocket 说 ACP。桥起
  Claude Code（`@agentclientprotocol/claude-agent-acp`）、Codex / ChatGPT（`@agentclientprotocol/codex-acp`）、Gemini CLI（`gemini --acp`）等；
  **RetainPDF 自带模型也包成一个 ACP agent**（用设置里的 key），这样问答窗只有一种协议。网页版（服务器上）只能用自带的那个。
- **书的数据**：`session/new` 时把 `retainpdf mcp`（[第 3 步之三](../ai-data-access/20261125-retainpdf-mcp.md)）交给 agent，
  它自己读页、看页图、改译文要许可；提问时只发位置、选中的字、那一块的原文译文（ACP 的 prompt 内容块），不推整本书。

## 要后端加的（ACP 定下以后的版本；接口名、字段由后端定）

1. **本机 ACP 桥**：浏览器经 WebSocket 连上来说 ACP（JSON-RPC），桥按选的 agent 起子进程（stdio）转发；列出能用的 agent（装了哪些）。
   `session/new` 时把 `retainpdf mcp` 交给 agent。请求许可（`session/request_permission`）原样转给浏览器，等用户点。
2. **自带模型包成 ACP agent**：用设置里配好的模型回答，发思考、正文、用量（输入 / 输出 / 缓存命中，模型支持的话打开提示缓存）。
   测试只用 haiku-5-5 / qwen3.8-flash（花钱的测试照旧先问用户）。
3. **存问答记录**（可以晚一点）：按书存会话和锚点，前端画「?」、重新打开；ACP 的 `session/load` 能用就用它。

前端先用演示模式里的**假 ACP agent**（直接发 `session/update`：思考、正文、工具调用、计划、要许可、用量）把问答窗做完；
后端桥好了，web 宿主那一层把 WebSocket 接上就行，阅读器包不用改。
