# 第 2 步：自带 agent（Python，stdio 上的 ACP）

2026-11-25。[后端 ACP 桥和自带 agent](./20261125-后端ACP桥和自带agent.md) 的第 2 步，分支 feat/ask-agent（叠在 feat/acp-bridge 上）。

## 做了什么

- 新包 `backend/ask-agent`（`retainpdf-ask-agent`）：核心 `retainpdf_ask_agent` 只用标准库（ACP 服务端、内容块转换、系统提示词），
  接线 `retainpdf_ask_agent_engine` 做三种协议的流式请求；入口 `python -m retainpdf_ask_agent`，桥起它。
- 回答在后台线程里流式发 `agent_thought_chunk`、`agent_message_chunk`，结束发 `usage_update`（token 细分在 `_meta.retainpdf.usage`）；
  `session/cancel` 每读一行流看一次，叫停就关连接回 `cancelled`。
- 请求体用翻译底座 `model_wire` 的构造函数（思考档位、图片写法和翻译一样）；Anthropic 在上一轮回答上打 `cache_control`，
  思考写法被拒（400）换下一种；Responses 要 `reasoning.summary = auto` 才有思考摘要。
- 端到端测试抓到一个真问题：`text/event-stream` 没写 charset 时 requests 按 ISO-8859-1 解码，中文成乱码；改成一律 UTF-8，
  入口的 stdin / stdout 也固定 UTF-8。

## 真模型实测（用户：「不用考虑费用」）

同一个会话连问（第 12 页一句薛定谔方程的译文对不对 → 哈密顿量不含时怎么化简 → 含时怎么处理）：

| 模型 | 首字 | 思考 | 缓存 | 正文 |
|---|---|---|---|---|
| claude-haiku-5-5（Anthropic，思考 high） | 2.5–3.6 秒（先出思考摘要） | 每问 42–86 段摘要（英文） | 第 2 问写入 999 token，第 3 问读到 999 | 中文、行内和独立公式都对，追问接得上 |
| qwen3.8-flash（OpenAI 兼容，思考 low） | 0.6 秒 | 每问 70–127 段 | 没命中（前缀太短，不到它自动缓存的门槛） | 同上，还给了表格 |

- 一开始 Haiku 一段思考都没有，可首字 4–10 秒、输出 token 多出一截——模型在想，只是没发。用户指出 **Claude 不给思考原文，只给摘要**：
  要 `thinking.display = "summarized"`（不写就是 omitted）。改成每个开思考的写法先带上它，不认（400）再去掉。
- 摘要的语言是 Anthropic 那边定的（实测英文），我们管不了。
