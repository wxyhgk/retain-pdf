# 读书走查：笔记是唯一的工作台（2026-11-04）

## 测试条件

作者说「笔记软件和 pdf 阅读部分感觉还是不顺，好几个地方逻辑比较混乱，你得从使用者角度出发去看」。一个 agent 照作者的用法走了一遍：开书、读、摘、写、问 AI、两本书、换笔记、整页和并排、回原文、重新打开、上传、搜索、暗色。

测的版本是 main 加上 studio/notes-first 和 studio/book-beside，也就是马上要合的样子。

- 用的是隔离的测试 Studio，连真书库 40001。
- 40001 跑的是 main 的构建，没有 open-book。测试浏览器里用 Playwright 的 route，把它换成了分支的构建。
- 截图没有进仓库（在作者本机的临时文件夹），下文的文件名只是记下看的是哪一张。

作者定了：照「笔记是唯一的工作台，书库只挑书、不读」这个模型改。

## 使用模型（作者定的）

**笔记是唯一的工作台。** 书只是开在笔记旁边的资料。书库只用来挑书、管书、上传翻译、看任务，从来不在里面读。AI 永远对着「这篇笔记 + 旁边开着的书和当前页」。

- **开书**：可以用笔记顶栏的「书」、带搜索的「+」挑书面板、⌘K 的「书里」。从书库点任何书，也都是开到当前笔记旁边，先作为预览标签。
- **读**：只有一种阅读器、一种布局。宽度三档：并排、专心读（页面树和右栏收起，笔记缩成能拉出来的窄条）、收起。切换不丢页。
- **记**：「摘到笔记」放到插入线的位置，摘完焦点回到笔记。
- **问**：AI 在右栏，看得到这篇笔记、当前页，以及所有开着的书。
- **回原文**：点笔记里的角标或 AI 回答里的出处，都在旁边翻到那一段，并高亮。

## 问题（按影响排）

1. **两套「书 + 笔记」布局。**
   - 笔记旁边是 booksSplit 的书标签。
   - 书库里是整页阅读器加 notesSplit：默认对照、缩放 50%、右栏收起，书页上的「笔记」按钮写着「打开这本书的笔记」，点「关闭」后变成图书馆在左、笔记在右（截图 h03-notes.png、h05-closed.png）。
   - 「查看原版」和 AI 问答里的出处，走的也是整页这条路（g02-original.png）。
   - 建议：书库里不再读；这些入口全部改成「回到当前笔记，书开在旁边」。代码在 main.ts 822–908、1078–1089、1124–1131。
2. **太挤。**
   - 1440 宽时书约 465px、笔记约 375px；1280 宽时书 386px、笔记 305px（c15-1280.png）。
   - 「⤢ 整页读」时，页面树和右栏都还在。
   - 建议：开书时自动收起页面树；⤢ 时页面树和右栏都收起，笔记缩成窄条。代码在 setBooksWide、setBooksOpen（main.ts 1027–1049）。
3. **标签栏溢出。** 开到 3 本书时，「+」和「⤢」被挤出标签栏（i01-wk-three-tabs.png）。
   - 建议：这两个按钮固定在可滚动区域之外，书名标签用省略号缩短。代码在 book-tabs.ts 的 draw()。
4. **切换布局就跳页**，比如 8 → 5 → 9 → 8。
   - 建议：宽度变化前记下当前页和块，变化后用 navigate 回到那里，或者让阅读器按页锚定。
5. **摘完写不顺。** 焦点留在书框里，插入位置的规则看不见（c02-quoted.png、c08-second-quoted.png）。
   - 归 notes-studio 会话做：摘完焦点回到笔记、光标放在摘录后面、显示插入线。
6. **多本书的摘录分不清。** 角标都一样，书名只在悬停时显示。
   - 归 notes-studio 会话做：角标旁边写上书名和页码。
7. **书框里 ⌘K、⌘S 不响应**（d10-cmdk-in-book.png）。
   - 建议：契约里加 key 转发，阅读页把 ⌘K、⌘S、⌘J、⌘\ 转给 Studio。
8. **书开没开是全局的。** 新建一篇笔记，旁边也空着半屏书栏（c13-new-note.png）。随手翻的书会粘在笔记上。
   - 建议：按笔记记开没开；从书库、搜索打开的书先作为预览标签，摘过一段才固定下来。代码在 main.ts 953–1049 的 retainpdf-books-open。
9. **搜索割裂。**
   - 全库检索只在书库里有，命中的那段不高亮；⌘K 搜不到书里的字。
   - 书内搜索在窄栏里会盖住整页（g10-finder-open.png）。
   - 「+」挑书面板没有搜索框。
   - ⌘K 搜书里的字归 notes-studio 会话做。
10. **旧说法残留。**
    - AiPanel.tsx:54 写着「记进这本书的笔记」，agent-sessions.mjs:1183 给 AI 的提示也这么写：归 notes-studio 会话改。
    - ReaderCloseHome.tsx:131 写着「打开这本书的笔记」。
    - ReaderTextHoverLayer.tsx:250 写着「原文和译文一起」，实际只放译文。
    - 悬停框露出块编号 p001-b0002（c01-hover.png）。
    - docs/studio.md 419–455 还在写「一本书一页笔记」。
    - 书库卡片：点封面开到旁边，点书名弹详情框；悬停时的眼睛图标标题却叫「对照阅读」（f02-card-hover.png）。
11. **AI 只知道当前显示的那本书**（tellReading 只取 bookTabs.reading()）：归 notes-studio 会话做，让 AI 看得到所有开着的书。
12. **资料库里的 PDF 不能送去翻译。** 现在是三条互不相通的 PDF 管线（f07-add-pdf.png）。
13. **暗色时书页是大块白底，强调色是绿色**，和 Studio 的黑白不是一套视觉语言（g13-dark-beside.png）。

## 已经做得好、不要动的

- 摘录就是普通段落加角标。
- 书标签切换不重新加载。
- 每篇笔记记得自己有哪几本书，重新加载后书、标签、页码都恢复。
- 点角标，书在旁边翻到原文，笔记不动。
- 书库点书、点搜索命中，都开到笔记旁边对应的那一页。
- 阅读页的「AI」就是 Studio 的 AI，空状态写明读得到哪本书第几页。
- 书库全文检索中英文都能命中。
