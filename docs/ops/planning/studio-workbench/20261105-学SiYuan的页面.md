# 学 SiYuan 的页面（2026-11-05）

## 作者说的

> 我们的页面逻辑可以学习 siyuan 笔记 永远是笔记为主,书籍是单独的一个页面

作者贴了 SiYuan 的截图：

- 左边是笔记一栏，带标签；
- 中间是 PDF 一栏，有自己的标签和工具条；
- 右边是 AI。

问了三点，作者选：

1. 笔记在左、书在右；
2. 书在旁边一栏，一本一个标签；书库只用来挑书，在书库里点一本书，就在笔记旁边那栏打开，不在书库里整页读；
3. 笔记那一栏也要有标签。

## 分工

- **Studio 会话（studio/note-left-tabs，接在 studio/book-one-row 后面）**：第 1、3 条。
- **前端会话**：第 2 条。
  - 摘录角标、AI 回答里的出处、⌘K 的书里，不管在哪个视图都回到笔记，书开在旁边。
  - 只有原文、还没翻译的书，也要能开到旁边：契约要能只带 document_id，书标签能按书开，请后端改。
  - 书库整页读没了以后，书库的「摘录」栏那条路一起拿掉。

## 做了（Studio）

- **笔记左、书右**（studio-page.css、notes-split.ts）：
  - 书那一栏在右，竖线在它左边，拖的是书的宽度（`retainpdf-books-width`，默认一半）；
  - ⤢ 整页读照旧。
- **笔记标签**（`wiring/note-tabs.ts`，`#note-tabs`，在笔记那一栏最上面，和书那一行一样高）：
  - 打开一页就在当前标签后面加一个；已经开着的不重复；
  - × 和中键关，只剩一个不能关；
  - 改名跟着改，删了就去掉；
  - 记在浏览器里，最多 12 个。
- 笔记旁边的书本来就按笔记记，切标签就是切那篇的书。
