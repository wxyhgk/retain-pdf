# 书这一侧精简（2026-11-05）

## 作者说的

作者贴了「笔记旁边开着书」的截图，说「这个 ui 还是比较乱」。

## 现在的样子（笔记旁边开着一本书，1440 宽）

书那一侧的按钮分在四个地方，上面叠了三层：

1. Studio 顶栏：「书」、编辑时间、新窗口、收藏、⋯、右栏开关；
2. 书的标签栏：书名标签、＋、⤢ 整页读；
3. 阅读页自己的工具栏：目录、搜索、原文/对照/译文、下载；
4. 阅读页底部的浮动栏：页码、书签、缩放、快捷键；
5. 书和笔记之间的夹缝里还有一个竖条「MD / AI」，旁边是收起用的 ›。

另外两处：

- 阅读页的「AI」和右栏的 AI 面板是同一个东西，入口重复了；
- 书页按 100% 画，没有跟着栏宽铺满，右边空着一条灰色。

## 改成

书那一侧只留**一行**：左边是书的标签，右边是阅读的控件。阅读页自己的工具栏、底部浮动栏和夹缝里的竖条都不再显示。

```
┌ 书 ──────────────────────────────────────────────────────────┐┌ 笔记 ─────
│ ELECTRICITY AND… ×  ＋     目录  搜索 │ 原文 对照 译文 │ 30/863 ⋯ ⤢ ││ 电磁学基础
├──────────────────────────────────────────────────────────────┤│
│                 （书页，宽度跟着栏走）                          ││
```

- **标签**：只开一本时就是书名；开了几本、或栏太窄放不下时，变成「书名 ▾」，点开切换（也解决了标签多了把 ＋、⤢ 挤掉的问题）。
- **目录、搜索**：在书页上面展开一个面板，不盖住整页。
- **原文 / 对照 / 译文**：栏窄时只显示图标。
- **页码**：显示「30/863」，点一下可以输入页码跳过去。
- **⋯ 里放不常用的**：缩放（默认「适合宽度」）、书签、下载、导出 Markdown（原来的 MD）、快捷键说明。
- **⤢**：整页读，⤡ 回来；收起书还是用夹缝里的 ›。
- **AI**：只用右栏的 AI 面板，阅读页里不再放 AI 按钮；在书里选中一段，还是能「问 AI」。
- **书页默认适合栏宽**，拖窄拖宽都铺满（拖动时只缩放、停下再重画，见卡顿那一条）。

## 要做的事和分工

- **契约 studio-bridge.v1 加**：
  - 阅读页报告它现在的状态：第几页、共几页、原文/对照/译文、缩放，有没有目录；
  - Studio 发给阅读页的命令：切原文/对照/译文、跳到第几页、缩放、开关目录和搜索、下载、导出 Markdown。
  - 嵌在 Studio 里（`embed=studio&embed_pane=beside`）时，阅读页不画自己的工具栏、底部栏和竖条，只按命令做。
  - 这部分由前端会话加，契约归后端会话管。
- **Studio（Studio 会话）**：book-tabs.ts 的那一行（标签合成下拉、控件、⋯ 菜单），按阅读页报告的状态显示。
- **阅读页（前端会话）**：去掉嵌入时的那几处界面，接上命令；书页适合宽度，拖动时只缩放、停下再重画。
- 书库里整页读书时（RetainPDF 自己的页面）不受影响，照旧是它自己的工具栏。

## 作者定了，做了

作者说「做你说的这个,合并成一行」。

- **Studio（studio/book-one-row）**：
  - book-tabs.ts 那一行：标签和 ＋，阅读页的控件（`wiring/BookControls.tsx`），⤢；
  - 标签挤成几个字时只留正在看的那本，其余的进 ▾；
  - 栏窄时控件只剩图标，更窄时原文/对照/译文挪进 ⋯。
- **协议**（retainpdf-view.ts）：
  - 笔记旁边的书框在 `hello` 里说 `reader-state`，阅读页在 `ready` 里说 `reader-command`（契约的规矩：features 写各自处理的消息）；
  - 阅读页发 `reader-state`（`page_idx`、`page_count`、`modes`、`mode`、`panels`、`panel`、`zoom`、`actions`、`ready`），Studio 发 `reader-command`（`mode`、`page`、`panel`、`zoom`、`action`）；
  - 阅读页不说 `reader-command` 时 Studio 只画标签，照旧。
- **阅读页（前端会话）**：认 `reader-state`，嵌在笔记旁边时不画自己的那几处，接命令，默认适合栏宽；契约请后端会话加。
