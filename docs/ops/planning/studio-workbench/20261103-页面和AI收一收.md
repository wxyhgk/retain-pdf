# 页面和 AI 收一收

2026-11-03。用户让一个产品经理 agent 看整个 Studio，一个设计师 agent 看 Studio 和 RetainPDF 结合得别不别扭。看完以后，用户从建议里选了两件先做：清理博客残留、AI 收敛。同一天定下两个仓库合并，名字叫 RetainPDF，以 `frontend/studio` 为准。11-03 在 notes-studio 上多做的「AI 面板跟着作者」挪了过来。

## 产品评审的要点（只记和这次有关的）

- 作者真正每天在用的，是对着材料问 AI，让它讲懂、调研、画出来。`chats/` 里 28 个对话，27 个用 pi。
- 博客时代的东西压在笔记上：
  - 每页默认带发布日期、类型、草稿/发布；
  - 新页面写进一句真正的正文「从这里开始写作。」；
  - 日期按 UTC 记；
  - 界面上「文章」「页面」两个叫法混用。
- AI 入口七个以上，设置分在三处（设置 › AI 模型、面板 ⚙ 模型和账号、终端 ⚙ AI 助手设置）。

## 用户定的

- **页面**：
  - 界面上统一叫「页面」；
  - 博客的属性只在发布了的页面上出现，发布挪进页面的 ⋯ 菜单；
  - 新页面正文是空的；
  - 日期按本机的日子记。
- **AI 入口**：
  - 留下：右栏 AI 面板（侧栏、整页）、⌘J、悬浮、单独窗口；
  - 去掉：正文里的 ⌥↩ / ⇧⌥↩（交给后台 AI 的一句话），终端上方的「启动 AI」和它的 ⚙。
- **以 pi 为主**：Claude Code 和 Codex 收进「设置 › AI › 高级」，打开了才在面板里出现。没存过开关时，和谁聊过就算谁开着。
- **AI 设置合成一处**：设置里的「AI」一组，下面是「模型和账号」「识别图片」「高级」，面板的 ⚙ 直接打开「模型和账号」。

## 做了什么（分支 `studio/ai-converge`）

1. AI 面板跟着作者：从 notes-studio 的 7f4985d 挪过来。
   - 改了标题，「当前页面」标签跟着变；
   - @ 先列最近打开的页面；
   - 只选几个字时告诉 AI 是哪几个字；
   - 输入框有焦点时，文章里选中的地方仍然标着；
   - AI 做事时带选中内容的话排队，不插话。
2. 页面不再带着博客：
   - 草稿的页头只有标题、图标、封面、标签、简介；
   - 发布挪进 ⋯ 菜单的「发布到博客…」；
   - 新页面正文是空的；
   - 新增 `localDay`，新建和「复制一份」都按本机的日子记日期。
3. 界面上 142 句「文章」改成「页面」。说给 AI 听的规矩和发给 AI 的上下文没改。
4. 去掉 ⌥↩ 和终端的「启动 AI」：
   - 删掉 `server/ai/instructions.mjs`、`AgentsDialog`；
   - 任务机制留给 PDF 识别；
   - 「在终端里问 AI」留着。
5. 以 pi 为主，设置收到一处：
   - 重写 `agent-settings.mjs`：每个 AI 只记它的 ACP 转接程序，开关存在 `agents.on`；
   - 新增 `ModelsSettings.tsx`、`AgentsSettings.tsx`；
   - 浏览器测试用 `STUDIO_AGENTS_ON` 打开 Claude 和 Codex 的替身。
6. 测试：打开 Studio 时，只等第一个 SMILES、SDF 块画好。「代码库」的测试会多加一个 SMILES 块，以前在这一步就挂，main 上也挂。
