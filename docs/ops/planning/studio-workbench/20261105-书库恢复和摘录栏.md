## 摘录栏（方案，待作者看）

书库里读书时（RetainPDF 阅读页占满中间），右边不再放一整篇笔记，而是一栏「摘录」：

```
┌──────────────── 阅读页 ────────────────┐┌──── 摘录 ─────────────┐
│                                        ││ 摘到《变分法笔记》 ▾   │
│   ……第 41 页……                         ││ ───────────────────── │
│   [摘到笔记]                            ││ 这篇笔记里 · 6 段      │
│                                        ││  第 38 页  变分原理…   │
│                                        ││    ＋ 写一句            │
│                                        ││  第 41 页  试探函数…   │ ← 这一页的加深
│                                        ││ 别的笔记里 · 9 段  ▸   │
│                                        ││ ───────────────────── │
│                                        ││ [打开笔记]             │
└────────────────────────────────────────┘└───────────────────────┘
```

- **摘到哪篇**：栏顶写着笔记名，默认是你离开笔记时在写的那篇。点开可以换：最近写的几篇、搜索、新建一篇。
- **摘一段**：阅读页的「摘到笔记」把这段放进那篇笔记，接在这本书上次摘的那段后面，没有就放在末尾。栏里马上多一条、闪一下；不跳走，键盘留在书里。
- **这篇笔记里**：那篇笔记里摘自这本书的段落，按笔记里的顺序。每条写页码和前两行，当前这一页摘过的加深。
  - 点一条，阅读页翻到原文那一段；
  - 「＋ 写一句」在这段摘录下面接一句自己的话，写进笔记。
- **别的笔记里**：别的笔记里摘自这本书的段落，按笔记分组，默认折起来。点笔记名就打开那篇。
- **打开笔记**：回到笔记，书开在旁边，还是这一页。想写长一点时用它。
- **AI**：右栏的 AI 照旧在；它知道这本书、这一页，以及摘到的是哪篇笔记。
- **不建页面、不另存数据**：摘录就是笔记里的普通段落（带 `retainpdf:` 出处），栏里显示的都是从笔记里读出来的。

### 定了的

1. 作者定：摘录栏放在右栏，作为一个标签，和 AI、文件并排。
2. 还没有在写的笔记时，第一次摘录先问摘到哪篇（按推荐定的，作者没另说）。

### 做了（studio/quote-panel）

- **Studio**：
  - 右栏「摘录」标签（`quotes/QuotePanel.tsx`），阅读页的 open-notes / close-notes 开关它，摘一段时它自己出来，离开书库就收走；书库里不再把整篇笔记放在书旁边（notesSplit 只剩笔记旁边开书时用）。
  - 摘录放进正在写的笔记，接在这本书上次摘的那段后面（`bookPassages`：一段算到下一段摘录或下一个标题为止），不动光标、不抢焦点。
  - 「＋ 写一句」接在那一段后面；「别的笔记里」由服务器扫各篇笔记（`ArticleRepository.bookQuotes`，GET /api/studio/retainpdf/quotes）。
  - 把摘过的块告诉阅读页：契约 `quoted`（`job_id`、`document_id`、`item_ids`，整份替换），阅读页在 `ready` 里说认才发。
- **阅读页**（前端会话，studio/reader-quoted）：按钮改叫「摘录」，认 `quoted`，在摘过的块左边画灰线。

### 分工（作者定了以后）

- **Studio**：摘录栏，服务器把这本书在各篇笔记里的摘录收起来（studio/library-view 里写过的 `bookQuotes` 可以拿回来用），往一篇没打开的笔记里插摘录和「写一句」。
- **前端会话（阅读页）**：阅读页的「笔记」按钮改成开关摘录栏，点栏里的一条时翻过去并高亮（桥接里已经有 navigate），摘完不跳走。
- 前端会话的 read-beside-only（去掉书库整页阅读）和这个方向冲突，先不合。
