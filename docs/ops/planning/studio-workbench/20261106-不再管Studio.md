# 不再管 Studio，专注 RetainPDF

2026-11-06。接着 [Studio 拿出去、RetainPDF 放进 Studio](./20261106-Studio拿出去.md)：Studio 已经拆回本机的 notes-studio，
Mac 应用改回 Studio.app（作者在 Studio 会话里定的）。

## 用户定的

「studio 部分我们以后不管了，我们专注我们的 retainpdf。」

- 本仓库删掉 `frontend/studio/` 和根目录 `.gitmodules` 里的编辑器子模块（milkdown）。已推送的历史里照旧有 Studio，不改。
- 「阅读器和书库做成组件放进 Studio」（上一份的第 2–4 步）不再是本仓库的事。阅读器做不做成组件，以后按 RetainPDF 自己要不要再定。
- Studio 那边同一天也定了「把书库拿出去」：Studio 里和 RetainPDF 有关的都拿掉（旁边开书、书库和翻译页、读到哪告诉 AI、RetainPDF 设置），
  以后不再嵌 RetainPDF。用户选了**嵌入代码也删**：
  - 前端（分支 chore/drop-studio-embed）：网页的 `app/bootstrap/studio-embed.ts`、`platform/studio-bridge/`、地址里的 `?embed=`
    （`carryEmbed`、`embeddedIn`、`embeddedPane`）、书库「交给 Studio」和「在笔记旁边读」；阅读器给宿主的七个接口（`notesQuote`、
    `notesPanel`、`readingPosition`、`hostAi`、`hostNavigation`、`quotedBlocks`、`hostChrome`）和它们画的东西（「摘到笔记」「摘录」按钮、
    摘过的细线、宿主画控件时藏起自己的栏）；两份 `themes/studio-embed.css`。拖分隔线不白页、换宽度停在原页、少挂文字层这些阅读页自己用得上的留着。
  - 后端：契约 `contracts/studio-bridge.v1.schema.json` 和它的测试可以删了（前端已经不读它）。
- 这个目录（studio-workbench）的方案到此为止，留着当历史。
