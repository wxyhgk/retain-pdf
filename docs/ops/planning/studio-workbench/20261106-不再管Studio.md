  `app/bootstrap/studio-embed.ts`、阅读器的宿主接口（`hostChrome`、`quotedBlocks` 等）、两份 `themes/studio-embed.css`。
  Studio 那边要改契约，照旧找后端会话；网页这头不主动加 Studio 的功能。
