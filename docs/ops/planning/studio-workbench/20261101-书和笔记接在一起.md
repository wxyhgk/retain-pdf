# 书和笔记接在一起（2026-11-01）

接着 [10-27 的设想](./20261027-笔记知识库翻译一体化设想.md)。这一天讨论下来定了几件事，做了第一步，定了第二步的做法。

## 定下来的

- **产品叫 RetainPDF。** 笔记是 RetainPDF 的一部分，不是反过来；书、翻译、阅读是核心，不做成可以卸掉的插件。
  化学、计算这些照旧是可选的插件。
- **先做出效果，再决定怎么搬家。** 笔记的代码（notes-studio，以下叫 Studio）先留在自己的仓库，两边各自开着；
  仓库怎么合、目录怎么放、网页版和 Docker 版带不带笔记、notes-studio 原仓库怎么处理，用一段时间再定。
- **第一步（已做）：Studio 左栏「翻译」。** 中间放 RetainPDF 自己的网页（iframe），地址默认
  `http://127.0.0.1:40001/`（RetainPDF 桌面版和开发环境的默认端口），Studio 的设置里能改。RetainPDF 要自己先开着。
  后端配了一个只取一段的接口 `GET /api/v1/jobs/{job_id}/reader/regions/{item_id}`。

做完的感受：放进去了，但两边还不知道对方，不像一个东西。

## 第二步：摘录 → 笔记 → 点回原文

要让人觉得是一个东西，关键是两边够得着对方：书里做的事落进笔记，笔记里点一下回到书。先做一圈：

1. 阅读页悬停框里，「复制」旁边加「摘到笔记」（不做选中文字就弹菜单，那个 10-05、10-25 两次否决过）。
2. Studio 在打开的笔记里插一个引用块，存书、段落编号、页码和当时的原文、译文（笔记里存一份，RetainPDF 没开也能看）。
3. 点引用块，中间切到「翻译」，阅读页跳到那一页那一段并高亮。

顺手两件：RetainPDF 在 Studio 里时不显示自己的顶栏和品牌、颜色跟 Studio 走；以后再加「这本书的笔记」（一本书一页笔记）。

### 两边怎么说话

RetainPDF 的网页在 Studio 的 iframe 里，两边只用 `window.postMessage`。消息格式是契约
`contracts/studio-bridge.v1.schema.json`（2026-11-06 Studio 不再嵌 RetainPDF，契约已删），要点：

- 每条消息都有 `protocol: "retainpdf-studio-bridge"`、`v: 1`、`type`。认不出的消息两边都不理，以后只加不改，要改旧的出 v2。
- Studio 加载 RetainPDF 时地址带 `?embed=studio`。
- 握手：iframe 加载完，Studio 发 `hello`（带亮色暗色）；RetainPDF 回 `ready`（带它会处理哪些消息）。之后才发别的。
- 消息：Studio → RetainPDF 有 `theme`、`navigate`（任务、页、块）；RetainPDF → Studio 有 `quote`（任务、书、书名、块、页、原文、译文）。

| 方向 | type | 什么时候 |
|---|---|---|
| Studio → RetainPDF | `hello` | iframe 每次加载完 |
| RetainPDF → Studio | `ready` | 回 `hello` |
| Studio → RetainPDF | `theme` | Studio 换亮色、暗色 |
| Studio → RetainPDF | `navigate` | 点了笔记里的引用块 |
| RetainPDF → Studio | `quote` | 点了「摘到笔记」 |

### 安全

- RetainPDF 只在 `embed=studio`、有父窗口、消息来自 `window.parent`、父窗口是本机回环地址
  （`http://localhost`、`http://127.0.0.1`、`http://[::1]`，任意端口）时才认 `hello`，记下这个 origin，
  之后发消息都指定它为 targetOrigin，不用 `'*'`。别的网页把 RetainPDF 放进 iframe 拿不到书里的内容。
- Studio 只认来自这个 iframe、origin 是设置里 RetainPDF 地址的消息。

### 分工

| 谁 | 做什么 |
|---|---|
| 后端（本仓库） | 消息契约、契约测试、这份方案、给前端的交接 |
| 前端会话（`frontend/`） | `embed=studio` 时隐藏顶栏和品牌；握手；处理 `theme`、`navigate`；悬停框加「摘到笔记」发 `quote` |
| Studio（notes-studio 仓库） | 加载时带 `embed=studio`、握手、发 `theme`；收 `quote` 插引用块；引用块的显示；点引用块发 `navigate` |

## 还没定的

- 仓库合不合、目录怎么放（顶层一个目录还是按层拆散）。
- 网页版、Docker 版带不带笔记：Studio 的服务器能执行命令、只认本机，放到服务器上要先有登录和限制。
- notes-studio 原仓库：搬进来时带不带历史（它从没公开过）；博客发布、化学插件这些要不要一起进 RetainPDF。
- 从别的设备（Studio 的「其他设备访问」）打开时，`127.0.0.1` 指的是那台设备，看不到这台 Mac 上的 RetainPDF。
