# 阅读页：画笔

2026-11-20 加，用户要的：在书页上圈、划、涂。后端先不管，笔迹存在这台电脑的浏览器里。

## 怎么用

- 进画笔模式有三条路：
  - 书页上右键：弹出小菜单（画笔、荧光笔、橡皮，四种颜色，撤销，清掉这一页）。
  - 按 P。
  - 右下角悬浮小球里的画笔图标。
- 按住 Shift 再右键，或者在输入框里右键，照旧是浏览器自己的菜单；书页区外也不接右键。
- 画笔模式下：
  - 拖动就画，鼠标变十字。悬停框、拖动选字暂停。
  - 左下角常驻一条工具条：换笔、换色、撤销、退出。
  - Esc、P、或者再点一次当前的笔退出。⌘Z / Ctrl+Z 撤销，可以撤画、擦、清一页，最多 50 步。
- 荧光笔是半透明的粗线（叠在字上用正片叠底，不盖住字）。橡皮擦碰到的整笔。

## 存在哪

- `localStorage` 的 `retainpdf.reader.ink.v1:<书>`，书的键和书签、阅读位置同一个（`viewStateKey`）。
  读写失败（无痕窗口、清过站点数据）就只在这次打开里有效。
- 一笔记：页、栏、工具、颜色、线宽、点。线宽和点都是这一页宽高的比例（0–1），缩放、切模式都不错位。
- 按栏存：在原文上画的只在原文栏，译文上画的只在译文栏；「对比版本」时左栏放的另一份译文另算（`compare`）。
  同一位置的字几栏不一样，画在一边的圈挪到另一边会圈到别的词。
- 以后接后端，换掉 `use-reader-ink.ts` 里的 `load` / `save` 两处就行。

## 代码

- `packages/reader/src/hooks/use-reader-ink.ts`：工具、颜色、笔迹、撤销、存取，橡皮擦的命中判断。
- `packages/reader/src/pdf/InkLayer.tsx`：每页盖一张 SVG，画出这一页这一栏的笔迹；画笔模式下接住拖动。
- `packages/reader/src/components/react-pdf/ReaderInkPalette.tsx`：右键菜单、左下角工具条、P / Esc / ⌘Z 快捷键、右键要不要接。
- 样式 `packages/reader/styles/ink.css`。
