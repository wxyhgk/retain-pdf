# 阅读页里的引用：「图 2.1」「式 (3.21)」

2026-11-25 加。用户：先做 1、2、4，第 4 项是「图 3」「式 (3.21)」悬停预览，点过去后 Alt+← 回原处。

## 去处从哪儿认（`packages/reader/src/shared/content/reader-xrefs.ts`）

- **图、表**：图注那一段（`Figure 2.1 …`、`Fig. 3`、`Table 2`、`图 2.1`、`表 3` 开头；数据标了 `figure_caption` / `table_caption`，
  或没标但不长）。去处是同一页上和图注连着的一串图 / 表 / 公式块，碰到正文、标题就停：表往下找、图往上找，那边没有再找另一边。
  表常被 OCR 认成一串公式（Szabo 第 83 页的表 2.2 就是），所以公式也算。预览画这一串加图注的并集；点了跳到其中第一个图 / 表块。
- **公式**：公式 LaTeX 里写了 `\tag{3.21}` 的。
- 同一编号只认第一次（后面的「Figure 2.1 (continued)」不覆盖）。**认不出去处的引用不标，不猜。**

实测（Szabo《现代量子化学》，扫描版）：图注 62 个、表注 71 个都认得出；公式 1953 个里只有 18 个带 `\tag`（印在右边的编号
OCR 大多丢了），所以书里 340 处「Eq. (x.y)」基本都不标。要标它们得让 OCR 留住公式编号，是后端的事。

## 引用本身在哪儿认

书页的文字层（react-pdf 的 `customTextRenderer`，`PdfPageSlot.tsx`）：一段字里认出「Figure 2.1」「Fig. 2.1」「Table 2.1」
「Eq. (3.11)」「图 2.1」「表 2.1」「式 (3.11)」「方程（3.11）」，索引里有的才包 `<mark class="reader-xref">`。
用 `<mark>` 不用 `<span>`：文字层的 span 都是绝对定位，套一层会错位（搜索高亮也是 `<mark>`，两者能叠）。
原文是扫描版时没有文字层，只有译文栏（我们排的 PDF）里有。一个引用被拆在两段字里（比如换行处）认不出来。

## 交互（`hooks/use-reader-xrefs.ts`、`components/react-pdf/ReaderXrefPreview.tsx`）

- 引用下有一条点线；停 250ms 浮出预览：那张图 / 那个式子按高分辨率重画（引用所在那一栏的 PDF），写着「第 N 页 · 点击跳过去」。
  预览只看不点，移开、滚动就收。
- 点引用：记下当前位置（页 + 页内比例），跳到那一块并亮一下（`jumpToAnchor`）。选了字松手不算点。
- 左下角出「← 回到第 N 页」；**Alt+←** 回原处，**Alt+→** 再跳回去（最多记 50 步）。没有可回的时候不拦，浏览器的 Alt+← 照旧。
