# 阅读页：放大看一块（图、表、公式、一段文字）

2026-11-25 加。用户：「还有图片的放大这个也很重要,以及文字区域的放大」。

## 怎么打开

- 悬停框工具条上多一个「放大」图标（和「改」「复制」放在一起）。正文、行间公式、表格、图片都有。
- 图片还可以**双击**。文字块的双击照旧留给浏览器选词（以前双击整块复制把选词弄坏了，见 `reader-hover-copy.test.mjs`
  的守卫：页面上只许一处双击处理，只认图片、不复制）。
- 图片以前不出悬停框（没有可复制的字）；现在出，框按整块画（不收到图里的标注字上），工具条只有「放大」，图里认出了字才有「复制」。

## 放大框

`components/react-pdf/ReaderZoomViewer.tsx`，盖在书上（`--z-dialog`）。

- 这一块按高分辨率**重新画**（`pdf/RegionCanvas.tsx`：pdf.js 按要的缩放只画这一块，画布最长边不超过 6000px），
  不是把屏幕上那张放大，所以放多大都清楚。PDF 用阅读页已经读好的那份（`PdfDocumentPane` 的 `onDocument`），不再下载。
- 对照模式左右并排原文、译文那一块；只开原文 / 译文就只画那一栏。
- 100%：先占满栏宽；太高的（高的图、整页的表）按框里放得下的高度缩，打开不用先滚。框高跟着内容，一段字就是一条矮框。
- + / −、⌘/Ctrl + 滚轮缩放（50%–400%），0 回到 100%；放大后拖着看。
- ← → 在书里同一类的块之间走：图和表算一类，公式一类，文字一类。Esc、点框外关掉；换书、换模式也关。
- 深色文档时画布照书页一样反色（`doc-theme.css` 的变量）。
