# 阅读页 Ctrl + 滚轮缩放、深色文档

2026-11-24。

## Ctrl + 滚轮缩放

在书页区域按住 Ctrl 滚滚轮，或在 Mac 触控板上双指捏合（浏览器把捏合也报成按着 Ctrl 的滚轮事件），以鼠标所在的地方为中心放大、缩小。
范围和 `+` / `-` 按钮一样，是 25%–100%：100% 时页宽等于整个阅读区，所以不会画出比现在更大的画布。阅读区外面按 Ctrl + 滚轮，照旧是浏览器自己的整页缩放。

代码：`frontend/packages/reader/src/pdf/reader-wheel-zoom.ts`（计算、锚点）、`src/hooks/use-reader-wheel-zoom.ts`（手势）。

### 大 PDF 的性能

滚轮转一格就会发好几个事件，触控板捏一下有几十个。如果每个事件都真的改缩放，每次都要重新排一遍所有页的高度，还要重画眼前几页的画布；
重画又会把上一次没画完的取消掉。所以：

1. **手势进行中只做预览**：给整个页面区加 CSS `transform: scale(…)`，以鼠标为原点。这一步由显卡合成，不重新排版，也不重画。
2. **停手 160ms 后提交一次**：这时才真正改缩放，重新排版一次，眼前几页各重画一次。
3. 重画的时候，每页先用上一张画布按新尺寸顶着（`PdfPageSlot` 的 `keepLastPaint`），不会出现白页。
   画布只挂在视口附近的页上（`PdfDocumentPane` 的窗口化），离得远的页只是占位。

实测：300 页的对照（两栏共 600 页），连续 30 个滚轮事件，

- 页宽只改了 1 次，没有长任务；
- 同时挂着的画布在 4–14 张之间；
- 从 50% 放到 100%、再缩到 25%，鼠标下都还是第 151 页的同一个位置。

### 鼠标下那一点怎么对回去

- 手势开始时，记下鼠标落在哪一页的哪个位置，按页内比例记。不能按滚动距离乘倍数，因为页与页之间的间距不随缩放变，越往后偏得越多。
- 新缩放生效后、画出来之前，把那一点滚回鼠标下面。
- 对照模式下，两栏的行高要等重新量完才变（`usePageRowSync` 在 100ms、700ms 各对一次）。所以提交后 1 秒内，页面区尺寸每变一次就再对一次。
- 用户自己滚动、按键、点击时，就停止再对。

### 对照时左右滚动

对照模式下每栏只有半屏宽，缩放超过 50% 时页面就比栏宽，每栏各自横向滚动（`.reader-react-pdf-pane`）。
栏自带的横向滚动条在栏的最底下，也就是整本书最后一页的下面，样式里也藏掉了。所以用鼠标的人没法左右挪；
触控板左右滑、Shift + 滚轮能滚，但界面上没有任何提示（2026-11-24 用户反馈）。

现在在视口底部按每栏的位置画一条一直看得见的滚动条（`components/react-pdf/ReaderPaneScrollbars.tsx`），
和那一栏的 `scrollLeft` 双向同步：可以拖滑块，点轨道空白处往那边翻大半栏。只在那一栏真的放不下时出现。
没有用浏览器原生滚动条：Mac 上原生滚动条平时隐藏、滚动时才出来，还是看不见。
颜色可以由皮肤改：`--reader-pane-scrollbar-track`、`--reader-pane-scrollbar-thumb`；没设时先用 `--scrollbar-thumb`。

栏用 `align-items: safe center` 排页：放得下时居中；页比栏宽时靠左排。以前是 `center`，页比栏宽时往左右各溢出一半，
而 `scrollLeft` 不能是负数，左边那半截永远滚不到，可滚的距离也只有一半（对照 75% 时页左边 163px 看不见；
加了滚动条后用户发现「滚到头不是 PDF 的边」，2026-11-24）。

## 深色文档

书页黑底白字。底栏有一个半黑圆按钮，快捷键是 `D`。这是全局偏好，不分书，存在本机（`retainpdf:reader:doc-theme:v1`）。
打开后，`<html>` 上会加 `data-reader-doc="dark"`，样式在 `frontend/packages/reader/styles/doc-theme.css`。

- 只给 PDF 画布加滤镜：`invert(0.9) hue-rotate(180deg)`。先反色，再转 180° 色相，所以红还是红、蓝还是蓝。用 0.9 而不是 1，是因为纯黑底配纯白字太刺眼。
  切换不用重画，大文档也是马上生效。
- 叠在书页上、自己画底色的东西（实时译文、改过还没排进 PDF 的译文）不反色，换成深色纸（`--reader-doc-dark-paper`）和浅色字（`--reader-doc-dark-ink`）。
  画笔、搜索高亮、悬停框、引用红框保持原来的颜色。
- 限制：书里的照片、插图也会被反色。pdf.js 自带的「页面配色」也是画完后给整张画布加滤镜，图片同样会反色，而且还要重画，所以没用它。
  如果以后要保留图片原色，得在页面上按图片的位置盖回原图，代价比较大，先不做。
