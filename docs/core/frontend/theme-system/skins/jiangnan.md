# 皮肤：素纸（id 仍为 `jiangnan`）

## 为什么旧版显「土」

| 问题 | 旧值倾向 | 观感 |
|------|----------|------|
| 底色过暖 | `#ede8e1` 米黄 | 夯土、陈旧 |
| 纸色发黄 | `#f7f3eb` | 廉价宣纸黄 |
| 强调偏铜绿 | `#2f6f5e` | 锈绿、俗气 |
| 点缀砖朱/亮金 | 砖红 + 鎏金 | 装修样板间 |

## 修正方向

**素雅 = 冷灰中性大面 + 一点冷青绿 + 干净红只做状态。**

| Token | 新值 | 说明 |
|-------|------|------|
| `--bg` | `#f1f0ed` | 冷石灰，几乎不黄 |
| `--paper` | `#fbfaf8` | 近白纸 |
| `--ink` / `--muted` / `--line` | 中性冷灰 | 不跟暖黄 |
| `--accent` | `#2a5f57` | 冷青绿，非橄榄绿 |
| `--selection` | `#e8efed` | 极浅冷罩 |
| `--danger` | `#c23b32` | 干净红 |
| `--gold` | `#8a7a5c` | 哑青铜，仅小标签 |

## 纪律（不变）

1. 大面积只用灰与纸，不用大块绿/金/朱。  
2. 不贴梅枝亭台印章。  
3. 层次靠明度与间距，不靠脏纹理。
