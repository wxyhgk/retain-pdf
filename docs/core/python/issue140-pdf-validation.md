# 双栏续句与 PDF 输出修复验证

本次修复针对 #140：OCR 将双栏文本按行高交错返回时，左栏末段和右栏首段没有作为完整句子翻译。续句识别、组成员编号及模型输入现在共用栏内自上而下、左栏到右栏的顺序，原 payload 顺序、块编号和坐标保持稳定。含邮箱的作者信息不参与正文续句。

真实样本复验同时发现并修复了三处输出问题：

- 链接标注原先仍停在英文位置。导出后按译文字形迁移点击矩形，保留链接目标及外观；支持跨页续句中的引用和换行网址。原样保留区域和无文字的图标链接保持原位置。无法匹配的链接保留并计入 `last_render_diagnostics.link_relocation.unresolved`。
- 最终换行后部分正文、图注超出原框。收敛步骤优先缩短行距，在仍无法容纳时局部缩小字号；低于可用字号下限仍不能容纳时恢复原设置，继续由排版报告暴露问题。
- OCR 已把部分数学符号替换成 `�`。归一化后仅对包含替换字符、且与 PDF 文本层匹配可靠的块恢复文本，并依据字形大小及基线恢复上下标。没有可用文本层或匹配不足时保留 OCR 结果。

没有新增 `document.v1`、translation manifest 或 stage spec 版本。文本层恢复写入块 metadata 的 `pdf_text_recovered`，新归一化结果需要重新翻译后才会进入译文。已有翻译可直接重新渲染以应用文本框和链接修复。
