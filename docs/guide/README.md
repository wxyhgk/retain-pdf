# RetainPDF 使用说明书

RetainPDF 把 PDF 翻译成中文，尽量保留原来的版面：公式、图表、页眉页脚、分栏都留在原位。翻好的书放在自己的图书馆里，可以原文和译文对照着读，也可以直接改译文。

这份说明书写给使用软件的人，按要做的事分章，从装好软件到读完第一本书。

3. [翻译第一本书](03-翻译第一本书.md)
